# 0.6B Jev：以最终 Top‑1 决策验收联合 TPO

本轮只设计一个候选，回答一个问题：同一个模型能否在相同音频上，同时保住 Noul 和 Choice 的分类能力，并迁移到未训练的话题任务？[197/198 证据](../experiments/tpo-reference-198/README.md)用于提出假设；已观察过的 SLURP TEST 和 MINDS 只能作历史对照。本文是新协议，不追改 197/198 的预登记，不代表工程已实现或 NPU 已运行。

## 最终输出与计分

| 面板 | 每条录音只取一个最终答案 | 正式结果 |
|---|---|---|
| SLURP clean TEST60，源任务 | Noul：原始成员概率最大的意图；Choice：全部 60 个候选及 NONE 共同取最大。无附加阈值，平分沿用冻结顺序。 | 两列 Top‑1 macro‑F1；附 Top‑1 accuracy。Choice 误选 NONE 给真实类别计 FN，不从分母删除，也不把无 gold 的 NONE 当第 61 个语义类宏平均。 |
| MINDS native14，跨数据集同任务 | 同上，改用本域全部 14 个原生意图。 | 同样两列 F1，检验意图识别迁移。 |
| SIB-FLEURS 英语，跨任务 | 对 7 个原生话题用相同两种读法，覆盖全部 320 份录音。 | 两列 F1；Choice 是预指定的跨任务改善指标，Noul 是跨模式护栏。区间以 177 个原句为组，不将同句录音视为独立。 |
| MMSU 词义，补充 | 保留 98 道原题的题干和原始选项，按题比较答案。 | Top‑1 accuracy；每题 A/B/C/D 含义不同，不报位置 macro‑F1。FSC 不作基线。 |

macro‑F1 对冻结语义类别等权：先逐类算 2TP/(2TP+FP+FN)，再平均。分别列 197、198、新端点和配对差，禁止先平均两个接口。全量面板中的 NONE 都是误拒；另在冻结的、与 gold 无关的变长列表上分报真类命中时的误拒率、缺席时的误接率及各自分母。变长列表与全量面板不混算。保留同一音频“两边都对/仅 Noul 对/仅 Choice 对/两边都错”四格；跨模式一致但都答错不算收益。Brier/NLL 由原始预测顺带归档，供解释过度自信，不用于选模、晋级或首屏排名。F1 上升也不单独证明置信度可靠。

## 一个训练候选

- **人口、起点及成本。** 为回答 198 的问题，首轮沿用 197/198 的同一起点、6,248 条 clean TRAIN 录音、两次完整曝光、同种子、34 次更新，0.6B BF16、LoRA r64/alpha128；仅在 181，6 卡训练、两个单卡推理实例，macro 384、每训练卡 64、micro 8。沿用封存的真实列表；缺配对视图时用同一音频和相同语义规约补建另一接口，按录音而非视图数计预算。双视图多出的前向、卡分钟、每秒录音数单列。这是匹配起点和更新数的联合方案验证，不声称等算力、全量冷启动或单因素归因。
- **reference。** 每步提交后以最新 actor 为下一 macro 计算近期参考 b；冻结共同起点输出 a 为长期参考。目标 q∝exp((1−ρ)log b+ρ log a+R/τ)，在对应的二元/候选分布上各自归一。首版取 ρ=0.25、τ=1，作为待验证的设计值；近期输出占主要权重，同时阻止旧误差逐步无约束累积。固定参考只对同音频、模板和候选顺序复用。参考、竞争者和 target 在一个 macro 内全部 detach；无需逐步保存权重。[推导及适用条件](../docs/research/tpo-joint-decision-reference.md)。
- **直接优化最终判决。** 分类效用对 Noul 的真实成员/非成员、Choice 的最终正确动作（列表内真类，否则 NONE）提供监督。排序效用奖励真类超过**当前**最强错类；在 Choice 命中时考虑 NONE 这个实际竞争动作，在缺席时让 NONE 胜过最高错误动作，不向任何具体语义类发正奖。使用不足间隔的有界惩罚，已拉开者不重复加码。保留对 Noul 成员和 Choice 覆盖的概率误差反馈。同时在等价上下文上约束 Noul 成员概率与 Choice 候选最终概率（覆盖率 × 条件概率），不比较条件 softmax 与绝对概率，也不让两种模式相互同意代替 gold。保持现有共享读出；本轮不拆 head。
- **可实现的目标构造。** 将分类、排序、概率和跨模式一致性作为同一 TPO 的效用来源：分类用正确动作的一单位收益，排序用最终概率间隔欠额 max(0,0.1−p_gold+p_rival)，概率用均方误差，一致性用同候选最终概率差的平方；后三项取负成本在当前 detached 输出处的一阶方向。Choice 在归一的“候选 + NONE”分布上投影；Noul 在每个候选的二元分布上投影，排序跨候选给金标和竞争者相反方向。按录音归一各项、各动作效用中心化后限幅至 ±1，首版权重依次 1、1、0.3、0.1；两个模式各占该录音一半。以上是提案初值，均进入候选配置，不从 TEST 反推。宏平均 F1 是整个数据集混淆矩阵的函数，不把它伪装成逐样本 reward。先在 clean TRAIN 以脚本检查命中/缺席的动作方向、padding 零权重及每类真实曝光，再封包。

## 判定与边界

1. 主对照预先固定：每个数据集的 Noul 对 197，Choice 对 198；同时展示与另一旧端点的差，避免隐藏退化。主报告比较第 34 步，不用 TEST 挑 checkpoint。原始预测不齐时，先用同样的已锁定模型和面板补齐，不替换指标或比较人口。
2. 单次候选的晋级口径：SLURP 两列相对各自对照都不得下降超过 **0.5 个百分点**，且至少一列配对 95% 区间下界大于零；MINDS 两列、SIB Noul 同样报告差值并守住 0.5 点退化预算；只有 **SIB Choice 的配对差 95% 区间下界也大于零**，才报告本轮观察到跨任务改善。0.5 点是预设的工程容忍度，按点估计判定；不能冒称统计非劣。各指标区间按数据集内配对抽样（同音频的多视图始终一起；SIB 按句），为逐项区间，不作全指标联合置信保证。
3. 分开给出「源域联合改善 / 跨域守住 / 跨任务改善 / 证据不足」；某列只因少选 NONE 上升时，结合四格和缺席误接率解释。未达门槛如实报告，不在同一测试集上循环选权重。一次训练只支持该种子结论，后续独立种子复核后再谈稳定收益或扩大到 1.7B。
