# 从 Qwen3-ASR 出发的单阶段 Jev 联合 TPO

研究问题：在现有 Jev 结构上，从第一步起直接优化最终决策，能否用一次连续训练学好 Noul 和 Choice？这是下一轮设计，不是从已训练 Stage1 端点启动的 [34 步联合目标对照](06-tpo-joint-top1.md)。

排程：181 优先留给上述 34 步对照。接续本实验前，须取得该次正式运行第 34 步的终点收据、核对运行身份并确认已释放设备。子进程在取得前三组 loss 后退出监听、准备期设备空闲或前序训练异常退出，都不触发接续。本实验仍从 Qwen3-ASR 和新的任务参数起步，不加载前序终点权重。

- 起点取同一 Qwen3-ASR-0.6B 基座，沿用现有 Jev 的初始构造方式、判决 marker、语言侧 q/v LoRA r64/alpha128 和共享浅层 Transformer 读出。登记第一次任务训练前的参数身份/种子；不把过去 Stage1、197 或 198 已学到的任务权重当零步结果。直接输入音频与任务规约。基座冻结，只更新既有 LoRA 和读出。
- 全程用一套优化器和联合 TPO。每个 macro 中同一录音同时提供原生 Noul 判决和变长 Choice + NONE，两种视图各占一半录音权重。从第一个更新就给真类、最强竞争者和列表覆盖提供可验证信号；即使初始策略没有选中真类，仍能从标注构造 target，无需等随机 rollout 采中答案。学习率 warmup 不改变目标，不重置 optimizer 或切换 adapter。
- 全量 clean SLURP TRAIN 每轮全部覆盖，不把旧 Stage1 的难例名单作为入场条件。候选身份、顺序、长度由固定脚本按种子生成，不以旧模型的预测筛录音。报告按长度和类别分层的命中/缺席曝光，防止一开始学成总选 NONE。竞争者按当步 detached 分数从当前样本选择，不额外启动一轮离线难例挖掘。
- Reference 复用联合 TPO 的更新语义。固定参考取此次训练 step 0 的同一套权重，近期参考取上一次 optimizer 提交后的模型。每个 macro 计算一次近期分数，micro 只读。第一个 macro 的两个参考相同，判别方向来自真实 TRAIN 标签和当前候选。记录初始与轮末的 NONE 误拒及各类召回，以判断起点锚是否妨碍学习。
- 比较终点以源域和迁移的 Noul、Choice 最终 Top‑1 macro‑F1 为主，沿用上一提案的完整候选 + NONE、配对人口与拒选口径。跟踪 step 0、轮末到最终 F1；并列训练曝光、音频数、NPU 卡时。全量单阶段与旧 6,248 条、34 步的后段不同预算；比较整条路线时计入旧 Stage1 的训练、全量打分与后段训练成本，不把这项比较解释成仅移除阶段边界的因果效果。
