# Jev 四阶段研究协议 v1：从逻辑指令到规模验证

状态：研究设计；全 TRAIN 的首个真值覆盖表已经由 CPU 复算。尚无新模板的模型结果。四个研究阶段分别交付输入契约、能力评测矩阵、训练算法对照、规模曲线；训练术语 Stage1 / Stage2 仍分别指区分性学习 / GRPO。四阶段不是四次连续训练。首轮只用单音频、平行概率读出。参数提取、参数归一化和工具调用属于 Harness / System2。

## 进入模板和算法实验前：用已知错例定义三个判决问题

以下三项是研究问题，不是把每一个错例自动分入一个根因桶。每次对照固定问题、候选、模型和计分人口，只改变指定证据。先在源 TRAIN 独立复现和预登记，测试集只描述现象；一次干预有收益，也不意味着它能解释所有错例。

全量 clean TRAIN 的 Stage1 step 318 已按冻结候选顺序重新计数：40,513 条中日历查询→创建 53 条、反向 121 条；有声书→音乐 99 条、反向 98 条；调低→调高音量 19 条、反向 8 条。此处是模型首选，不是主观听审。封存 Stage2 step 102 的 SLURP TEST 对应有查询→创建 32 条、有声书→音乐 40 条；FSC TEST 的调低→调高有 245 条。不同端点和本体不能合并计数。见[完整 TRAIN 混淆表](/srv/multimodal-jev-xingchao/operations/jev-native-train-confusions-v1/report.json)和[测试错例分析](../experiments/heldout-0p6b-step102-errors.md)。

| 要识别的问题 | 源域对照 | 证据与决定 |
| --- | --- | --- |
| 1a 样本间能否区分 | 固定完整候选与规约，配对只改变一个语义要素的两段音频；另配同义异说话者样本。标签对不自动等于声学最小对，未经独立核验只能称同类/邻类对照。 | 同时报告该翻转时两条都对、该不变时两条都对、正确类与混淆类分差。若示例仅提高单条均分而不提高配对成功率，不声称学会了区分。 |
| 1b 类边界是否说清 | 固定同条音频，在所有查询共享的前缀中比较原始定义、加纳入/排除条件、再加一正一反 few-shot。另用等长对照与候选换位；示例由源 TRAIN 单独支持折提供，不能与查询同源，不按查询 gold 检索。 | 看同一对类的双向错判、每类召回、修正与新错、全体 Top-3。先在独立来源组确认增量收益，再决定是否把 few-shot 引入训练，并保持训推模板一致。 |
| 2 词义、组合语义，还是请求时事实 | 比较词/短语音频练习与等音频曝光的整句最小对学习；在未见措辞、说话者和否定句上测试。对确实依赖情境的判决，固定同一段音频加两个能改变正确答案的可信情境，再移除情境；另设同样包含时间词但意图无需日期的例子。 | 区分词义可学、句法/语用需上下文、外部事实不能背出。无独立条件真值则只记研究假设。绝对时间与工具参数的抽取仍归 System2。 |
| 3 信息不足时能否给出 UNKNOWN | 构造成对样本：完整可判、只移除决定性信息、移除等量无关信息；另设清晰但无匹配候选。仅将独立确认在给定规约下确实存在多个合理答案的例子标“证据不足”。原始单标签数据本身不给这个监督。 | 候选概率保留；拟议独立读出为给定输入与 Q 的证据充分概率。以源域冻结阈值映射 UNKNOWN，比较仅凭最高分或 top1–top2 拒答的基线。报告未知召回、可判错拒率、同覆盖率下已接受样本错误率和原生全人口 Top‑1/Top‑3。 |

UNKNOWN 是针对具体判决的证据状态；清楚但不属于候选集是 NONE，Harness 基于产品风险停止执行是 ABSTAIN。音量指令排错、低分、人工漏标、参数缺失和 FSC 合法的 location=none 都不自动产生 UNKNOWN。证据不足可与候选排序并存。未知样本不强迫选定一个 intent；可判样本不能通过输出 UNKNOWN 免罚。缺少可信未知标签时只评测拒答的风险与覆盖率，不新增正式训练标签。

四阶段工程路线依次验证上述问题的模板、迁移、训练和规模；下文的 IS/OR/NOT 仅是实现边界规则的候选机制。下一次训练的先决条件是完成相应错例对照，而非因为已有逻辑真值表就修改 reward。

## 一、冻结可检验的前置上下文

把问题写成有类型的表达式。IS(P) 询问音频所属的原生标签是否满足本体谓词 P；OR(X,Y) 为包含“两者皆真”的或；NOT(X) 只否定本规约中的已定义命题。NOT(IS(天气查询)) 不等于音频从未提到天气。无可信标签的命题加 observed mask；不把缺标当 false，也不以 NOT 推出 true。第一版只评分所有所需叶子都可观测的式子。

固定前缀为操作符释义、候选定义、问题和表达式；可变音频在后；每个 Q 在音频后有自己的决策 marker。模型一次调用分别给原子问题、复合问题和原生候选输出概率。评分器从可信标注解释表达式产生真值，不替模型填写复合读出。固定语法起步用现有词表能编码的文本标记；新增真正的词表 special token 是独立对照，要验证 embedding、LoRA 保存、HF/vLLM 加载和一致性。新模板会改变输入与 reference 身份。

首个例子 A=原生 scenario 为 calendar，B=原生 action 为 query。Q1=IS(A)，Q2=IS(B)，Q3=OR(A,B)，Q4=NOT(OR(A,B))。从全量 clean TRAIN 的获审逐类人口汇总：

| A | B | 录音数 | Q3 | Q4 |
|---|---|---:|---:|---:|
| 否 | 否 | 24,992 | 0 | 1 |
| 否 | 是 | 10,030 | 1 | 0 |
| 是 | 否 | 3,587 | 1 | 0 |
| 是 | 是 | 1,904 | 1 | 0 |

40,513 是原始录音数，一条录音出四道题不变成四条独立录音。原生 query 只是本体 action，不能解释为所有自然语言问句。首个例子供管线验算；能力评价还须在未见过的谓词/表达式组合上重复。模型若只复制一个分支，在单真格会暴露；OR 若被学成 XOR，在双真格会暴露。

固定同一批音频、同一位置和读出数比较：自然语言等义指令、带明确定义的 IS/OR/NOT、再加入预先固定的一对正反示例。控制示例长度/位置，用等长无关内容或等义改写区分上下文长度效应。模板不随样本 gold 选题。用一组同义测试（交换 OR 两侧、双重否定），一组翻转测试（同一音频改问命题及其否定），以及固定公式换音频的最小语义对。计同义两问都对、翻转两问都对、四格等权准确率、原子全对条件下的复合准确率（附分母）、整组全对率、原生 Top‑1 macro‑F1 和 Top‑3 召回。另设“原子读出 + 确定性解释器”作可部署参照；与它持平也不是内部推理机制的证明。保留 p_final 自身的原始概率，报告 Brier/NLL。源 TRAIN 内留出诊断折，按说话者/同源话语隔离同音频的所有派生题。

## 二、把迁移拆成可区分的学习任务

| 能力 | 训练单元与配对对照 | 结论边界 |
|---|---|---|
| 声音与定义绑定 | 同一规约换音频，关键动作改变时答案应变、同义措辞/说话者变化时应保持；同一音频换候选顺序后映回语义 | 源域基础判决；给出混淆对双方的召回和新增错误 |
| 组合与遵循指令 | 同一音频、同一谓词词汇，改变公式；按谓词对/组合结构留出，比较已见与未见组合 | 从同一 intent 派生的标签只证明组合泛化 |
| 跨数据集成员判决 | 只在 clean SLURP TRAIN 学习；冻结模板、参数和源域阈值，用原生候选定义测 FSC/MINDS | macro-F1、Top‑3、预测类覆盖、校准；不可据目标测试错例调模板 |
| 真正跨任务 | 例如“是否出现指定槽位类型”：只有获得独立可信存在/缺失标注与独立评测人口才纳入；冻结后测试未参与学习的判决任务，单列已参与多任务学习的对照 | 缺标 mask，不抽取值；有新监督时报告二元 macro-F1、AUPRC 和概率质量。暂无可信新任务则明确留空 |

模板选择和训练反馈限源 TRAIN；冻结 selection 仅按预登记规则选点；TEST、迁移目标只出报告。比较按同一音频配对，按说话者/同源组 bootstrap，保留各格支持和最差格。每项晋级前在 TRAIN 诊断折锁定实用最小效应、原生非劣界、置信区间和样本量。逻辑能力的增益与原生任务提升分别陈述；只提升逻辑子集不宣称修复 FSC。

## 三、用现有两段式基座做可归因的训练对照

训练 Stage1 保留当前独占候选 InfoNCE + gold 对最强负类概率间隔 + 双侧阈值约束。多个 Q 可以同时为真，不能在所有 Q 上做一次只许一个正类的 softmax。候选设计：每个被观察的 Q 都比较同命题“成立/不成立”两个原型（也可配对 Q 与其否定），用二选一对比损失；难负类从可信 TRAIN 中确定，并检查不会把其他真命题当负类。附加原式/否定式有方向的概率间隔；等义式的读出一致性只作小权重辅助。总损失按真实音频归一，每条内部按可观察 Q 数归一。常数输出也能自洽，必须同时满足有标真值才计入成功。独立 sigmoid 的 OR 不等于假设独立时的概率并集，不能强制用 pA+pB−pApB 当 teacher。

训练 Stage2（GRPO）保留排名、存在性、原生集合效用和固定 Stage1 reference。新增逻辑信用时对同一音频采样多个真实布尔动作向量。分三项记录：逐 Q 的采样动作与真值是否一致；复合动作是否与本次采样子动作的布尔计算相符；复合动作和依赖叶子是否**同时**符合 gold。首个逻辑 reward 可取“依赖全对且关系满足”为 1，否则 0；在组内相对优势中，低于平均的采样会得到负优势。原子/复合错误的局部信用分别记账，不能因碰巧自洽或重复一条约束多拿奖励。没有足够支持的关系屏蔽。纯关系满足率仅诊断，禁止单独作为 reward。奖励权重与可选平滑辅助 loss 写入版本化插件，先不指定未经验证的最优值。

关系信用依赖哪些动作，就用这些唯一动作的联合 log‑prob 计算新旧策略比及 clipped GRPO；共用的叶子只计一次，不能把整组 reward 广播到互不相关候选。独立 Bernoulli 头可相加 log-prob，若未来条件采样，必须用真实条件联合概率。逐项 advantage、零方差组、裁剪率、有效梯度、reference KL 和真实步时分别报告。组内全等时该项无 RL 梯度，只记录并依赖有标的 Stage1/辅助约束；不能凭一个常数增减 reward 宣称产生负梯度。原生任务仍用原有独占集合路径；逻辑头读出须单独提供 schema、依赖 ID 和 mask，现插件的全观测独占标签不适用。

在相同源样本、种子、LoRA、曝光与评测面板下依次比较：同模板逐 Q 学习；只改 Stage1 的配对/约束；固定同一个 Stage1 端点及其 reference 对比相同 Stage2 GRPO 有/无逻辑信用。对改变 Stage1 的运行各自绑定其新 reference。逻辑改善若仅来自增加标注或读出数，只能归因于额外监督。正式训练前只做有限的数值、恢复和真实更新验收，不新增独立百步效率跑。步骤按第一阶段的数据与任务契约先行；逻辑指令的 RL 收益要到此对照才验证。

## 四、验证规模关系

先以 0.6B 锁定任务/指标，再以同系列 1.7B 做同预算复验。两个尺寸只能报告配对趋势。用嵌套且按类、来源分层的 25% / 50% / 100% TRAIN，在不同种子上测数据曲线；另记录独立音频数、音频小时数、每音频的问题数、有效曝光、rollout 数、总参数、可训练 LoRA/head 参数、实测 NPU 小时与输入长度。改变模板深度或每条 Q 数是任务难度/监督密度变化，单列实验轴。数据规模实验是研究臂，不替代全量正式基线。分别给同曝光和同计算预算的比较，等 NPU 小时不等于等 FLOPs。

主要连续误差取固定可信标签面板上的 NLL（同一面板同一归一分母）；并列报告四格均衡逻辑错误、源域及迁移 Top‑1/Top‑3、校准、最差组、延迟。固定预训练家族、语料与音频编码器的可比性有差异时逐项声明。LoRA 容量也可能限制结果，记录 rank，并单独用等可训练参数预算作对照。获得足够多的同家族尺寸与独立数据量后，预登记候选 E=E∞+aP^(−α)+bD^(−β) 与简单基线，留出一个完整尺寸或数据档检验外推，按不同种子/说话者组估计不确定性；若参数不可辨识、目标域非单调、或留出预测不优于简单基线，只报告观测曲线。新增训练资源、尺寸和开销另列，当前不派发。
