# JEV-212：Stage1 逐录音 Top‑5 难例采样

**研究问题。** 211 的类别 EMA 在 7,828 条源 TRAIN 严格错排录音中，三个槽命中最强错卡的期望只有 5.52%。212 验证：在相同起点、数据和目标下，让每条录音带上实际竞争对手，能否减少错卡高分并改善泛化。[全量覆盖复算](../wiki/reports/JEV-211-stage1-negative-sampling.md)

## 首轮参考、训练起点和评测对照

| 用途 | 锁定选择 |
| --- | --- |
| 212 训练起点 | 复用 211 训练前同一份 0.6B、LoRA r128/α256 和判决 head 的初始化快照，policy ID `3060f93b5fa3251879a8336b1cc1019ead944d8b0408f4e74af90456e61a51ce`；用新 optimizer 起训。 |
| Epoch 1 挖掘参考 | **冻结的 211 Stage1 step 1359**。复用已审核的 109,610 条 × 68 卡原始成员分数（rules 卡面）。无卡语音榜另从同一 checkpoint 导出读出向量；只复用上游身份匹配的冻结声学缓存。 |
| Epoch 2 挖掘参考 | **212 自己的 Epoch 1 正式末点**。核对 checkpoint 审核通过后，以同一口径重打源 TRAIN 并重算语音向量，再冻结第二轮清单；从同一末点恢复 optimizer、学习率进度和随机状态。 |
| 效果主对照 | 211 Stage1 step 1359 的正式留出评测（EMA）。历史 r64 step 160 的 MINDS 表现只提供背景。 |

首轮使用已训练的同任务策略给负例定优先级。官方准入标签仍是真值；211 的概率不作为软标签、loss 目标或校准参数。这样利用的是历史源 TRAIN 的样本级混淆信息，避免用初始化 head 的未成形榜单启动，也省去一次全量判卡。首轮榜与 212 初始模型可能不一致；保留长尾和语义对照，并在有限验收中记录 212 初始权重下候选实际触发排序或间隔信号的比例。212 检验整个「历史模型冷启动 + 本轮模型刷新」采样方案，无法拆出首次参考、逐轮刷新和停止 EMA 各自的独立贡献。没有等价收据的旧分数或缺失向量不得冒充相同参考。

## 训练和数据配置

沿用 211 的 109,610 条准入源 TRAIN（真人及合成）、知识卡、正例规则、随机 few-shot、两轮全量锚点曝光、学习率日程及三项 InfoNCE。每个成员请求仍为完整 system prompt + 单知识卡 + 单录音。温度分别为 0.10，固定语音、固定卡、无卡语音的权重分别为 0.5、0.5、0.25；沿用权重 1 的 **0.30 原始 sigmoid 概率间隔**。不把校准数值或 harness 阈值引入采样或 loss。预登记消融变量是负例来源和分配；保留 211 的诊断定义。

对每条锚点 A，真卡为 g。按固定卡面和冻结策略得到 p(c, A)；在准入错卡里，若最高错误分数严格高于 p(g, A)，记为错排；相等记为并列；其余按真卡减最高错卡是否达到 0.30 区分边界与清晰录音。分类只用于分层报告和覆盖审核，清晰录音照常训练。对每轮分别构造三个 Top‑5 榜：

| 榜 | 合格候选与排序 |
| --- | --- |
| 固定语音、换错卡 | 同一 A 下的可信错卡，按 p(c, A) 降序；并分层记录错排、并列及间隔违规。 |
| 固定真卡、换异类语音 | 在异意图录音中按 p(g, N) 从高到低取候选；用 p(g, A) − p(g, N) 检查其对锚点的间隔违规，同一真卡的倒排索引可复用。为防同一批五条录音覆盖整个类，使用按来源去重的深倒排，限制单条录音在每类锚点中的曝光。按锚点与冻结种子分配，超限则按榜顺延并记录，单列最高误收覆盖与间隔违规覆盖。 |
| 无卡语音相似度 | 取 Stage1 loss 使用的无卡读出，在合格异意图录音中按归一化后的余弦降序。冻塔和 projector 条件成立时只复用缓存、按 checkpoint 更新共享读出；用有界分块检索，不为每个录音对调用完整成员模型。 |

卡分数并列按固定候选顺序；录音并列按稳定 ID。以冻结准入条件排除冲突音频、同源重复及不能确定互斥的对照，跨锚点可复用，保留同意图同文异录作为正例。不人工挑样或用模型改标。第三项检索不得用逐卡概率向量替代；两张负语音榜分别报告命中，不能把一个目标的高分当作另一个目标的高分。

训练每组仍是 **1 锚点＋1 正录音＋3 错卡＋3 异类录音**：

- 错卡：最强有效项必带，另取一张 Top‑5 轮换，第三张用严格语义对照或长尾探索。
- 异类录音：误收榜一条、无卡语音榜一条，第三条用严格语义对照或长尾。两个槽重合时从次位补齐；在不增加组宽的前提下，两项语音损失用同一组有效录音。若已入组的错卡或异类录音也属于语义对照，直接复用其槽位，并把空出的槽用于长尾；不得为了对照替换最强错卡。原有诊断取同一个语义对照的卡和录音，继续使用无示例规则卡。其余训练保留随机 few-shot。
- 负例槽内去重、跨锚点允许重复。榜中不足则先在同源规则允许的异类候选中顺延，再走确定性的长尾补槽；仍无法凑齐有效槽位的清单停止发布。严格按来源去重和曝光上限选择，不能降低标注准入来填槽。默认误收槽把同一候选的曝光控制在该真类锚点的 5% 内（向上取整），适用在该真卡的误收槽；记录稀有类实际候选量和超限失败。

在挖掘快照、同一卡面和合格候选集合内，若把最强错卡放进组内，组内最大负例的概率间隔就等于该锚点的合格全卡间隔。此性质不成立于未重新打分的卡面或模型版本，也不等价于完整 InfoNCE 分母。验收分别记录原榜、准入后榜和训练槽的覆盖、替代原因、负例复用、随机卡面下的名次稳定性和轮间漂移。

## 资源、恢复与评测

| 顺序 | 依赖与资源 |
| --- | --- |
| 首轮数据 | 本地 CPU 或 181/212 CPU 审核并索引既有分数；只有同 checkpoint 的逐录音无卡向量缺失时才导出。涉及卡上前向时在 181 按受验收的有界批次并行，和训练错峰。音频、特征、知识卡及封存面板复用。 |
| Stage1 训练 | 181 八卡 DP8，两轮各覆盖全量锚点。每卡 bucket batch 32 / 24 / 16 / 8，边界 116 / 136 / 165 / 以上，按组内最长实际配对序列分桶，传 attention mask。每桶批更新一次，全局 batch 随桶变化；按实际清单推导更新数，学习率保持已登记的阶段进度，不写死 211 步数。 |
| 轮间刷新 | Epoch 1 终点审核后，用 181 八卡重新计算 TRAIN 成员分数及同版本无卡读出。按样本分片，复用声学缓存，CPU 收集、检索、审核在租约外。211 全 TRAIN 打分实测约 1 小时 49 分，只是成本参考；本轮额外向量导出和检索另计。 |
| 评测与回填 | 预登记初始点身份、Epoch 1 末点和 Epoch 2 末点。Epoch 1 补 SLURP clean selection，供学习曲线诊断；固定 Epoch 2 末点集中跑既有六面板，与 211 冻结预测配对。 |

配置、epoch 清单及收据独立于 211；用内容身份绑定 checkpoint、评分模板、源 roster、标签、音频/特征、种子与构建器版本。支持块级幂等和失败续跑；跨 epoch 恢复需绑定第一轮 checkpoint 与第二轮清单，进程内恢复需继续使用原清单，禁止靠全量重打覆盖已审核分块。新训练后端须先过独立审核、4 次概率对齐、2 次真实更新，并验收跨轮恢复、两个负语音槽和严格对照监测。已有 211 EMA 后端不接收 212 的逐录音清单。

主指标是 SLURP clean selection / TEST 和 MINDS native14 的 Top‑1 macro‑F1，附准确率、真卡/最强错卡/Top‑1 原始概率、修好与新错。使用成对 95% bootstrap 区间（2,000 次、种子 317，沿用冻结面板的来源组；如仅有录音 ID，按录音配对并写明限制）。SIB-FLEURS、MMSU 及官方 SLURP TEST 保留既有口径并单列。仅使用 source selection 判断是否推进；相对 211，selection macro‑F1 的配对区间下界需高于 −1 个百分点的预登记界限。宣称 MINDS 迁移改善需要其 macro‑F1 配对区间下界高于 0，同时公开源域 TEST 结果和概率移动。用冻结面板同时比较无卡检索和成员判卡，缺失向量须标明；收益结论不以 TRAIN 命中或低 loss 代替。统计 NPU 训练吞吐与包含轮间打分的总耗时。

本登记范围为 **Stage1 与独立评测**。Stage1 结论出来后再决定是否接既有 Stage2 A；若接续，只复用仍匹配的缓存，由 212 正式末点生成参考及训练视图。最后一轮没有需要消费的 Stage1 清单，不额外刷新负例榜。
