# 同一问题的动作组、对比录音与 LoRA 容量

本页保留历史对照设计和数据依据。当前仅执行[统一训练 proposal](../proposal/05-next-generation-simple-jev.md)；这里的实验分支不单独派发。

目标还是两个：随音频和任务规约给出正确的候选顺序，以及能用于决策的独立存在概率。所有对比使用源域 clean TRAIN，不取迁移评测或 TEST 的错误来配对。Top‑K 不进入训练约束。

**两种 group。** G=16 指给定同一音频、同一候选比较、同一行为策略，从该二选一分布采样的动作。可以将录音 A「调大音量」、B「调小音量」一起放入同一批，两条音频使用同一完整候选规约，各自独立前向、独立按自身问题归一化奖励。另一种配对是「调大音量」/「请调大音量」，判决应保持。比较两边都答对的比例、翻转是否双向、等义音频的概率差；不能只看平均准确率。例子说明配对语义，不是已经审核的成对录音。独立逐条损失在同一 optimizer update 中相加，单纯改变 microbatch 内的相邻顺序不会创造对比梯度，应与同曝光的随机组批比较。

直接令 16 条不同录音的单个奖励共享均值和方差会改变优化器：奖励差异含题目难度和类别先验，G 不再是固定输入下的多动作基线。若要探索真正的跨样本 GRPO，一个可定义的动作是同时为一对录音作两个判决。第 g 个样本是 (a_A,g, a_B,g)，在条件独立的两次前向下联合 log-prob 是两者之和。G 组都在**同一对录音**上采样，预先定义局部关系与两端正确性的有界联合奖励；用联合动作比率和组内优势，不能把联合奖励配给两个独立 PPO 比率。这是新任务估计量，不是修改 batch 配置；组方差可能更低，暂不作为主线。要保证可比，固定录音数、困难回放比例、真实曝光数、候选面板、行为策略和实际动作预算。

**先查实际信号。** ranking_signal_coverage 从正式审核 hash 追溯 transport 及 102 个 groups 文件，跳过 padding；计算真实二选一组的全对/全错，再单独用 Stage1 对全源 TRAIN 的独立 sigmoid 估算期望。0.6B 两轮正式训练共 38,758 次真实曝光，48,522 个严格错序的比较组，其中 12,059 组全错（24.85%），0 组全对；有错序的 11,844 次曝光中 6,317 次至少有一对全错。这仅指该对的 ranking RL 梯度为零；存在、全候选 NLL 等仍可提供梯度。Stage1 自然人口的 23,880 个错序对中，预期 3,207 组全错（13.43%）；训练视图和策略不同，二者不能相减当效果。现有真实组内采样信号不充分，但不能从此推出跨录音归一化有效，也不应强行把一对的 16 次采样固定成半对半错。二选一动作也可以枚举两边并按真实行为概率求期望，另立估计量基线；与有限 G 的组内标准化不同。

**容量与目标要分开诊断。** 正式策略里，28 层语言 q/v 的 r4/alpha8 共有 573,440 个 adapter 参数，独立 Transformer head 有 6,304,769 个参数；两者合计 6,878,209，可训练范围不含另存的冻结 1,024 维 marker。head 大并不等于它能恢复 backbone 没有传出的声学线索。r8/alpha16 将 q/v 可训练参数增至 1,146,880，head 不变；总可训练量只比 r4 多约 8.34%，但每个 q/v 增量的秩上限翻倍。严格隔离探针的自然语音配对只有两对翻转、五对保持，不足以支持全量采样策略。扩充配对须有多个句架、谓词、说话者；分开报告未配对的人口，避免复制少数样本扭曲概率。

**最低成本的区分性验证，按顺序只改一个变量：**

1. 以 102 步正式配置为对照，固定 r4、同一 Stage1 起点、视图、种子和曝光，仅将 task_rl_weight 从 0.5 置零，不重分配到其他分支；使用 configs/experiments/stage2-without-set-credit-v1.json。集合动作指标仍可观测。此对照识别删掉集合项后的净变化（包括梯度尺度），不能单独证明梯度冲突或加速。若要区分相消与尺度，固定源 TRAIN 批次，用各项单独反传记录 LoRA/head 梯度范数、双信用夹角与总步长；抽诊不叠加到正式目标中。
2. 比较有审核支持的对比录音组批与同样录音、曝光的随机组批，保持每题自己的 G。隐含期望是成对翻转/保持及原生任务指标共同提升。若要强化组内关系，第一选择是 Stage1 已有的对比监督，Stage2 不同时加第三个奖励。复用同一指标检验同义条件下概率的变化。
3. 只有前两步仍不能解释残差时再做容量实验。固定任务与目标、模型族、初始化函数、曝光、学习率与 head；比较相同初始函数的 r4/8 和 r8/16。可从同一 Stage1 末点做保持旧增量的 rank 扩展：保留旧 A/B 和 alpha/r，新增 A 独立初始化、对应 B 置零，不能 A/B 同时为零；参考策略仍取原末点。此路线须新增 adapter 转换/加载、切换契约，未经训练前 logit/概率对齐及恢复验收不启动。另一条可行但回答不同问题的路线是从同一 base 独立跑两套 Stage1，各自缓存 reference，比较端到端预算与结果。冻住数据和目标，不混淆两种估计。

优先看源域未参与训练的 Top‑1 macro‑F1、整面板排序改善/退化、独立概率 NLL/Brier；训练内诊断按难易分层。FSC/MINDS 仅冻结后报告。训练变好、源域与迁移未改善不能作为容量收益。该对照是下一轮候选，不是已启动的训练或效果结论。

**Stage1 先做可归因的全量对照。** 冻结 step102 对方向词的 53 对 TRAIN 诊断在原布局双边 Top‑1 为 45/53，边界模板仍是 45/53，边界模板同时逆序定义和读出降为 24/53。这是 Stage2 终点的组合干预；应先测 step318 的 Stage1 端点，不能推定同样退化已经发生在 Stage1。对同音频单独改定义顺序、单独改标记顺序，分数按候选 ID 复位。首次训练比较保留全候选 InfoNCE（温度 1）、概率间隔 0.10、围绕 0.50 的双侧锚点、r4 与 DP4，原生组与两个单因素组都每条每轮只前向一次。两轮内每条恰好各见一次原布局与对应变体。配置见 configs/experiments/stage1-layout-ablation-v1.json；准备脚本 tools.reports.prepare_stage1_layout_plan 可重建 40,513 条、每臂 81,026 次曝光的分配与可复用面板。正式训练前还要在真实 processor/actor/reference/评测路径验证位置绑定、输入 cache 身份及训推数值。

关键词翻转和无关变化保持属于独立的声学轴。把规则扩展至十组原生意图、仍隔离旧探针及其同源数据后，4,809 条合格录音仅产生 6 个翻转录音对（4 个句架、3 个类别对）、15 个保持对（9 个句架）。其中有些同时改多个词，不称为孤立的词因果效应。当前只作 TRAIN 辅助机制验证，不复制成主训练分布。验收同时看双侧判决正确、正确类概率对最强负类的间隔、同义输入按 ID 对齐后的概率偏移，以及原生全人口 Top‑1 macro‑F1 和 NLL/Brier；常数读出不能凭低偏移过关。泛化结论由独立源域评测和冻结迁移给出。新 Stage1 终点须重新全 TRAIN 评分并封存新 reference 与难例回放视图。
