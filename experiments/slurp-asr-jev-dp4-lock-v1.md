# SLURP Qwen-ASR Jev 四卡训练与对标协议

2026-11-12 UTC。依据用户最新指令固定路线；本文件是执行和评测协议，不是完整训练启动回执。正式数据名单、全本体读出及连续 trainer 尚待实现和验收。

## 训练与推理

- 基座：本地 Qwen3-ASR-0.6B，身份 `02fe809e756cd2de3d9fa5364c763bb5127d50d8956f2570c265e7c34264a458`。Omni-30B-A3B-Instruct 为冻结参考模型，不作为当前训练模型。不下载新模型。
- 训练：175 的物理卡4、5、6、7，FSDP FULL_SHARD、world size 4、use_orig_params=True。四 rank 使用不同录音分片，按有效请求数归一化全局 loss；多卡单独跑实验不算数据并行。沿用已验收 q/v LoRA rank4、alpha8 作为首个工程配置；正式学习率、批量与预算需在完整数据发布后预注册，不从8录音探针推断最优参数。
- 精度：base、LoRA 执行/导出、typed projection 均 BF16；关闭 PEFT adapter 自动升精度。FP32 master、Adam、归一化和 loss 允许。未合并 adapter，同一份身份用于 actor 和 rollout。
- rollout：vLLM TP1；可在验收后采用多个 TP1 副本。TP4 未通过既有一致性检查，不纳入主线。四卡内 actor/rollout 分阶段调度，不假设额外设备或同时驻留的显存容量。
- 输入直接为音频和完整问题模板，问题及 Span 位置在输入前给定，一次前向读出 typed 输出。不加入目标转写、gold 意图或外部文本推理。记录真实处理波形身份；训练/rollout 一致，增强只用于学习样本。
- 每次接纳策略版本前，验证完整候选分布和联合动作概率、导出重载、音频/模板/head/adapter 身份；不降低既有 gate 阈值。新本体的全候选验收需重新做，三布尔 gate 不能替代。
- 采用 verl actor/loss、vLLM rollout 及版本同步。原生生成式 token trainer 不能直接冒充一次 typed Span trainer：需要落实 typed action batch、old logprob、reward、有效监督 mask、参考策略及恢复游标在完整生命周期中的传递。

## 任务与监督边界

1. 意图任务：音频 + 统一候选意图定义，输出一个 intent enum。主指标 Top1 accuracy、macro-F1，Top3 作为诊断；类别支持数及逐类召回同时报告。
2. 类型任务：音频 + 固定业务类型定义，不提供意图，输出类型集合。按候选类型填充布尔 Span 并合并；问题打包方案须固定、不得依赖 gold 或先前输出。业务本体按 omni 55 输出类型逐项映射，54个有支持类型与55输出类型不能混称。正式发布前不能宣布映射已完备。
3. 决策 CoT 扩展：保留 `Q1,<SPAN1>,Q2,<SPAN2>,Final Q,<SPAN3>`。只用可从已审核数据得到监督的前置问题；单问与多问用相同最终任务、音频和监督预算对照。规则派生 Final 不替代原生意图/类型成绩。

槽位值生成、SLU-F1 的值匹配分数另列，不是本轮 Jev 主成绩。None/Other 是候选控制协议，不是新增业务类型，更不代表缺标。已确认缺陷不进入 loss/reward/教师反馈/选择；未知标签必须 mask，不能补 false。只有已审核为完整的集合可计算集合 exact 与“全空正确”。其余样本保留并单列覆盖率，防止以删难例提高指标。

当前仅48来源的时间三类型监督完成语义审核，不能据此宣布全意图、全55类型训练就绪。沿用 clean-v7 和 source-group 隔离，发布监督准入清单、冲突隔离、音频哈希、本体及 scorer 哈希。正式测试集保持自然分布，不用于本体调参、奖励或提示搜索；调试批次均衡不改变测试分布。类型多标签无法保证所有联合组合均衡，应分别记录边际/共现覆盖和采样权重。

## omni 参照及可比性

固定来源为 `omni/repro/publication/omni`，锁定版本 `9acf649ef93df21dc887c5cfe9a4ac2a0f4c55c9`；文件 SHA256 及分母见 [参考锁定](../docs/research/omni-slurp-jev-reference-lock-v1.json)。已用该版本的 Git 对象逐一核验5个文件，不能用持续变化的工作区 HEAD 替代该引用。以下均为 omni 历史项目结果，不是本项目新复测，也不是行业 SOTA 声明。

| 任务 | 历史结果 | 使用限制 |
|---|---|---|
| P 意图 | Top1 84.56%，Top3 94.70%，n=1075 | FoldA 质量排除后独立节点 |
| S 条件类型 | micro-F1 77.22%，集合 exact 310/545 | 给正确意图，仅正确分支；476学习+69隔离 |
| S1 无意图类型 | P 14.18%，R 94.12%，F1 24.65% | 6681条历史 P 成功筛选的 TRAIN；1截断保留，原JSON scoring PARTIAL |
| S1 grounding | P 23.42%，R 89.46%，F1 37.12% | 同一 TRAIN；完整覆盖下降，未晋升 |
| S1 None | P 27.37%，R 84.92%，F1 41.40% | 同一 TRAIN；正样本完整覆盖79.74%，未晋升 |

S1 的职责更接近当前 Jev 类型任务，但训练集筛选偏差仍在。77.22%不可作为无意图类型的直接达标线；24.65/41.40也不能作为不同测试名单的直接门槛。逐类型布尔 Omni 协议尚无已核验完整精度，不填入分数。

正式比较冻结 ASR、ASR+LoRA SFT、同起点 ASR+LoRA RL、冻结 Omni。分别报告 Omni 原生提示协议和与 Jev 匹配的候选/知识协议，避免将提示差异全部归因为模型。ASR 冻结读出若需要训练 head，必须标为 head-only 对照，不能称零训练基线。

类型主报 micro P/R/F1、macro-F1、集合 exact、非空样本完整覆盖、空样本误报率、额外候选数、协议失败率及监督覆盖率。不得用负类占优的二分类 accuracy 或单独 recall 宣称胜出。按 source_group 配对 bootstrap，报告95%区间；同测试名单、本体、缺标处理和输入知识才可横比。

目标是形成“同集达到/超过 Omni，同时 RL 超过同预算 SFT”的证据。意图 Top1 与类型 F1 分开判定，类型必须同步披露完整覆盖、空样本误报和退化，不能以单指标提升判综合胜出。非劣效容限与选择规则在首次使用新选择集之前另行预注册，当前不捏造统计达标阈值。泛化另用来源隔离和预注册任务族留出评测，不把同源改写当跨任务泛化。

## 奖励与实验次序

先锁定监督起点，再比较同预算 SFT 与 verl RL。奖励按有效任务监督计算：意图正确性、类型正负判别及集合质量分别记录；权重和类平衡只由 TRAIN 定义。类型奖励必须检查全选/全空退化，不能用全体类型的平均负类正确率主导。批次类别均衡须在所有对照一致并披露采样分布。

前置 Span 有可靠标签时才允许过程奖励，未知位置 mask。首先做无过程奖励的 Final-only 对照，再独立比较加入过程奖励；不默认奖励所有前置问题能改善 Final。seed17 双留出 structured Final 上，GRPO 与 conditional 相对 SFT 的差值区间均含0，并出现几乎全判 false 的退化；其它单元存在未校正区间不含0的结果，不能概括为全部差值区间含0。成对奖励候选尚未验证，当前奖励方案不晋升主算法。详见 `docs/engineering/span-transfer-three-methods-s17-a2-v1.md`。
