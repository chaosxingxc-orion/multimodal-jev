# 0.6B：方向词与语义绑定的分项诊断

问题来自两个不同的干预：固定规约换音频，方向信号是否变化？固定音频换候选布局，变化后的分数是否仍归给相同含义？此次为 Stage2 step 102 冻结 HF 端点，在 181 四个单卡容器上测试同一批 298 条 clean TRAIN 录音。每个配置 60 个候选。不是独立开发/测试集，不能从本面板推断跨域效果或阶段训练收益。

53 对方向录音的原生标注分别为调高、调低；离线参考措辞除配置的一对方向词外相同；14 对同说话者。匹配转写未给推理服务；非同一音频编辑，声音、语速等仍可变。对每条音频定义 d=p(调高)−p(调低)，衡量 (i) d(调高录音)>d(调低录音)；(ii) d(调高)>0 且 d(调低)<0；(iii) 两条在完整面板均 Top‑1 正确。端点输出为独立 sigmoid。

| 配置 | 相对分差方向正确 | 双边胜过方向反例 | 双边分差均 ≥0.1 | 双边完整 Top‑1 |
| --- | ---: | ---: | ---: | ---: |
| 原模板 | 53/53 | 49/53 | 46/53 | 45/53 |
| 加入日历类边界 | 50/53 | 48/53 | 46/53 | 45/53 |
| 再加日历正反示例 | 51/53 | 47/53 | 44/53 | 41/53 |
| 边界模板，候选完全逆序 | 52/53 | 46/53 | 38/53 | 24/53 |

逆序面板的 14 个同说话者对，14 对两侧均胜过方向反例，仅 6 对两侧均为完整首选。证据支持“排序/绑定是值得优先解决的失分环节”；在此未做声学局部遮挡，也未比较冻结预训练与适配后端点，不能据此证明模型独立识别了每个词，或把效果归于预训练本身。逆序同时改变定义与读出顺序以及因果历史，只证明组合干预敏感。

## 下一轮实验配置原则

- 规约描述“查找哪个语义证据”和“这个证据如何影响哪个判决”。区分 literal mention、语义方向、动作/对象/否定作用域与原生命令，不把关键词等同最终意图。训练题从本体或预注册配置产生，不看本条 gold 选 Q。别名作为释义，不能作穷举白名单。在线只输入音频和规约。不做工具参数或文本解码。
- 源 TRAIN 构造音频×谓词矩阵：同句架换方向应翻转；换说话者/同义短语应保持；同一个词在不同对象、否定、引用场景下应按指定 Q 改变或保持；固定音频换 Q，问“是否提到调高”与“是否请求调高”可不同。后两项需可信的独立 supervision，不能从 intent 缺失反推词没出现。对缺依据 Q 保留 mask。
- 分开打乱定义顺序和 marker 读出顺序，四种组合依同一 semantic ID 评分，使用数个固定置换并平衡位置；再交换临时标签别名和释义检验是否依赖 ID 字面。原布局兼容组始终保留。批内共享少量前缀，避免逐样本随机文本打散缓存；训练、rollout、reference、评测共用编译器。
- 第一臂冻结声学前端，复用现有音频语言隐状态、语言层 q/v LoRA 和 Transformer 概率头。原生全候选 InfoNCE 仍是主项；加配对音频各自相对反义候选的对比与概率间隔，另以语义 ID 对齐同音频的等义排布并保持监督目标。样本及多视图按真实音频归一；不把含义已改变的 Q 当作不变性。分别添加每个辅助项后，再看是否需要更改编码器。
- Stage2 候选：保留原生排名/存在信用，只有合法同源配对能追踪到真实采样动作及其联合 log-prob 时才给关系奖励。仅一致但两次都错不奖励。先验证 Stage1 配对间隔、未见句式、未见说话者及原生 Top‑3，再考虑 GRPO；不能因为 TRAIN 探针好看就更新冻结训练。
- 基线两项 CPU 计算见 `aligned_cue_objective.py`；尚未接入正式训练。上线前要接入分组 sampler、批内切分/DP 归一、可重放 reference 和数值验收。声学层是否需解冻取决于严格读词/音频替换对照，而不是候选逆序导致的成绩下降。
