# FSC 完整 TEST：冻结基座与离线教师提示词优化

2026-11-11 完成独立验收。相同本地 Qwen3-Omni、相同音频和任务请求下，
选定提示 p1 将 native 严格正确率从46.1904%提高到91.7743%，增加45.5840个百分点。
正确候选缺失的成功率仍不足1%，六视图全对率仅0.6327%。当前证据支持 FSC
严格消费接口的提示词优化收益，尚不支持可靠的完整 Jev 决策、权重训练收益或跨任务泛化。

## 比较条件

官方 TEST 共3793条录音，每条生成6种相关视图；每个提示完整执行22758次音频调用。
模型权重冻结，在线 actor 直接消费音频和任务 schema，不使用转写串联。
远程教师离线生成候选，候选在 TEST 前经冻结的 TRAIN 选择协议确定；本次测试
没有用于提示词优化。六视图共用录音，不能把22758视为独立样本量。

两边使用相同固定镜像、模型 revision、请求名单、解码和严格 scorer：BF16、TP2、
greedy、seed17、最多128输出 token、4096上下文、一次 replicate；NPU4/5、
16 CPU、128 GiB内存、8 GiB共享内存。模型 revision 为
`26291f793822fb6be9555850f06dfe95f2d7e695`，源码为
`553c27d823c7e2209fa4041ba7632e5e9d3e3d02`。

严格正确要求原始响应直接解析为只有 `value` 和可选 `confidence` 的 JSON 对象，
输出值及类型与目标一致。不抽取解释中的答案、不剥离 Markdown、不修复格式。
native 是原始 action/object/location 组合的候选选择接口；分数同时反映任务判断
和接口遵循能力，并非独立的语音识别准确率。

## 结果

所有单视图和配对指标分母均为3793条录音。

| 视图 | 父提示正确数（正确率） | p1正确数（正确率） | 增加百分点 |
|---|---:|---:|---:|
| native | 1752（46.1904%） | 3481（91.7743%） | 45.5840 |
| permutation | 2037（53.7042%） | 3511（92.5653%） | 38.8611 |
| rebind | 1768（46.6122%） | 3497（92.1962%） | 45.5840 |
| missing_candidate | 36（0.9491%） | 37（0.9755%） | 0.0264 |
| noul.True | 2561（67.5191%） | 3495（92.1434%） | 24.6243 |
| noul.False | 2291（60.4007%） | 3666（96.6517%） | 36.2510 |

p1全部22758条响应 JSON 格式合法；native、permutation、rebind 和两种 noul
视图全部符合 schema。missing_candidate 有3107/3793符合 schema，686条不符合。
合法 JSON 不等于合法候选或正确的未知判断。父提示 native 格式合法率为50.6723%，
因此整体提升包含格式遵循改善，不能全部解释为音频语义能力增强。

| 同一录音要求 | 父提示同时正确 | p1同时正确 |
|---|---:|---:|
| native与permutation | 1382（36.4355%） | 3379（89.0852%） |
| native与rebind | 1410（37.1737%） | 3449（90.9307%） |
| native与missing_candidate | 19（0.5009%） | 25（0.6591%） |
| noul.True与noul.False | 1729（45.5840%） | 3372（88.9006%） |
| 六视图全部正确 | 9（0.2373%） | 24（0.6327%） |

逐录音父提示→p1转换中，native有1739条由错变对、10条由对变错；
missing_candidate为26条改善、25条退化，配对双侧精确 McNemar p=1。
六视图全对为20条改善、5条退化，未做多重比较校正的 p=0.0040773。
这点绝对提升并不代表达到可用水平。部分单视图的 p 在机器浮点数中下溢为0，
不应解释为数学上的零概率；各视图也不是相互独立的实验。
