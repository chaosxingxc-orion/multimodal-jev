# SLURP native multi-Span SFT v1

固定于启动前：本实验验证原始音频多 Span 的反向传播、适配器更新及保存；不声称学术基线复现、CoT、RL 或泛化收益。

- 固定本地 Qwen3-ASR-0.6B-hf、BF16 eager，物理 NPU 4，离线固定镜像。
- 数据为 reviewed release `48511c803e33936cfa787301cac940773ed4e80d90e346841498a59205f5f584`，48 条学习录音、142 项审核监督，2 项不可靠监督仍屏蔽。审核为参考文本语义审核，不是人工听音。
- 所有录音固定 date/time/timeofday 三问，最后一项仅为接口 Final；三项为并列角色。targets、review、来源分组均不进入模型模板。
- 原有 native LM head，读取占位符前位；每条录音一次骨干前向，不解码、不回填答案。
- 单 epoch，seed 17，语言骨干 q_proj/v_proj LoRA rank 4/alpha 8，AdamW lr 1e-4，weight_decay 0，梯度裁剪 1。每次更新累积 2 条录音，共 24 次更新；按该批可用 Span 数加权全词表 CE。
- 验证有限损失、非零有限适配器梯度、保存适配器；记录训练前后各 Span 候选概率、142 项准确数、46 条完整三问全对数，另记录训练后等长度静音对照。
- 所有指标只描述学习人口；无验证集调参、无测试集访问。无任务收益准入阈值：损失下降或训练集正确率提高不能证明有效泛化。
- 单次容器硬截止 3600 秒；输出逐步进度、history、最终 adapter 与 terminal。中断后保留证据，不自动覆盖或恢复已完成工作。

真实多 Span 前向已在 `slurp-single-pass-spans-smoke-v2` 通过：600 token，243 音频帧，读出位置 286/447/589，一次骨干调用，三个全词表读出有限，候选归一化通过。该证据不包含训练能力。
