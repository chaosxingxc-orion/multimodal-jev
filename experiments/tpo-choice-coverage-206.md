# JEV-206：逐类概率、双向对比奖励与 harness 阈值

**登记状态：仅设计，不领取。** 本条沿用 206；没有制作数据、发布运行包、派发训练或得到评测结果。

**研究问题。** [201 的变长 MINDS 面板](../wiki/reports/JEV-201.md)逐条复用了 198 的候选名单。真类在场时，候选内准确率从 79.13% 升至 81.46%，误拒率却从 32.01% 升至 71.22%。此外，201 的逐类输出在 MINDS 上的 Top‑1 macro‑F1 为 69.74%，低于 197 的 71.94%。206 分别检验：模型能否区分标签、不同音频的同一标签分数是否可比，以及 harness 的单一阈值能否迁移。201 的结果是设计依据，不是 206 的结果。

## 输出与训练信号

Jev 直接消费音频、任务和标签定义，只返回逐标签的原始 sigmoid 分数。0 到 1 的值域固定，不要求分数之和为 1。推理不依赖同批其他录音，不设 Choice 输入、NONE 动作、覆盖头或训练阈值。业务支持哪些原生标签由 harness 配置；对短名单不重新归一化，低分不区分业务范围外、漏召回或音频不清。

设 p[i,c] 为录音 i 对标签 c 的成员分数，y[i] 为其唯一可信真类。设计采用冻结 Stage1 参考、逐标签 Bernoulli TPO 投影。参考上的三项信号如下：

| 信号 | 定义 | 需要防止的错误 |
| --- | --- | --- |
| 音频 → 标签 | 固定一条录音，在完整原生候选上，奖励真类的 log-softmax 分数。 | 看清真类和最强错误标签，而非让 59 个容易负类主导排序。 |
| 标签 → 音频 | 固定标签，每条正录音分别与同一全局训练批中该标签的全部已确认负录音形成 softmax，奖励该正录音的对数份额；按正录音取均值。 | 同标签的其他正例不进分母；padding、未知项不作负例；无可信负例时跳过此项并记分母。 |
| 绝对分数 | 对已观测成员位使用负 Brier 分数，即负的 (p−y)²，y 为该位的 0/1 监督。 | 两种比较都不能单独锚定绝对数值；不把类别均分一致或某个固定分数当作校准。 |

两个 softmax 均用 log(p) 作输入，温度 1；“动态”指竞争权重随已冻结的参考分数及实际批次而变，不引入在线参考刷新。两方向等权构成一项辅助 reward。设计起点：对每条正例的对数份额取关于成员分数的局部效用（含对竞争负例的影响），按方向汇总至对应成员位，各方向位移裁剪到 [−1,1] 后各乘 0.5；Brier 的单成员效用为 2(y−p)，同样裁剪，权重 1。三者加到冻结参考的对数赔率，得到每位的 Bernoulli 训练目标；训练仅拟合这些目标。批间对比以实际 global batch 的非 padding 行为单位，不以单卡 microbatch 代替。对数和边界值的数值处理、截断比例应在未来封包时记录，并验同类不互斥、换序不变、推理单条与成批一致。[CLAP 双向对比资料](../docs/research/jev-harness-decision-learning-survey-v1.md)仅支持该设计类比，不作为本地效果证据。

## 人口、对照与判据

- **同起点对照。** 从 201 使用的 0.6B Stage1 step 160 起跑，复用 201 的 6,248 条 clean SLURP TRAIN、种子 317、两轮、全局批 384、34 次更新；只复用录音、金标、批成员与顺序，不复用 Choice 目标。来源为 201 targets/MANIFEST.json（SHA‑256：9fd6ec10e3df3d92307b180d3e021ea50a4a6fb8ba4c36d4842d2e88f9cb3847）。预登记 step 0/34。201 step 34 的**逐类分数**为历史方案对照，step 0 为共同起点；201 的 Choice 误拒率不能与 206 的 harness 接受率直接相减。单个 206 候选只能验证整套方案，不把净变化归因于某一方向。
- **阈值校准。** 两端点分别在同一份源域 clean TRAIN 校准人口上，用同一规则选一个全局阈值：按原始 Top‑1 分数决定是否输出其标签，最大化将拒绝计为未命中的单标签 macro‑F1，并列取较高阈值。人口取 206 训练视图之外的 TRAIN，排除同源语句组与重复音频，先固定 ID、分母、身份及类别覆盖。Stage1 已见过源 TRAIN，该人口仅用于 harness 拟合，不作为独立测试。阈值在 selection、TEST、MINDS 和补充面板前冻结；不使用 0.5 作通过线，不为迁移集另选阈值。
- **主读数。** SLURP TEST、MINDS native14 分报同一录音上的原始 Top‑1 概率、单标签 Top‑1 macro‑F1、准确率。并列报告逐类 Brier/NLL、按分数分箱的实际命中率及分母、正/负成员分别的误差；避免大量容易负类掩盖真类退化。对冻结阈值另报覆盖率、接受中的错误率、Top‑1 原本正确却被拒的比例；有真类缺席的固定短名单时，分报在场误拒和缺席误接。不能用短名单缺席冒充真实业务范围外监督。
- **结论口径。** 按数据集给出相对 step 0 和 201 的差值、逐条修复/新增错例与分组配对区间。排序改善、绝对分数更可信、冻结规则可迁移分开判定：只有覆盖率可比且接受错误减少，才主张路由有益；仅靠多拒绝降低错误不足为证。区间跨零或覆盖率无法对齐时记录证据不足。补充沿用 SIB‑FLEURS 英语话题（按原句分组）和 MMSU 多义词（按原题准确率）；不扩大数据集范围。
