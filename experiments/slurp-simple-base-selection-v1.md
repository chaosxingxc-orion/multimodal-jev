# Qwen3-ASR 简单 Final60 零训练基座结果

完整 9,226 条 clean SLURP TRAIN 内部选择集已完成直接音频推理、固定镜像评分和
独立原始概率复算。此结果是本工程的零训练控制，不是官方 TEST 学术基线复现。

| 指标 | 结果 |
| --- | ---: |
| 正确 / 总数 | 154 / 9,226 |
| Accuracy | 1.6692% |
| 固定 60 类 macro F1 | 0.0547% |
| 有支持类 macro recall | 1.6667% |
| 失败 / 无效 | 0 / 0 |

模型为本地 Qwen3-ASR-0.6B，BF16、单 Final60 Span、固定候选 argmax；
56 个 LoRA B 矩阵实际核验全零，所以推理等效于未训练基座。输入只含音频与
任务定义，未用转写替代音频。完整预测均为 `qa_definition`，9,226 个候选概率向量
各不相同；平均最高候选概率 0.5563。这说明当前任务读出发生单类塌缩，不能据此
认定模型没有声学信息，也不能把该数值称为随机分类实验。

固定镜像计分测试 30 项通过；评分核对完整输入、实际容器终态、策略身份和
候选映射。另从原始候选概率独立计算全部 argmax、混淆计数及宏指标，逐项一致。
数据发布、模型及原始结果身份见 [机器可读结果](slurp-simple-base-selection-v1.json)。

Stage1 全量指令适配仍在运行。后续使用相同选择集、相同原推理源码/profile 和
指标口径评测最终 checkpoint；本报告不包含训练收益或 RL 收益。
