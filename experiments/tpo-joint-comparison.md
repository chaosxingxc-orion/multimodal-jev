# 联合 TPO 实验协议

JEV-201 验证 Stage1 后接续联合 TPO，JEV-204 验证从基座起步的全量单阶段训练。两者共享直接音频输入、Noul 和 Choice 两套判决接口，以及动态竞争者和固定长期锚。各自使用独立的训练视图、固定参考与包身份。[台账与冻结证据](../wiki/experiment-ledger.md#证据定位)

| 设置 | JEV-201 | JEV-204 |
| --- | --- | --- |
| 初始策略 | 0.6B Stage1 step 160 | Qwen3-ASR-0.6B，任务参数新初始化 |
| clean SLURP TRAIN | 6,248 条冻结视图 | 40,513 条全量 |
| 训练预算 | 两轮，12,496 次真实录音曝光，34 步 | 两轮，81,026 次真实录音曝光，212 步 |
| 批大小、种子 | global batch 384、microbatch 8、seed 317 | global batch 384、microbatch 8、seed 317 |
| 运行布局 | 六卡训练、两张卡分别运行单卡参考实例 | 六卡训练、两张卡分别运行单卡参考实例 |
| 评测 | 第 34 步。Noul 以 197 为主对照，Choice 以 198 为主对照 | step 0、轮末、末点。和两阶段路线比较完整链路成本 |

SLURP 与 MINDS 逐集报告 Top-1 macro-F1、准确率及平均最高候选概率。变长 Choice 面板分别报告有真类时的误拒和真类缺席时的误接，列各自分母。独立话题与词义面板按各自冻结协议报告。两条路线的起点、训练人口和预算不同，比较结果反映路线整体差异。

训练、评测与结论分别更新到 [JEV-201 报告](../wiki/reports/JEV-201.md) 和 [JEV-204 报告](../wiki/reports/JEV-204.md)。
