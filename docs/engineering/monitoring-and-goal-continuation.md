# 训练监听与Goal自动续跑

训练/评测普通监听固定为900秒，由已有脚本执行。模型收到Goal自动续跑消息，
不代表训练监听已到期，也不代表用户新增了分析任务。无到期检查或具体待办时，
不重复查询进程、改写状态记录、分析结果或新增后台任务。

2026-11-15核对：当前会话get_goal返回active；可用目标工具为create_goal、get_goal、
update_goal，没有续跑间隔参数。不能把工程配置中的900秒宣称为模型唤起间隔，
也不能通过反复结束回合或每分钟发送等待消息实现15分钟的模型调度。

官方[长任务文档](https://learn.chatgpt.com/docs/long-running-work)说明Goal进度条
支持暂停、恢复、编辑和清除，但该页未说明设置Goal续跑间隔的方法。
官方[定时任务文档](https://learn.chatgpt.com/docs/automations?surface=app)介绍另一类
定时任务入口；不能据此推断当前Goal是定时任务或其唤起间隔可在同一位置设置。
本次没有查到可直接配置Goal为每900秒唤起的依据。

项目脚本负责确定性执行和状态记录，Goal模式负责用户明确授权的工程、研究与故障任务。
不得为了降低唤起频率而错误标记研究目标完成或阻塞；暂停目标需用户明确要求。
本次没有改动任何任务调度或目标状态。
