# 可配置波形前处理

用户授权在模型输入前采用标准语音处理。`audio_preprocess.py` 提供确定性、直接波形处理，`load_audio` 可返回处理凭证。输入仍为单声道 16 kHz；原始文件不改写。

顺序固定为首尾静音裁剪 → speed perturbation → preemphasis → 带上限 RMS 增益。默认空配置保持 float32 波形逐字节一致。首尾裁剪按 20 ms RMS 帧阈值并保留边界 margin，**不是语义 VAD**，不移除句内停顿；全静音保留原长。preemphasis 实现 y[t]=x[t]−αx[t−1]，首样本不变。RMS 增益以整段波形计算，最大增益受限并进行峰值保护，不称为感知响度归一化。

当前语速变换用 scipy resample_poly，在固定输出采样率下改变时长，也会改变音高，不称为保音高 tempo。仅作为明确的增强/鲁棒性配置。后续若需保持音高应另加独立算法和对照，不隐式替换。

六个单因素候选位于 `configs/audio/preprocessing-v1.json`，均未被选为最佳配置。Span SFT 可用 `audio_preprocessing` 字段，保存原始/处理后波形哈希、样本长度、裁剪区间及实际增益；重载 verifier 重用相同配置并验证 receipt。静音对照用处理后的长度，避免比较不同长度。所有后端必须使用同一配置及处理后波形/特征，不能仅给 actor 加增强而 rollout 使用原始音频。

48 条学习录音波形审计全部通过：raw 173.691 秒且 0 条变化，首尾裁剪阈值 −45 dBFS、margin 100 ms 后 164.583 秒、39 条变化；0.9/1.1 speed 后分别 192.9913/157.9024 秒。只说明变换执行正确，没有模型准确率证据。详见 audio-preprocessing-audit-v1.json。

训练增强与固定推理前处理分别规划；尚未启用随机增强或测试集选参。当前均衡分类调试轮保留 raw，防止同时修改多个因素无法解释。
