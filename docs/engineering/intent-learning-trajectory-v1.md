# 完整学习曲线的面积与退化统计

2026-11-12 UTC。为落实持续RL改善协议，在现有逐点D/Q/P比较中增加
`trajectories`：末点相对起点、各相邻点改善/退化/持平次数、低于起点的
检查点数，以及按累计来源使用次数积分的曲线面积。NLL使用负方向计算收益。
这不会选择最佳检查点，也不产生显著性或独立泛化结论。

面积采用全部观测点间的梯形插值，归一化分母为当前已观测来源使用次数。
它是检查点之间的描述性插值，不代表未观测中间策略的真实分数。来源重复
使用不计为新增独立样本，来源使用次数也不是算力。仅有起点时归一化面积
为null；不完整连续前缀明确标记complete=false，不与完整预算混报。

实现位于`src/multimodal_jev/intent_learning_trajectory.py`，开发版
`compare_intent_matched_pilots.py`在原完整独立验收后增加三臂轨迹汇总，并
将新增模块纳入输出哈希。已运行控制器的冻结源码没有修改；其原报告仍会
按旧格式生成，完整三臂完成后可用开发版另外生成不可覆盖的新版本报告。
