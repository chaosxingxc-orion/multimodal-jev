# 原生意图有限候选更新的独立验收准备

2026-11-12 UTC。首轮D意图训练的后置验收已冻结源快照和config-template，尚未创建或启动容器。准备位置、镜像、启动参数和哈希见同名JSON；训练入口仍使用此前不可变快照，不原位修改。

`freeze_intent_finite_acceptance.py`要求确切训练容器在固定镜像上实际退出0，四rank均成功，再绑定导出adapter、真实optimizer分片、训练输入和源码哈希。既有创建尝试或最终config均禁止覆盖。冻结前验证全部pin经Docker挂载后的实际文件；完成冻结不等于已派发或验收成功。

`run_intent_finite_acceptance.py`串行执行独立HF与vLLM TP1的全部178个D/Q请求，再调用实际四rank状态审计。最终ACCEPTED只在两阶段均成功后写入；外部控制器仍须检查实际容器退出码、controller终态和验收文件哈希。

新增`intent_gate_identity.py`从已审核发布重建全部D/Q请求，核对CPU processor产物、请求哈希、策略身份、音频处理、候选顺序及张量身份，防止两后端一致地运行错误任务却通过概率一致性验收。该检查覆盖完整178输入，训练8条另要求FSDP更新后概率与独立HF重载一致。它不重新证明音频语义标签正确，不把学习集提升当独立任务收益。

本地测试覆盖非训练请求被篡改并重新计算哈希、旧策略、候选顺序、音频/张量身份、非法概率、重复/缺失请求，以及训练仍运行、退出失败、单rank失败、重复冻结等情况。实际新验收流程尚未在NPU执行，CPU单元测试不能代替后端验收。
