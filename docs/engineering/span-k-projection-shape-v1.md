# 第0层 K 投影输出宽度诊断

在固定镜像、物理NPU4、关闭internal format条件下，使用真实首条语音的
第0层input norm输出[600,1024]和原始BF16 K权重[1024,1024]进行离线计算。
K未加LoRA，四rank记录的输入与HF输入逐位一致。输入仅用于离线诊断，
未替换任何在线推理的中间状态。实验容器退出0。

| 计算 | 与HF K输出差异 |
| --- | --- |
| 完整输出宽度1024，重复3次 | 每次逐位一致 |
| 四个输出宽度256的矩阵乘法再拼接，重复3次 | 每次20/614400个元素不同，最大误差0.00048828125 |
| 切片计算与真实TP4 trace比较 | 逐位一致 |
| 各切片补零至原输出宽度1024，再选取对应输出 | 与HF逐位一致 |

该受控对照复现了真实TP4最早观察到的K投影偏差，支持输出维度改变导致
矩阵执行数值路径不同的解释。它不确定底层具体采用何种kernel/tiling，也不证明
Q/V、其他层、其他形状同样可由这一措施解决。没有LoRA或输入差异参与这个K对照。

补零路径只用于辨别原因，会增加计算/临时存储，尚未作为全模型修复方案。
完整输入维度投影已减少后续归约误差，但现有TP4仍未通过全候选概率gate。
下一步评估保持矩阵运算形状的诊断干预及成本，不能用单层精确结果宣称全模型一致。

脚本 `tools/jev/probe_span_projection_shape.py`固定输入/权重/源码pins，保存实际输出张量。
主进程独立复核pins、终态、tensor哈希并重算全部逐元素差异与重复性。
证据：`span-k-projection-shape-v1-launch.json`、`span-k-projection-shape-v1-verified.json`。
