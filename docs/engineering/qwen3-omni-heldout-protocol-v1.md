# Omni候选选择后的完整FSC测试协议

在Omni候选返回、选择集和TEST推理前登记。适用于当前冻结
Qwen3-Omni-30B-A3B-Instruct，沿用固定模型revision、NPU镜像与任务发布包。

## 进入条件

教师完整响应只产生待审候选。候选必须保持动态schema、候选ID绑定、
Noul命题真值和null语义；不得嵌入样本答案或FSC命令专属规则。
语义审查不读取选择集或TEST输出。审查合格候选与原提示全部登记后，
在既定256个TRAIN选择组上完整运行，并按已登记六视图/配对排序选优。
不依据部分选择结果提前停止较差候选，也不因选优结果追加教师调用。

## 测试范围与对照

- 使用同一FSC-Jev发布包的官方TEST全部3793录音×6视图，共22758请求。
- 比较原提示与唯一选定提示；若选中parent，不重复运行相同提示制造独立样本。
- 两个条件使用相同推理实现、模型、输入、采样参数和严格解析器，仅提示不同。
  选择阶段之后不可改变上下文长度、输出预算、围栏解析或候选语义。
- 原始输出、请求绑定、token与截断情况全部保留。容器、应用、评分成功终态
  和前后模型文件哈希均须通过。运行中断保留成本与部分证据，不生成全量成绩。

## 报告口径

原生joint intent与学术FSC任务表对应，但区分冻结基座和FSC监督训练权重。
派生五种视图单列，不能与论文native数字混为一个总准确率。
主报告包含六视图各自的严格正确率、四项配对正确、六视图全对、格式合法率、
schema合法率和截断数；不删掉难视图、不用宽松解析替换主成绩。
比较按同录音对齐，报告修复/退化数和all-six组级变化。派生视图相关，
不把22758请求当作独立录音计算显著性。TEST不进入教师或候选筛选。

## 与跨任务结论的关系

当前原生SLURP和SLURP-Jev小探针使用原提示，只是工程与任务行为验证。
它们不是FSC提示迁移结果。后续迁移比较需把选择完成的提示固定，采用
匹配的Jev输出合同，并在独立SLURP划分完整比较原提示和选定提示。
原生SLURP复合输出与Jev单value输出不同，不能直接把FSC提示替换后
将合同冲突算作泛化失败，或偷偷加任务专用提示修补再宣称零样本迁移。
