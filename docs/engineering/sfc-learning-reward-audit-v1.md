# SFC-Jev 完整 learning 奖励分布审计

`audit_sfc_learning_rewards.py` 接受固定的 learning shard plan 与 SHA256，
从完整 input-only TRAIN release 重现原始分区和分片计划。
只在原始请求属于 learning 时解析同位置 target 行并调用严格奖励函数；
selection target 行跳过，不解析、不评分，TEST target 文件不打开。
整个 TRAIN target 文件仍需哈希以绑定原始 release，因此不能宣称未读取任何
selection 字节。测试特意将 selection 行替换为不可解析内容并更新文件身份，
验证该分支没有依赖 selection 标签。

覆盖原始 learning 的全部 3,600 会话、4,428 bundles、69,210 决策。
标签仅用于离线审计，不进入模型提示；不调用模型或教师、不训练权重。
每个 bundle 使用同一严格 scorer 评估四种固定人工输出：oracle、全部空调用
并保持正反 Noul 一致、所有决策输出 false、所有决策输出 Markdown 包裹内容。
三元组 bonus 固定为 0.2；此工具不搜索或选择奖励权重。

结果包括按原始 level 的 active/inactive 函数数、无调用 bundle 数、函数数量直方图，
以及四种人工策略的完整原生任务正确数、全决策正确数、三元组正确和逻辑一致数、
active/inactive 分层的决策正确率分子分母。总奖励、逐决策平均与逐 bundle 宏平均
分别保留，避免把函数数不同的样本混成同一种加权方式。

这些是标签分布和奖励行为证据，不是实际模型退化率、RL 效果或跨任务泛化。
不能从六条工程样本的 17/26 无调用比例直接推断完整 learning 分布；
完整结果必须由本次审计覆盖校验后报告。

测试覆盖完整 learning、拒绝 selection/TEST 计划、target 漂移、selection 行不解析，
并联跑原始奖励、merge 和反馈测试，共 50 项通过。

## 完整结果

审计成功结束，证据见 [结果记录](sfc-jev-learning-reward-audit-v1-result.json)。
全部 3,600 个会话、4,428 bundles、69,210 决策已覆盖，23,070 个函数中
active=6,085、inactive=16,985（73.6238%）。所有 bundle 至少有一个真实调用，
无调用 bundle=0。

| 固定人工策略 | 总奖励 / oracle 总奖励 | 完整原生任务正确 | 逻辑一致函数 | 正确函数三元组 |
| --- | --- | --- | --- | --- |
| oracle | 100% | 4,428 / 4,428 | 23,070 | 23,070 |
| 全空调用 + false/true | 73.6238% | 0 / 4,428 | 23,070 | 16,985 |
| 所有决策 false | 0% | 0 / 4,428 | 0 | 0 |
| 所有输出 Markdown 包裹 | −83.3333% | 0 / 4,428 | 0 | 0 |

全空策略在 active 决策上 0/18,255 正确，在 inactive 决策上 50,955/50,955 正确。
其按 bundle 宏平均奖励为 0.8434146，oracle 为 1.2；与逐决策加权的 73.6238%
奖励比例不同，报告时不得混用。所有决策 false 的总分为零，是正确的一个 Noul
端点与格式无效的 calls 惩罚相抵，不代表每项都正确或没有错误。

分层标签计数：level_1 为 2,118 active / 10,590 inactive；level_2 为
1,319 / 2,415；level_3_1 为 716 / 1,920；level_3_2 为 1,932 / 2,060。
这解释了简单 level_1 占比较高时总奖励尤其容易掩盖真正的调用失败。

设计后果：保留本版单题/三元组奖励为可追溯对照；在正式优化前另登记
active/inactive 平衡和完整 bundle 成功奖励的消融，比较实际梯度信号及样本效率。
标签统计本身没有证明哪种改法更优。全局平衡最多改变空策略的相对贡献，
不会自动提供完整任务成功信号；仅用稀疏 bundle 奖励又可能导致全零优势。
需要在相同采样与预算下验证，不能把任意重新加权称作已解决奖励投机。

本 learning 集合缺少整条无调用请求，不能单独支撑“对无需执行的请求正确拒识”
的能力结论。FSC 缺候选诊断同样不能替代真实声学/业务未知；需独立、预登记且有
可靠标签的未知/无需动作任务。当前不修改官方标签，不合成未经核验的语音负例。
