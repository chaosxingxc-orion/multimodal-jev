# Stage2 正确候选概率间隔目标（待验收）

用户确认：以正确 label 的概率减去所有错误 label 中最大的概率，而不是预测 top1/top2 的无监督差值。仅适用于当前可信单意图 TRAIN 监督；缺失/不可信标签不生成负例。

令 `p = sigmoid(z)`，`g = p[gold] - max(p[not_gold])`，增加 `L_margin = relu(M - g)`。`M` 与 `margin_coefficient` 必须在可编辑目标配置中显式给出；`0 <= M < 1`，关闭权重能够复现原候选。达到间隔后此项梯度为零；未达到时提升正确候选、压低最强错误候选。概率已经错误饱和时 sigmoid 梯度较小，保留现有 BCE-with-logits 的纠偏路径，不用 margin 替代它。

现有奖励非负并不表示没有负梯度。GRPO 组内中心化对低于均值的样本给负 advantage；整组奖励相等时无相对梯度。仅给奖励统一减常数在中心化后抵消，不能作为新增惩罚收益。新增惩罚若有需要，应针对错误集合/错误置信度定义可区分行为的代价，先在 TRAIN 诊断。

需记录：正/负/零 advantage 数量、零方差组比例、负 advantage 的 clip 比例、正确概率与最强错误概率、间隔达标率、margin loss，以及准确率、NLL、Brier、完整集合指标。测试与迁移集不用于选择 M 或权重；选择集只用于既定候选筛选，不作为奖励和调参反馈。

本项属于下一阶段 Stage2 的版本化可编辑目标；当前 Stage1 保持纯 InfoNCE。尚无本项 NPU 效果结论。
