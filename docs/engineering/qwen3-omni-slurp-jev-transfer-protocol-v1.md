# FSC 提示向完整 SLURP-Jev 的迁移协议

本协议在FSC选择集完成之前登记，不依据部分选择结果或SLURP TEST结果改提示。
迁移对象是冻结Qwen3-Omni上的任务指令，不是已训练权重或RL算法收益。

## 提示与输入

原提示直接使用FSC选择协议中parent的原始字节，候选使用全部选择评测完成后
选出的唯一提示，二者只改动态任务schema。选中parent则只运行一个条件。
parent虽未显式提及open_slots，但动态schema完整提供类型与问题；不事后为
parent或候选补写列表指令。解释结果时必须披露这一差异，不能仅将列表格式
改善解释为语义推理或强化学习提升。

此前SLURP-Jev TRAIN探针采用支持列表的另一条原提示和256输出token；它是
工程诊断，不能充当此迁移比较的parent，也不与本协议结果直接计算收益。
教师只使用FSC固定64组TRAIN反馈；不读SLURP输出来修订迁移候选。
已查看SLURP TRAIN工程探针，因此称“FSC反馈优化的跨数据集提示迁移”，
不声称整个工程设计从未接触SLURP。

## 评分和泛化结论

分别报告意图native/permutation/rebind、成对全对、实体present/absent
配对全对、全部/非空/多值列表精确匹配、格式与schema合法率、输出截断。
重建原生输出使用固定官方SLURP评分器；非法必需输出按已有规则记失败，
不以参考答案补齐。常数false、全部空列表的退化对照只使用评分夹具。

parent与选中提示按同录音同问题对齐，报告修复/退化。语义组内多录音、
单录音168问题均相关，不以2197104条独立样本计算显著性。不得把大量
不存在实体的问题造成的微平均优势描述成完整SLU或跨任务成功。

本协议不替代原生SLURP完整TEST，也不替代历史domain-held-out/first-slot
数据的域迁移实验。完整学术基线复现与后续verl权重训练仍是独立未完成工作。
