# SFC 类别奖励权重与 GRPO 归一化

完整 learning 审计发现 active=6085、inactive=16985，共 23070 个函数。
全空调用策略获得原三元组奖励的 73.6238% oracle 总分，却完成 0/4428 个任务。
本次不修改已实现奖励，也不读取新的标签；复用已固定的完整 learning 审计哈希
`65475f49ff795714ab978c25e5e39826b737eb89b0a93ab398c1564925ddc1ba`，
分析简单逆频率权重在实际 verl 优势函数中的行为。

## 公式和数值证据

以类别总质量相等、总体平均权重为 1 定义：

`w_active = 23070 / (2 * 6085) = 1.8956450`

`w_inactive = 23070 / (2 * 16985) = 0.6791286`

原始全空策略的奖励占 oracle 比例因此在算术上变为 50%。
这仅是离线奖励质量重新分配，不证明实际优化信号已改变。
对同一 prompt 的 K 个响应，gold activity 固定，所以 w 是组内常数：

`(w*r - mean(w*r)) / (std(w*r) + eps)`

等于 `w*(r-mean(r))/(w*std(r)+eps)`。正权重在标准化中基本抵消，
残留仅由 eps 和有限精度造成，不能用来宣称达到了类别平衡。

固定镜像真实 `compute_grpo_outcome_advantage` 的 CPU 检查使用 K=4、四个
合成奖励组，含正确、错误、格式惩罚、schema 惩罚、三元组 bonus 和全等组。
16 个响应含不等 token 长度和 padding。结果如下：

| 优势处理 | 先乘类别权重后计算优势，与原优势的最大差异 |
| --- | ---: |
| 仅组内中心化 | 1.1419473 |
| 组内中心化及标准差归一化 | 0.0000007153 |

仅中心化时，先乘奖励与后乘优势最大差异 2.38e-7，符合线性关系。
标准化时，先乘奖励与后乘优势最大差异 1.1693367，明确不等价。
全等组优势和所有 padding 位置均为零；没有人为制造全等组探索信号。
精确容器、源码与数值见 [result](sfc-reward-balance-numerical-v1-result.json)。

## 对算法消融的约束

不能把“类别权重乘在奖励上 + 原样标准化 GRPO”当成已实现类别平衡的独立算法。
后续可比较两条明确不同的路径：

1. 仅中心化，类别权重乘完整 outcome reward；记录整体奖励尺度及学习率交互。
2. 先计算标准化优势，再给各 prompt 的 policy-gradient 项乘类别权重；
   这是带权策略目标，需显式定义 token/response/bundle 的分母与微批聚合。

第二条不能无说明地给 KL、熵或其他正则项同样加权；必须固定这些项各自的权重。
函数数量不同、响应长度不同以及 clipping 会使实际梯度贡献不等于原始类别质量。
因此 50% 离线 reward 占比也不保证 50% 梯度贡献或完整任务成功率提升。
所有候选仍保留 independent 和 function-conjunction 原始对照，比较同一采样/预算。
稀疏完整 bundle 奖励可能改善目标一致性，但全零优势问题需实际采样检查，
不能由该数值探针决定采用，更不在本轮修改奖励或派发权重训练。

本实验是完整学习分布计数加合成奖励数值验证，没有真实模型响应、梯度、
学习收益或跨任务泛化结论。没有读取 selection/TEST 标签。
