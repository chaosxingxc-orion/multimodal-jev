# Intent RL 探索归档（2026-11-12 前后）

本文件收编早期“原生意图有限支持 RL”家族。原始 md 已移入 `archive/raw/intent-rl/`，
逐次训练/验收 JSON 收据仍在 `docs/engineering/` 原名保留。

## 做了什么

在 SLURP 89 条独立学习来源上，以原生意图候选做小预算多步更新，比较三类信号：

- **D**：直接 Final 判决。
- **Q**：增加可迁移语义问题，但只用 Final reward。
- **P**：在 Q 输入上增加过程 reward。

配套工程包括四卡 DP4 连续更新、BF16 导出重载、178 输入 HF/vLLM 概率 gate、
来源日程和逐步独立验收。

## 有效结论

| 观察 | 结果 | 边界 |
| --- | --- | --- |
| D 十二步 | 13 个检查点 Final 均为 1/89；预测类别数始终 1；NLL 6.24040→5.73107 | 概率改善未跨过分类边界；约一遍学习人口的短程探针 |
| Q 十二步 | 末点 3/89，相对起点净增 2 条；3 次上升、2 次下降、7 次持平；全部 12 点 NLL 仍差于起点 | 无独立开发集、跨 seed 或 P 过程奖励证据；不能宣称可靠持续收益 |
| Q−D | 同预算下 Q 末点比 D 多 2 条正确 | 输入长度与成本不同；单 seed、学习人口内 |
| 工程链路 | 连续恢复、BF16 导出、HF/vLLM 概率一致通过；最大 logprob 误差约 9.54e-7 | 工程通过不等于任务收益 |
| 过程/关系信用 | 有局部概率方向改善，但无稳定 Final 提升 | 不能把 reward 或正确概率上升当作分类改善 |

**结论：意图有限支持 RL 工程链路可用，但没有形成持续、可复现的分类收益；存在预测塌缩和常假退化。**
后续主线转为 `context-prob-v1` 的全量 SLURP clean 60 意图成员判决；本家族不再作为当前训练分支。

## 失败/过期路径

- 按单步或末点挑选“概率更好”的检查点：不作为成功证据。
- 把 Q 的 3/89 当作多跳推理或过程信用收益：无独立开发与跨 seed 支持。
- 旧的 89 条学习人口与 178 输入 gate：只适用于当时冻结实验，不是当前全量人口。
