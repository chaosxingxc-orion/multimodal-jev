# 有限候选信用的原生 actor 四进程验证

2026-11-12 UTC。新模块 `span_finite_actor.py` 将完整请求的边缘候选概率、优势和积分权重放入真实 verl DataProto；原生 actor 负责微批、梯度累积及 Adam 更新。单行候选补齐至同一宽度，补齐列积分权重为0，模型不消费占位token。标签不进入模型输入。

四个Gloo/DDP进程每步共8请求，覆盖60类、六个Boolean、60/2/5混合候选。各rank有效请求权重为1、7、0、15；全局分母23。比较microbatch 1和2，各连续两次更新，逐项对照全局显式有限支持参考目标。

- 梯度最大绝对误差1.4901161193847656e-8。
- 参数最大误差2.9802322387695312e-8。
- Adam一阶/二阶矩最大误差1.6298145055770874e-9 / 2.7284841053187847e-12。
- 故意使用rank局部归一化时，梯度误差至少0.05906，负对照可区分。
- 单rank修改mask、旧概率或积分权重，全局错误分母及重复请求，均在模型collective前被所有rank拒绝。

固定镜像容器退出0，未映射NPU、非privileged，源快照只读；所有源哈希及当前新增实现与快照一致。见同名launch/verified JSON。真实NPU、BF16、音频、Ray调度和任务收益尚未由本实验验证。此路径限制每个新行为批次一个optimizer minibatch/epoch；本探针不证明旧数据多轮PPO复用。
