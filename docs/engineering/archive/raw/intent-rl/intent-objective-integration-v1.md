# 简单Final奖励候选：目标身份、训练入口与验收接入

2026-11-12。本轮修改开发源码；既有冻结D/Q/P及控制队列继续使用原快照。
没有新增NPU派发，没有平滑效用的真实语音训练或收益结论。

配置通过`objective`明确指定优化目标：默认或显式`correctness-v1`；
单Final D支持`smoothed-utility-v1`，固定tau=1/K²；另支持
`uniform-credit-v1`及预先登记的固定scale，用于区分信用重分配和统一尺度效应。
未知字段、隐式调tau、结构臂误用及非法scale拒绝。控制scale尚未为NPU实验选定。

训练入口在旧概率与监督认证后、四rank拆分之前转换信用，并写入objective.json。
模型输入、行为概率、来源日程、分类均衡请求权重和全局有效分母保持不变。
每个rank输出优化目标身份。恢复必须保持相同目标，显式目标的前驱验收必须包含
目标身份及被哈希认证的信用/监督文件。推理策略身份与优化目标身份分开记录。

独立验收从已接受旧策略概率与发布监督重新构造信用，核对训练实际保存权重，
拒绝仅修改receipt来伪造目标的情况。此处的目标一致性仍不等于模型执行轨迹
完全验收；新候选须另跑真实NPU更新、精确恢复和完整HF/vLLM检查后才可准入。

输入变换新增重复请求、请求权重、tensor设备及变换后有限性约束。
缺标保持无监督；全批缺标的有效分母仍由原生actor批准入拒绝。
测试覆盖非法输入、目标切换、恢复证据缺失、权重篡改和旧概率变化。
合成四rank探针通过与训练入口相同的objective dispatch进入原生verl actor，
以独立非线性效用梯度比较两步更新、microbatch1/2、混合候选及整卡缺标。
精确运行记录与误差见`intent-objective-cpu-v2-verified.json`。

前版平滑效用v1证据对应当时源码，原快照在共享实验根目录的source下保留；
本轮修改后的开发源码不得冒称与前版文件哈希相同。
