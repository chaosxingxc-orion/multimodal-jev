# 第二、三步Adam更新方向诊断

2026-11-12 UTC。读取已独立验收的step1/2/3四rank FP32 master与Adam状态，在固定镜像的无设备CPU容器中运行。容器`67b2e7d9d5fd8898102625fc61c6a6f4ed27a7ef83e4cb1b1eb1a07af968b219`实际退出0，输入哈希和内部终态均核对通过。结果见`intent-adam-direction-step23-cpu-v1-verified.json`。

工具`diagnose_intent_adam_direction.py`利用一阶矩关系重建已裁剪梯度`g=(m_new-beta1*m_old)/(1-beta1)`，以实际FP32 master差作为位移delta。按照当前Adam二阶矩和bias correction，将预测位移分成历史动量项与当前梯度项，求它们各自与g的内积；四rank按真实FSDP分片合计，不把分片norm取平均。当前只有一个参数组、weight_decay=0、非AMSGrad、非maximize；其它优化器不套用此推导。

更新2在当前梯度的一阶近似下为下降方向；更新3的历史动量反向贡献超过当前梯度下降贡献，实际位移为当前损失的一阶上升方向。这比仅观察reward下降更具体，但仍不能证明它解释全部有限步BF16概率变化或泛化退化。梯度是从FP32矩重建的近似，未冒称直接保存的反向梯度；二阶矩递推最大残差约1.05e-12，位移重建最大误差约1.86e-9。内置合成Adam反向动量案例使用已知直接梯度验证内积、方向和位移误差，并验证非连续步数拒绝。

第三步日志未裁剪梯度norm0.08388065与重建norm一致；第二步原norm1.80557被grad clip=1裁剪，重建norm接近1。第三步D自然分布batch和全89来源的正确概率下降，与当前损失一阶方向异常相容，但这些观察不等于参数级因果对照。

对后续实验的影响：保留已冻结D/Q/P及较低学习率对照。固定同一状态和梯度时，降低lr缩小Adam位移但不改变其方向；所以不能承诺lr2e-5一定解决第三步的方向问题。若较低lr对照仍无法学习，再单独检验beta1/动量策略或具备精确master/Adam回退的更新后接受条件，必须从相同起点另开协议，不在当前曲线中清空Adam或修改奖励。当前没有实现或派发新的动量消融。
