# 类别加权策略损失与微批梯度

本探针继续检验 GRPO 类别权重的实际作用位置。使用固定 learning 计数得到
active=1.8956450、inactive=0.6791286；不读取 selection/TEST，不修改当前奖励或训练配置。
固定镜像中的真实 verl `compute_policy_loss_vanilla` 包含 PPO clipping 和 dual clip。
源码哈希与精确容器见 [数值结果](sfc-weighted-policy-loss-v1-result.json)。

## 可检验的目标

设每个响应的标准化优势为 A，类别权重 w>0，比例为 rho。
真实损失的 max/min 分支对正比例缩放保持齐次性，因此把 w 乘在 A 上，
等价于将最终裁剪后的策略项乘 w，且保留优势正负号及裁剪分支。
这不同于先乘奖励再组内标准化；后者会抵消组内常数权重。
该等价只针对此策略项，不自动包含 KL、熵或其他正则项。

同时检验两个明确不同的目标，分母均不包含类别权重：

- token 平均：所有有效 token 的带权策略损失总和 / 有效 token 总数。
- 响应平均：每个响应先按自己的有效 token 数平均，再对所有响应平均。

权重固定来自完整 learning，不在每个微批重新估计或归一化。
响应平均使长 calls 输出不因 token 数多而自动增加整体权重，但不是完整 bundle 平均；
一个 bundle 含更多函数时仍贡献更多响应。采用哪一种是独立算法选择，尚未部署。

## 实测

16 个人工响应、46 个有效 token、K=4，覆盖正负优势、等分组、上下裁剪及 dual clip。
两个可微标量只用于构造 logprob 扰动，没有模型、优化器或参数更新。
独立逐 token 公式与真实 verl 的梯度对比如下：

| 目标 | 完整梯度最大误差 | 全局分母微批累计误差 | 错误局部平均的梯度误差 |
| --- | ---: | ---: | ---: |
| token 平均 | 7.45e-9 | 7.45e-9 | 0.07483 |
| 响应平均 | 1.49e-8 | 2.24e-8 | 0.09591 |

微批大小刻意设为 3/7/6。每片使用完整批次的 token 或响应分母后求和，
无需再次除以微批数。若采用原生 worker 自带的梯度累计缩放，接入时须补偿一次，
不能直接将本探针的裸 loss 累计方式当作已验证 worker 更新。
两种分母产生的梯度最大差异为 0.03807；加入类别权重的梯度变化分别为
0.05391 和 0.02740。反例表明分母和权重确实改变目标，并非重复计算同一算法。

## 接入限制

原有 `jev_static_token_mean_v1` 仅验证单 rank、单 epoch、token 平均，
不能据此声称已支持分布式 Omni 或新的带权训练。
类别标签只进入奖励/优势构造，不作为 actor 输入，也不替代 rollout importance weight。
未来须在完整 K 组上先算优势，再按同一响应身份施加固定权重；如启用 KL/熵，
分别声明其目标与分母。实际采样、模型梯度、完整任务收益和跨任务泛化仍待验证。

## 显式响应平均适配

源码 `6153ec9` 新增独立注册项 `jev_static_response_mean_v1`，保留原 token 平均项。
每个响应先按有效 token 数平均，再使用完整批次响应数作为分母；适配器补偿原生
静态 worker 的 gradient accumulation 除数一次。调用者须先在完整 K 组上计算优势，
再施加正类别权重，分母不改为权重之和。仅接受单 rank、单 epoch、单个完整可整除
静态 minibatch，明确拒绝 KL、熵、动态批处理与 rollout importance weights。

33 项本地准入/注册测试通过。固定镜像真实 verl 损失检查使用 12 个合成响应，
覆盖不等长度、正负优势、零优势组及 PPO/dual clipping，分别按 1/2/3/4/6/12
微批大小累计。六种条件对独立公式的梯度误差均为 0；token 平均与响应平均的
梯度差 0.16180456，去除合成类别权重的差为 0.08050784，反例具有区分性。
该检查手动复现原生累计除数，未调用 actual actor update_policy、优化器或模型。
这不是已完成的真实模型微批更新或分布式验证，也没有部署到现有运行队列。
