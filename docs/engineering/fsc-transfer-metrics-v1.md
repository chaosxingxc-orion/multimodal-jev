# FSC配置迁移的配对评分

2026-11-12 UTC。新增`fsc_transfer_metrics.py`，固定同一音频名单在direct/structured × native/permutation/rebind六个视图的完整概率输入。gold只进入评分端；每条模型请求根据音频与已冻结配置重新编译，核对请求、音频哈希、策略身份、完整候选支持和归一化概率。配置及名单哈希随报告保存，跨checkpoint比较拒绝任一变化。

主指标为31联合命令Final准确率，附正确类概率、NLL、Final组件正确率；structured另报过程组件正确率和Final兼容率。过程组件不修复Final。重排/重绑定同时报告两视图均正确率和语义一致率，避免一致地答错获得虚假鲁棒性结论。

跨checkpoint按逐样本记录核对同名单、gold和说话人；同时复算聚合值，拒绝过期摘要。固定模板下的差异衡量模型更新，固定模型下的direct/structured差异衡量模板，两者交互单列。共享说话人bootstrap抽样同时用于全部视图，报告utterance-weighted差异及交互的95%百分位区间，固定seed941、2000次。该区间不涵盖跨训练seed波动、跨说话人的重复命令依赖或多重比较；不是因果推理机制证明。

17项相关测试通过，覆盖缺行/重复、配置/策略/音频变化、非法概率、错绑、组件不能修复Final、旧摘要及单说话人区间拒绝。另对31个本体命令×6视图构造186个合成oracle概率案例，重排语义保持、同策略差异和2000次聚类区间均符合预期，见`fsc-transfer-metrics-fixture-v1.json`。这些都是软件控制，不是真实FSC模型成绩；没有读取目标语句标签训练或选模板。

后续实际调用还需由外层工具核实官方划分、目标标签/音频身份、两后端验收、源域checkpoint选择规则。该模块不会自行授予数据集或模型准入。当前真实FSC仅完成12条TRAIN音频的72输入CPU检查，尚未开始模型推理或迁移评测。
