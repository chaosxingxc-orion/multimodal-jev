## 一次派发与验收

每个 Docker dispatch 前 fsync 持久化意图；SSH 返回不明、执行失败或已有意图时均不重放。
观察只轮询同一个完整容器 ID，保存容器终态、日志及应用终态。

采样成功后由监督进程读取原容器 Docker inspect 并保存哈希，再启动无 NPU 设备、
无网络、CPU2/12GiB 的固定镜像验收容器。验收镜像加载实际 tokenizer，读取这份
受信协调器捕获的 Docker 终态，执行全部 156 条记录的独立校验。
验收后协调器再检查原容器身份与终态，核对 acceptance 的采样容器和 result 哈希。
该模式不把任意上传的 inspection JSON 当成外部信任根。

source、配置、完整 CPU preflight 和依赖证据均在不可变快照中绑定。
实际预检代码与队列源树中共有的模块逐文件相同；新增验收/队列模块不冒充已执行预检。
