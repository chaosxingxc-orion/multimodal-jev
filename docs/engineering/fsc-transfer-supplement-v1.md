# FSC迁移补充报告：分类覆盖与模板收益区间

2026-11-12。新增独立工具`tools/jev/summarize_fsc_transfer_matrix.py`，
保留既有冻结矩阵、主评分器和已排队源码快照。
补充工具重新调用完整矩阵认证入口，核对实际Docker退出、HF/vLLM完整gate、
源域检查点选择规则及协议身份后，才读取目标标签并计算补充报告。
缺一个矩阵成员就失败，不以部分结果筛选检查点或修改模板。

新增输出：

- 每策略/视图的观测类macro-F1、完整31类macro-F1、观测类macro-recall、逐类支持与正确数。
- 每位说话人的正确数、录音数和准确率；整体仍按录音加权。
- 过程全部正确与Final正确的四种组合，以及过程全对条件下的Final准确率。
  条件人口为空时为null；不能用组件拼接修正Final。
- 每个策略的structured减direct模板增益及配对说话人聚类95% percentile区间。
  seed941、2000次；所有策略和视图共享说话人抽样，不将六个视图当六条独立录音。

原评分器已提供同模板跨检查点增量及权重/模板交互区间；补充模板区间不取代它们。
若所有策略的模板收益都相同且权重前后没有变化，只能说明模板作用，不能称RL迁移。
只有10位FSC测试说话人，区间还不覆盖训练种子、跨说话人的重复命令依赖或多重比较；
不能将探索性区间当作普遍有效性的确认。

27项测试通过：已有矩阵和输入身份约束，加上语义分数篡改、过程条件、缺失类、
模板单独获益与不均衡说话人反例。9条同说话人受益、1条另一说话人不变的合成例，
点估计为0.9而不是0.5，聚类区间覆盖[0,1]，用于区分错误的独立录音bootstrap。
这些是软件控制，不是模型迁移结果。没有读取真实FSC TEST标签或开展新的目标推理。

完整矩阵完成后的调用方式：

```
.venv/bin/python tools/jev/summarize_fsc_transfer_matrix.py \
  --protocol <已冻结的完整矩阵protocol.json> \
  --protocol-sha256 <原协议SHA256> \
  --output <新的补充报告路径>
```
