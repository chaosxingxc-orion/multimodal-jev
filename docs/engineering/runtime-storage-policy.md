# 运行时持久化规约

适用于本工程的新训练、推理、教师调用、数据加工与诊断任务。2026-11-13起执行。
175/181已确认同一Ceph内核fsync空指针故障，详见
[故障分析](host-ceph-crash-20261113.md)。本规约缓解应用触发风险，不替代内核修复。

## 写入边界

1. **禁止在尚未修复的175/181上把Ceph作为运行时可写状态目录。** 包括checkpoint、
   优化器、请求意图/响应账本、临时JSON、锁、进度、日志、编译缓存和临时文件。
   约束覆盖Python及其底层库，不限于显式`os.fsync`。
2. 此阶段应用不得对Ceph上的文件或目录调用`fsync`、`fdatasync`，不得使用
   `syncfs`/全局`sync`作为替代，也不得改用`O_SYNC`/`O_DSYNC`绕过边界。
   降低同步频率不是正确性修复；普通共享写入仍可能间接走有缺陷的内核路径。
3. 热状态必须在经实际挂载检查的本地持久盘（ext4/xfs/btrfs）上。共享路径的软链接、
   bind mount或改名不算本地化；tmpfs与未经核验的容器overlay不能作为恢复依据。
   模型、音频、稳定前缀特征缓存、冻结源码和发布数据可直接从 Ceph 读取。宿主共享挂载可写不影响只读消费。训练容器对这些资产使用 `:ro` 挂载。
4. **本地关键提交保留同步语义。** 需要崩溃恢复的文件采用同文件系统临时文件写入、
   flush、文件fsync、原子rename、父目录fsync；提交完成才发布成功状态。
   不允许全局替换/monkey patch `os.fsync`为空操作，不把Python flush等同于持久化。
   不需要逐条可靠性的进度日志可批量刷新，但恢复账本与checkpoint必须另行定义提交边界。
5. 启动前显式指定本地`TMPDIR`、`XDG_CACHE_HOME`、`HF_HOME`、
   `TORCHINDUCTOR_CACHE_DIR`、`TRITON_CACHE_DIR`；核验默认`HOME/ascend/log`及
   显式`ASCEND_WORK_PATH`、`ASCEND_CACHE_PATH`。只读共享模型用明确模型路径加载。
   Shell重定向日志、Ray工作目录、其他框架缓存也必须纳入启动器清单。
6. 从已修复或已验收的独立客户端批量拉取**已封闭且不可变**的本地提交，归档到Ceph；
   在受影响主机上仅把同步搬进另一个线程/容器不能规避宿主机缺陷。
   归档记录文件hash、来源boot/run、提交号和同步水位，完整校验后发布完成标识。
   部分复制、活跃目录快照、仅close成功不能冒充持久化备份；归档失败保留本地权威副本。
7. 启动需同时满足工作负载预算和最低预留：本地剩余空间至少20GiB（绝对容量），
   可用inode至少5%。2026-11-17 用户决定取消相对空闲比例门槛（原“至少10%”）：大容量
   本地盘可以长期低于10%空闲而仍有充足绝对预留，比例不是容量判据。最低值不是训练所需
   容量估计，运行中需按预算检查并有序停止。
   新容器日志必须轮转，例如`--log-driver=json-file --log-opt max-size=100m
   --log-opt max-file=3`；已单独可靠收集日志时才可使用`none`。不得全局prune或删除故障证据。

## 已实现与待验收

2026-11-13补充IPC路径：Linux pathname Unix socket上限107字节，vLLM会在临时目录
追加36字节UUID。实验目录过长会导致ZMQ绑定失败，即使容量和文件数正常。
新推理容器将本次运行的本地`/data/.../cache`绑定到容器`/jev-tmp`，显式设置
`TMPDIR=/jev-tmp`及`VLLM_RPC_BASE_PATH=/jev-tmp`；不能用指向Ceph的短软链替代。
`local_ipc.py`在engine分配前检查UTF-8字节长度和真实挂载/容量；长文件输出路径
仍保留实验身份，只有IPC临时目录用短别名。现有快照不修改，失败任务另建修复版本。
本地socket边界及实际bind测试已通过；新NPU快照验收尚待完成。

`local_runtime_storage.py`解析当前进程`/proc/self/mountinfo`，解析软链接与bind挂载，
检查已声明热路径的文件系统、只读标志、空间及inode。已接入
`train_slurp_instruction_npu.py`，在输出mkdir及torch/NPU导入前拒绝不满足要求的配置。
这会使旧的Ceph输出配置失败；不得原位修改已冻结运行快照来绕过，需发布新的启动配置。

该检查不是系统调用拦截器，不能覆盖未声明的库路径、运行期间新建挂载或其他工程。
容器共享根只读、完整路径清单、本地checkpoint一致提交、归档/恢复验收及内核升级
仍须完成，才能发布稳定工程。不能仅凭路径检查通过就恢复训练。

## 永久修复与验收

依据Ascend驱动/固件支持矩阵选择包含Ceph空会话及会话竞态修复的内核，由维护流程
安装并重启；不能热替换正在挂载的Ceph模块。保留旧内核回退、驱动安装材料与boot日志。
确认重启后实际加载的新kernel/ceph.ko身份，再在隔离环境验收文件/目录提交、恢复及
实际音频训推一致性。配置本地kdump容量与持久串口日志，防止下次只剩不完整日志。
禁止在当前生产旧内核上故意复现崩溃。当前未完成内核升级与恢复验收。
