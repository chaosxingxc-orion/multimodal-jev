# 端到端语音任务：冻结读出对照结果

## 路线约束

音频与任务定义直接输入同一个语音多模态 actor，由它输出任务结果。
不派发 ASR 转写后再交给独立语言模型的主线实验，也不以参考转写代替音频。
旧串联运行仅保留历史诊断；相关执行入口已停用，训练队列继续暂停。
远程教师仍可离线优化提示词，但在线 actor 必须直接听音频。

## 本次实际完成

- 模型：Qwen3-ASR-0.6B-hf，冻结官方权重；HF eager，BF16，seed 17。
- 硬件：175 服务器物理卡 4；两个条件顺序运行，均正常退出。
- 数据：固定 64 个 FSC TRAIN 录音组，每组 6 个任务视图，共 384 条请求。
- 条件：原始音频、等时长全零音频；模型、任务、候选顺序与提示词相同。
- 直接读取下一 token 的候选标签分数，再按任务定义映射结果；不生成转写、
  不调用文本决策模型、不增加训练头、不更新权重。
- 原始音频耗时 92.45 秒；全零条件耗时以对应 result JSON 为准。
- 两个条件均完成全部请求；运行后 checkpoint 文件哈希未变。
- 路线拦截、有限标签读出、六视图评分和对照审计的 26 项测试通过。

这是 TRAIN 接口探针，**不是官方 FSC TEST 结果，也不是论文基线复现成绩**。
格式由程序读出保证，不能报告为模型学会了 JSON 指令；候选归一化概率未经校准。

四类选择任务的 256 条预测在两个音频条件下完全相同，全部选择索引 28
（第 29 个候选位置，标签 S）。原生视图恒为 c28，重绑定视图恒为 c29；
候选打乱后虽然输出 ID 多样，仍然只选同一个位置。

Noul 条件只有 true 或 null，从未输出 false。原始音频中肯定问题
60 true/4 null，否定问题 61 true/3 null；全零音频分别为
47 true/17 null、55 true/9 null。27/384 条结果随音频条件改变，
但这没有带来正反命题辨别。概率分布变化也不能单独证明语义理解。

结论限定为：**这个 checkpoint、提示词和首 token 标签读出组合未建立有效的
任务判别基线**。不能据此否定 ASR 转写能力或所有端到端任务方案。
全零音频只是敏感性对照，不是标注为 unknown 的语义评测集。

## 执行决定与后续

1. 保留失败数据，不把该读出方案扩展到选择集或测试集，不用此结果宣称
   教师优化收益；本次没有新增教师 API 调用。
2. 下一步先核查 ASR 模型的任务输出接口与可适用范围。若引入直接音频
   指令模型，作为明确标注的外部端到端对照，不能把它悄然当成原 ASR 骨干；
   若需要训练读出头或任务适配，须另立训练协议，不能称为无训练提示优化。
3. 有了有效的直接音频任务信号后，才能进入学习集反馈 → 离线教师提案 →
   独立选择集筛选 → 冻结测试的流程。测试集不参与提示词选择。
4. SLURP 原生导出和 SpeechBrain 官方 FSC 端到端基线继续独立运行。
   本次检查时前者仍处于 TRAIN 音频哈希校验，后者仍未完成全部 3793 条；
   不报告部分评测准确率。有限候选读出不支持 SLURP 原生开放实体生成。
