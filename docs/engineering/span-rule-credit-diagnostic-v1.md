# 加性奖励的联合动作信用噪声诊断

当前模型一次前向输出多个有限分类分布，采样联合策略分解为各Span分布乘积。
离散前置答案不输入Final。若奖励只依赖Final，前置动作对奖励没有因果作用，
其独立logit坐标上的期望score-function梯度为零。共享backbone仍可通过Final
路径获得梯度；这不意味着前置隐藏状态没有作用。

对真实8请求的已验收初始策略分布，固定256个随机种子重采样，保持原奖励，
计算未标准化期望奖励的score-function梯度。精确梯度用有限候选解析计算，
并以全部8种动作枚举及autograd验证。没有运行新权重更新或改动已派发算法。

| Final-only采样数/请求 | 对精确梯度的平均平方误差 | 前置logit梯度平均范数 | Final平均范数 |
| --- | ---: | ---: | ---: |
| 8 | 0.005293 | 0.152569 | 0.338274 |
| 32 | 0.001236 | 0.073321 | 0.336948 |
| 128 | 0.000319 | 0.037232 | 0.337810 |

精确前置范数0，精确Final范数0.337483。按实际GRPO组内样本均值/样本标准差
标准化后，32样本时前置范数0.147967。该归一化估计器与上述未标准化目标
不是同一目标，不能把两种范数直接当质量排名或将差值全归于某实现错误。

辅助权重0.2时，精确前置范数为0.047669，而32样本的未标准化估计范数
为0.084474；不能将范数差当成噪声范数，但结合均方误差可见仍有估计方差。
所有数值是独立logit坐标，并非LoRA参数梯度或任务准确率，不能直接外推
训练速度或泛化收益。

## 后续算法假设

对可分解且有审核标签的加性奖励，研究按决策依赖分配信用，去掉不影响
该奖励项的动作采样噪声。有限支持允许对无关Span做条件期望（Rao–Blackwell
化），或者直接计算各候选的条件奖励与行为基线。仍由vLLM给出真实行为分布，
使用相同未合并BF16策略，不能用actor重算替换old policy来制造ratio=1。

该方法与目前整个tuple的PPO裁剪不完全等价：逐Span比率/裁剪会改变多步
离策略目标，应独立定义、实现并比较。单步on-policy解析梯度等价不证明
多轮PPO目标等价。也不能仅去掉辅助动作项而宣称实现了更强隐式推理。
非加性规则一致性奖励需要明确联合依赖；无审核真值时不允许偷偷使用gold
事实或给自洽但错误的输出高奖励。

下一轮应固定相同初始adapter、批次、更新预算和seed集合，比较原联合GRPO、
条件信用分配和继续SFT。先用有限支持枚举验证目标/梯度，再接真实verl损失及
NPU更新，保持完整动作的训推验收。收益需同时看Final、事实保留、互补规则响应
和独立来源/规则族；本诊断尚未准入任何新算法。
