# Qwen3-Omni 冻结提示词选择协议

本协议在读取Omni选择集输出前登记。沿用既有64学习/256选择组划分，
教师只使用64学习组反馈；完整TEST在候选选定后使用。当前尚无教师候选，
因此尚未生成具体选择登记文件或启动选择集实验。

1. 两路学习控制必须成功终止；教师生成、结构筛选、语义审查完成后，
   `register_omni_selection.py`登记parent及全部合格候选（最多2个）。
   提示、划分、模型审计、请求文件和模型配置以哈希固定。
2. `infer_qwen3_omni_selection.py`只接受登记的256个TRAIN选择组，1536个请求。
   复用Omni音频推理函数，使用单独的population selector；原学习入口仍只允许
   1或64组，不开放TEST、不允许静音条件或学习组替换选择组。
3. 全部提示使用同一源码快照、镜像、权重、解码和数据。必须给parent重新跑
   完整选择集，不能把64学习成绩与256选择成绩横向比较。
4. `select_omni_prompt.py`要求全部候选、parent的应用/容器/监督器成功终止，
   逐项核验运行版本和结果完整性，按严格六视图评分重新计算。
   不剥Markdown围栏，非法JSON不等同有效null。
5. 排序依次为六视图全对组数、四项配对正确数之和、六视图正确数之和；
   全部相同时优先parent，然后更短提示，然后候选ID。配对转移和McNemar
   仅用于描述，选择集不声明官方TEST显著性或泛化收益。

当前代码通过14项选择范围、提示/输入修改拒绝、严格格式配对及学习控制相关测试。
NPU上新增选择入口尚未运行；派发器及具体候选登记仍待控制实验和教师步骤完成。
正在运行的学习控制使用不可变94be9a6快照，不受工作区入口修改影响。
