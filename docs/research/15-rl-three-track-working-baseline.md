# Loss、过程信用与配置迁移工作基线

2026-11-12。集中回应三个研究问题；协议细节见[主协议](14-rl-decision-credit-and-transfer.md)。
所有实验直接输入音频与问题/候选配置，一次填充 typed Span，不引入文本推理。
主线比较RL更新的收益、结构奖励的收益和跨数据集收益，不增设RL/SFT效果比较。

## 1. 简单判决：先锁定目标，再处理弱信用

对于有可靠标签的单个K分类问题，任务奖励为 `r(a,y)=1[a=y]`。
未知标签不参与loss或有效分母；分类ID没有数值距离意义。
未来确有连续数值标签时，按业务容忍误差定义有界效用，并重新定义策略分布；
不能直接套用有限候选枚举。

固定旧策略p0，用完整候选计算：

```
A(a) = r(a,y) - sum_b p0(b) r(b,y)
rho(a) = p_theta(a) / p0(a)
L_i = -sum_a p0(a) min(rho(a) A(a), clip(rho(a),1-eps,1+eps) A(a))
L = sum_i w_i L_i / sum_i w_i
```

p0、优势和来源权重均不反传；实际实现另固定verl版本的dual clipping。
类别均衡在来源抽样/外层w_i实现，不在组内标准化时抹掉它。
有限候选枚举避免随机采样全错而无信用；它不保证低概率样本获得足够梯度。
在同策略点，正确性目标的梯度含p0(y)系数，容易集中到少数已有优势的来源。

中心化策略loss在新旧策略相同时可为零而梯度非零；不同更新的优势也不同。
因此“loss持续下降”不是主验收。需记录greedy accuracy、macro-F1、类别覆盖、
正确概率、NLL、margin、更新KL和梯度裁剪。独立评测的分类提升为主，后者解释优化。

当前D的0–12步全部为1/89、只预测一个类别，正确概率均值却从0.01518升至0.01915。
这是约一遍89条学习人口的短程结果，支持排查信用/初始化/配置消费，
不支持成功结论，也不支持否定RL。

独立候选采用平滑效用 `U(p)=log((p+tau)/(1+tau))/log((1+tau)/tau)`，
`tau=1/K²`；以冻结的U'(p0)缩放正确性优势。它改变优化目标，
不是原准确率目标的无偏修正。数学及合成四rank CPU验证已通过，
真实语音NPU、恢复与收益未验证。详见[候选及证据](intent-smoothed-utility-candidate-v1.md)。
比较时需要统一标量缩放控制，区分相对信用重分配和单纯放大梯度。
先完成冻结D/Q/P，候选另立版本，不在曲线中途更换奖励。

## 2. 结构判决：过程监督必须改善Final

当前策略给定音频与完整模板后因子化输出多个Span。前置位置和Final共享隐藏表示，
Final不读取前置离散预测。这里能先验证结构化辅助信用，不能预先称为已实现多跳因果推理。

首轮可靠意图分解为scenario、action、joint intent：

```
R = 1[Final正确] + 0.1*1[scenario正确] + 0.1*1[action正确]
L = L_Final + 0.1*L_scenario + 0.1*L_action
```

第二式指每项用未加权优势构建上述边缘PPO，再加权一次；实现若已将0.1乘入优势，
不能在loss外再乘一次。跨请求仍按原有效来源权重求均值，不再除以Span数量。
新增更多过程问题时保持总过程预算固定；缺标项无信用，不擅自补标签。

Final正确性只给Final边缘动作信用，各过程项获得自己的正确性信用。
在当前因子化策略下，仅Final奖励对前置离散动作的精确条件优势为零，
但Final梯度仍会更新共享表示。把同一个采样Final奖励广播给所有Span会引入无效噪声。
有审核关系因子时，才使用 `A_j(a)=E[R|a_j=a,x]-E[R|x]` 分配关系信用。
一致性惩罚单独立臂，不能奖励“一致但全错”。

过程奖励总额小于Final奖励，只约束奖励数值，不保证共享参数梯度由Final主导。
需诊断两者梯度范数与方向、过程修复是否伴随Final修复、过程全对时Final仍错的比例。
没有满足条件的样本时条件指标为null，不填0。
当前真实共享参数梯度诊断仍未出结果，已有输出logit范数不能替代它。

| 对照 | 输入 | 训练信用 | 作用 |
|---|---|---|---|
| D | Final问题 | Final | 直接任务基线 |
| Q | 过程问题和Final | 仅Final | 分解模板本身的作用 |
| P | 与Q相同 | Final及0.1/0.1过程信用 | 过程监督的额外作用 |

比较每臂完整曲线、相对各自起点的变化以及同预算最终绝对分数。
P相对Q隔离过程信用，P相对D衡量完整结构方案；额外过程标签、token与NPU成本单独披露。
预期收益可以是更高Final、达到同等Final需要更少来源/更新，或未见组合更稳健。
只有过程准确率或总reward上涨不算成功。

数据层面，scenario/action由intent投影，适合第一轮工程和信用实验；
下一层任务须有多个独立可核查的音频事实、明确Final规则和未见组合划分，
并检查单个事实不能直接泄漏Final。仅增加问题数不足以构成复杂任务。

## 3. SLURP到FSC：测配置消费和权重迁移

FSC配置已包含问题、候选含义、当前符号映射、合法命令和输出类型。
模型直接听音频，不提供参考转写。结构模板询问action、object、location和Final。
例如音频语义为“打开厨房的灯”，目标为activate/lights/kitchen和对应合法联合命令；
这些目标只在监督/评分侧，不能放进该请求输入。原生none是合法类别，不是缺标。

配置在所有请求中给出完整合法本体，不按gold筛候选；不能靠将31个类ID替换为SLURP类ID实现迁移。
要学到可迁移性，源域应覆盖候选语义、变化的符号绑定和问题结构，
同时用源域开发集验收。固定ID训练后能否消费新定义，是实验假设。

先冻结SLURP权重，在FSC不更新参数、不用TEST挑模板或检查点：

```
权重迁移 G_T = F(theta_RL,T) - F(theta_start,T)
结构配置 H_theta = F(theta,structured) - F(theta,direct)
二者交互 I = H_RL - H_start
```

只有H_RL大于零不能证明RL迁移；G_T才比较同模板下源域学习的影响。
重排/重绑定后按语义还原评分，报告两种视图同时正确率；两边一致地错不算成功。
Final由模型自己输出；组件规则拼接可以作为诊断，不能替换模型Final成绩。

冻结矩阵为起点及D/Q/P各第6、12步，共7策略，每策略3793条官方TEST、
direct/structured与native/permutation/rebind交叉的六视图。
主指标为31命令exact，辅以macro-F1、组件准确率、Final兼容率及重绑定稳健性。
统计区间按说话人等依赖结构计算，衍生视图不是独立录音。
FSC若接近天花板，单报真实剩余误差和稳健性，不根据TEST现编更难模板。
使用FSC训练标签做搜索或适配时须独立登记为目标域适配。

## 研究解释与下一版设计边界

以下补充解释三个问题的联系，不修改已冻结的D/Q/P、utility试验或FSC评测配置。

### Reward、优化Loss与评测不是同一个量

正确性reward定义业务价值，PPO loss负责用旧策略概率更新参数，独立评测判断
部署时的greedy决策是否改善。三者分别记录，不能要求每轮重置优势后的策略loss
呈现类似固定监督loss的单调下降。单分类完整候选期望为J=p_theta(y)，
同策略点有grad J=p_theta(y)*grad log p_theta(y)。这直接说明：
枚举能解决漏采正确类别，却不能消除弱概率来源的梯度抑制。

对于60类、近似均匀起点，8次独立抽样全部错误的概率为(59/60)^8，约87.4%；
这是示意计算，不是当前模型实测。有限支持信用因而适合当前任务，复杂结构中
可加奖励同样可逐Span求和，无需枚举整个联合候选笛卡尔积。

类别均衡必须明确优化的人口：均匀类别抽样本身已改变期望目标；再叠加
逆频率权重可能重复补偿。每版冻结抽样分布及外层权重，报告实际有效类别质量，
不要默认两者同时使用。测试分布保持原始发布，同时报告accuracy和macro-F1。
未知标签的mask与业务上合法的unknown/none状态分开；后者只有标签定义明确时
才是可评分候选。enum ID之间没有距离奖励，真正数值任务另定义误差效用和策略。

### 结构信用：可扩展的公式与可证伪的收益

令j为过程Span，F为最终Span，m为监督mask，w为外层来源权重：

```
R = m_F * r_F + sum_j lambda_j * m_j * r_j
L = sum_i w_i * (m_iF * L_iF + sum_j lambda_j * m_ij * L_ij)
    / sum_i w_i * 1[该请求至少有一个正权重且可靠的监督项]
```

这里每个L_ij用未乘lambda的优势计算，lambda只应用一次。现有两过程为
0.1/0.1，Final为1。若下一版增加过程数量，预先分配固定过程总预算，
不因增加问题数扩大总奖励，也不按现存mask临时重新分配缺标项的预算。
过程正确、Final错误时仍给相应过程信用，保留可学的局部信息；业务验收仍看Final。
把过程信用乘Final正确指示会重新变得稀疏，是不同目标，当前不采用。

一般关系奖励的精确条件优势为
`A_j(a)=E_old[R|a_j=a,x]-E_old[R|x]`。在当前条件因子化策略和纯Final奖励下，
前置离散动作的该优势严格为零。共享参数仍可收到Final梯度，但不能把此事实
解释为离散前置决策已经影响Final。只有独立审核的关系奖励或新的内部依赖结构
才能改变这部分信用；它们须单独立臂，不从D/Q/P结果中混合归因。

过程总预算0.2只控制奖励幅度。实际应比较共享LoRA参数上的g_F与g_process：
记录范数比、夹角及实际优化器位移，避免把输出logit范数当共享梯度证据。
若发生持续冲突，下一版可比较过程权重退火等候选；不能在冻结P曲线中自适应修改。

复杂任务提升分三层检验：

1. **决策效果**：P相对Q的Final增益，以及P相对D的总体增益；完整曲线与相对起点
   变化都报告，不能只选最好一步。相同更新次数之外披露音频来源数、token和NPU时间。
2. **学习效率**：在独立选择集上预先固定目标分数，比较达到目标所需来源/更新/计算；
   未达到时如实记录，不用观测后的阈值制造效率提升。
3. **组合机制**：独立可信的前置事实、未见组合划分及对中间隐藏路径的干预；
   只有分解监督收益时按辅助决策学习解释，不升级为多跳推理结论。

现有SLURP可先回答第一层；其60类中45类可由一个真实组件唯一确定，89条学习
来源仅26条属于需两组件消歧类。FSC的31命令也仅4类在本体上必须三个组件齐全。
这些是本体结构证据，不是声学复杂度或模型推理深度的证明。

### 配置迁移的最小可复算结果

最小解释单元是同一批FSC音频上的四格：

| 固定权重 | direct配置 | structured配置 |
|---|---|---|
| RL起点theta_0 | A | B |
| SLURP RL后theta_t | C | D |

报告C-A、D-B（各配置下权重迁移），B-A、D-C（各权重下结构收益），
以及(D-C)-(B-A)（交互）。交互为正仍可能伴随绝对准确率下降，必须与四个
原始分数一起解释。按原录音配对，按说话人等依赖单位估计区间；不把多模板
重复视图当成新增独立样本。现有七策略六视图矩阵可直接提供这些比较。

配置必须提供问题含义、候选语义、当前符号绑定、输出类型和合法命令全集；
输入不能包含本条gold或按gold缩减的候选。推理模型直接输出Final，规则拼接
组件的结果另作诊断。FSC的none是合法的未指定值。

若源域固定符号学习无法迁移，下一版优先在SLURP学习集内训练配置消费：
固定可复现的候选重排/符号重绑定日程，用变换后的正确绑定计算原正确性奖励。
同一来源的派生视图留在同一划分并共享来源预算；仅用源域选择集确定版本。
这属于计划中的源域增强，不意味着当前模型已具备此能力，也不改现有FSC矩阵。
单纯两视图预测一致不能作成功奖励，因为两视图可能一致地错误。

推进顺序是完成已有短程证据与独立数据准入，优先解除简单任务单类预测问题，
再判断过程信用是否改善Final，并用已冻结FSC配置检验迁移。已排队工程试验保持
原协议；新增研究预算须围绕上述可证伪比较登记，避免无关诊断扩展替代任务收益。
