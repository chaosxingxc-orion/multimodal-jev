# 第74步真实动作重放：只有12.5%的采样组有奖励差异

本次对已归档第74步的128条TRAIN请求重放CPU采样，不执行模型或新训练。
重新运行原独立绑定检查：全量TRAIN发布、日程、音频hash、processor张量、读出位置、
候选顺序和gold均校验；四rank的全局rollout副本相同，只计算一次。
使用归档FP32概率、seed及原torch.rand采样公式，**128/128组动作的shape、dtype和字节hash
完全匹配原记录**。因此以下是这次实际采样的计数，不是理论碰撞概率。

| 16个动作的奖励情况 | query数 | 比例 |
| --- | ---: | ---: |
| 全部为1 | 86 | 67.1875% |
| 全部为0 | 20 | 15.6250% |
| 全部为同一个部分奖励（2/3） | 6 | 4.6875% |

共2048个动作，1544个完全正确集合、1689个取得正奖励，平均采样F1为0.8010254。
112组奖励恒定，但只有105组动作完全相同；不同错误集合也可能得到相同奖励。
这解释了为何不能把动作多样性直接当作有效策略学习信号。

固定阈值0.5下的98条正确决策中，86条奖励恒定、12条奖励有差异；30条错误决策中，
20条全部零奖励、6条全部部分奖励、只有4条奖励有差异。正确确定性与错误确定性必须分开。
后者26条在本次采样里没有组内相对奖励信号，不能仅凭总体采样reward较高判断它们能够被纠正。

局部公式复算GRPO和RLOO在这些恒定奖励组上的优势及独立输出logit的采样score方向均为0。
这里没有重放verl、actor参数梯度或optimizer；本地环境缺verl，未伪称调用成功。
辅助排序、概率损失和固定参考KL仍可能提供梯度，所以不能说这112条完全没有训练作用。
更换GRPO为RLOO本身不能使恒奖励组获得相对奖励信号。

## 对下一版本的约束

当前正式曲线保持完整，禁止据这一个TRAIN批次改阈值、reward、G或选择checkpoint。
应先用完整选择集曲线确认Final效果和概率质量，再判断错误确定性是否持续存在。
复杂Q的过程reward可以引入组内差异，但必须验证这些差异确实改善Final；过程准确率上涨
不能作为Final收益替代。GRPO的组标准化尺度问题与恒奖励组问题是两个不同问题。

若完整证据支持后续改进，已准备的精确期望reward/节点反事实信用可作为独立算法候选，
复用同一音频前向；它们不等于当前GRPO目标，也不能保证修复饱和。先冻结各自目标、
动作分布与对照预算，再做有限验收，不在现有运行中静默替换。
