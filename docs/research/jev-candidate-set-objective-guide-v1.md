# 为 harness 提供候选：输出语义与学习目标

状态：研究设计候选，不修改现有训练、不冻结新 loss。上游证据见
[方案综述](jev-harness-decision-learning-survey-v1.md)和其中的来源快照。
本文件补足“选中一个合法候选”和“识别所有适用候选”的区别。

## 任务边界

输入为音频、任务问题、候选语义定义及调用方明确提供的状态/约束。一次前向输出
各候选的适用性判决、必要的有监督属性，以及可选的相对排序。候选 ID 仅用于请求内绑定。
候选空间由 harness 配置或枚举；Jev 识别、评分并返回支持的候选，不承担任意动作的文本生成。
harness 执行硬约束检查、成本权衡、阈值和动作选择；Jev 的高分本身不是执行授权。

必须分开三个量：

| 输出 | 概率或分数的含义 | 监督依据 |
| --- | --- | --- |
| 每候选适用性 q_i | 在给定证据和规约下，该候选满足适用条件的概率；不同候选不要求和为 1 | 明确的适用/不适用标注；缺标 mask |
| 候选偏好 s_i 或相对分布 | 当前菜单和已声明效用下的排序/选择偏好 | 有效的候选对偏好或结果效用；不虚造合法候选间顺序 |
| 证据/决策状态 | 已定义的缺证据、冲突或无适用候选等状态 | 对应任务的独立监督，不从预测低置信度自动制造 gold |

分别预测 q_i 不意味着假设各候选事件统计独立；不能把它们相乘当作联合概率。
独立二元 NLL/Brier 可用于 q_i，但只有标签含义、采样和校准验证匹配时才能解释其概率。
输入定义支持跨任务复用，采用二元判决本身不等于固定类别识别。

## 为什么只优化 Final 不足

令 A、B 都适用，C 不适用。以下是构造的选择分布，不是模型实验：

| 分布 | A | B | C | 命中适用集合的概率 |
| --- | ---: | ---: | ---: | ---: |
| P1 | 0.45 | 0.45 | 0.10 | 0.90 |
| P2 | 0.89 | 0.01 | 0.10 | 0.90 |

集合 NLL `-log(sum_{i in valid} p_i)` 与命中集合的期望奖励对两者取值完全相同。
但 P2 将合法候选 B 排在非法候选 C 之后，对依赖排序取得候选集的 harness 有明显差别。
集合目标允许在合法集合内集中概率；不能以命中率证明完整候选识别能力。

均匀 soft-target CE 会惩罚 P2，却额外规定 A、B 应均匀获选。适用性标签没有提供这种
真实偏好，均匀分配至多是明确声明的训练约定。有效/无效 pairwise 排序能约束每个合法
候选高于非法候选，不要求合法候选均分概率，但仍然无法独自提供绝对概率校准。

因此推荐以“候选适用性及覆盖”为核心监督，排序和 Final 由任务需要添加：

- 完整适用性标注：逐候选 proper scoring；宏平均与原 query 权重都需固定。
- 有效/无效关系：可加 pairwise 对比；缺失标签不作负例，多正例不互斥。
- 有真实偏好：才学习合法候选之间的排序，必要时引入偏好学习。
- 仅有“任选一个即可”的反馈：集合目标适用，但必须标明不能监督所有适用候选。
- 全合法或全不合法：显式定义任务行为；无有效正负对时 mask 排序项，不丢原样本。
- 缺标与无法判定：分别处理，缺标不等于模型应输出 unknown。

## 与 RL 的关系

Stage1 先学习音频、定义和 typed 判决绑定。Stage2 保留通用 GRPO/RLOO 基线，研究
真实任务效用、错误候选代价及已有监督的集合质量奖励；保留可衰减监督项。
直接可微的排序或适用性 loss 应如实标为辅助监督，不通过改名声称是 RL。

若 Final 只获二元集合命中奖励，令命中概率为 m，则独立采样 G 次全同奖励的概率为
`m^G + (1-m)^G`。在均匀 60 候选且唯一正确时，G=16 得到 0.764209；这说明早期
可能缺少组内奖励差异，不证明任何算法已经失效，也不支持未经验证地删组或改 G。
多合法候选任务的该值更低，不能把任务空间变化的差异称作 RL 算法收益。

精确期望奖励的梯度满足 `grad(-m) = m * grad(-log(m))`。这个等式不等同于
有限采样、归一化优势和 clipping 下的 GRPO 更新；不用于声称两种训练算法等价。

## 数据承载与验收

SLURP clean 意图标签只支持原本体事件及明确的规则投影。现有调用方路由控制任务能检验
动态规则消费和多合法候选，但不是复杂语义理解或工具执行的充分证据。不能通过任意
hash 分组宣称获得新语义任务。规则和菜单生成不能读取当前样本 gold。

下一正式实验应先锁定以下指标，再确定 loss 权重：

1. 候选集合 precision/recall、macro-F1、整集合正确率、至少一个适用候选覆盖率、
   返回数量。返回全部候选可提高 recall，必须同时报告 precision 和候选预算。
2. 有监督偏好的排序质量，以及 harness 在固定成本/阈值下的错误决策率。
3. 适用性 Brier/NLL、校准误差、risk–coverage；校准集与训练/最终测试隔离。
4. 候选换序、ID 重绑定和等价表述的一致性，以及规则改变后的双方正确率。
   相对 softmax 随菜单改变；不强求其数值保持原值。
5. 未见候选定义、规则族和数据集的迁移；只有真实环境结果才能报告执行成功率。

保留单选 Final60 作工程与音频能力锚点。新增候选集合目标独立版本化，不能将已有
Stage1 重命名为 harness 决策模型训练。仍采用端到端音频、一次多 Span 读出，不生成文本思维链。
