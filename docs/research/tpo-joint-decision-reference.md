# Jev 动态 reference：用同一个决策解释 Noul 和 Choice

研究建议，未派发新训练。对象为 0.6B、单标签互斥意图，不外推至多标签任务。

[197/198 配对诊断](../../experiments/tpo-reference-198/README.md)比较了相同起点、同一 34 步排程和奖励定义。198 每次提交后用 actor 替换先验，Noul 的奖励位移仍由初始 TRAIN 分数算出。SLURP 上 Noul 最强负例概率中位数 0.1348→0.9897，macro-F1 81.32%→71.12%；Choice 的误拒率 99.87%→0%，忽略 NONE 后的候选准确率却从 84.47% 下降到 75.01%。MINDS 同向。全候选面板只包含真类在列表内的请求，不能据此判断拒绝列表外意图的能力。证据支持改变 reference 会改变权衡，尚不能将变化定位到某个 head。

## 可复用的算法机制

- [TPO (2026)，算法 1](https://arxiv.org/pdf/2604.06159)：冻结当轮行为策略，采样本轮候选，重新打分并标准化，用旧概率乘以指数化效用后归一化；固定 target 做一到多次更新。算法 1 无独立的长期概率锚。Jev 的候选来自脚本；我们的先验是输出分布，不是生成候选列表的采样概率。
- [LPO (2026)，算法 1、第 2.1、4.3 节](https://arxiv.org/pdf/2605.06139)：区分行为策略和更新前策略，在线算法在外轮起点把两者设为当前模型；在采样列表上构造目标、内轮投影。主设置没有对初始模型的显式 KL。forward KL 在列表内产生零和的系数，可以学习相对排序，却不识别所有候选分数的共同偏移。
- [TR-DPO，第 3.2 节](https://arxiv.org/pdf/2404.09656)：每步按权重混合参数，或每隔若干步硬复制 actor；[TRL v0.23.1 配置](https://github.com/huggingface/trl/blob/v0.23.1/trl/trainer/dpo_config.py)默认关闭同步，开启且保留其他默认值时，[回调](https://github.com/huggingface/trl/blob/v0.23.1/trl/trainer/callbacks.py)每 512 步做一次 0.6 actor + 0.4 旧 reference 的参数混合。这个周期在本轮预算中不会触发。即使缩短，慢更新也只缓解短期波动，不能限定累计漂移。分别混合 LoRA A、B 的结果不等于混合有效权重 BA，更不等于混合输出概率。
- [Magnetic Mirror Descent，第 3.3 节式 10](https://arxiv.org/pdf/2206.05825)：分别惩罚偏离当前策略和偏离指定 magnet 的 KL。两个系数承担不同职责，可从其有限动作更新推导下文方案。论文的博弈收敛结论不直接适用于 Jev 的参数化训练。

## 建议：同一事件，两种接口，两个时间尺度

定义 p_i 为听到音频、给定相同语义规约时意图为 i 的事件概率。若列表 S 只改变可选动作、不增加有关答案的证据，覆盖质量 c 为 S 内概率和；Choice 候选条件分布 r_i=p_i/c（c>0），返回给 harness 的候选质量是 c r_i，NONE 是 1-c。列表外语义含未知类时也要保留这部分质量。当前独立 sigmoid 输出不满足归一约束，不能直接求和再截断。在成对请求上可以直接比较已给出的 Noul p_i 和 Choice c r_i，无需假设当前模型已经一致。候选语义定义改变或召回器额外提供证据时不强求等式。

建议继续用同一个模型。用 clean TRAIN 成对构建音频相同、语义相同的 Noul 和变长 Choice 视图；预先登记列表生成规则，记录真实命中和缺席比例。保留每条音频的总权重，不让列表长度或负例个数充当隐式任务权重。用真实标签对成员概率和覆盖概率计算 proper score（如负 Brier），命中列表内用真类与当前竞争者的比较衡量排序，最终分类在含 NONE 的决策空间评价。若将这些目标做成 TPO 效用，可对评分目标在 detached 当前分布处取一阶方向，再构造本轮 target；对概率向量的 Brier 与给某个离散动作 +1 是不同的函数。真实风险和跨模式残差需直接测量，拟合 target 本身不是校准证明。

对同一输入、同一动作空间，设 b 为上次提交的 actor 输出，a 为冻结起点输出，R 为当轮标签给定的效用，λ、μ>0。最大化 E_q[R]−λKL(q||b)−μKL(q||a)，闭式目标为 q∝b^[λ/(λ+μ)] a^[μ/(λ+μ)] exp[R/(λ+μ)]。分别在二元或同列表的分布上做归一，不能混合不同列表的位置索引。总强度 λ+μ 决定一次 reward 位移幅度；固定总强度时，μ/(λ+μ) 单独决定回拉份额。对固定输入、固定支持、正概率、精确投影，下一步相对初始的两动作 log-odds 偏移等于旧偏移乘 λ/(λ+μ)，再加奖励差除以 λ+μ。它解释了长期锚能限制有界效用累积，也说明错误锚会保留错误；不能据此保证实际网络收敛或校准。尤其要在 TRAIN 分开核验起点的排序、覆盖和概率，不用一个严重误拒的覆盖输出强行约束所有目标。

每次 optimizer 提交后形成下一 macro 的 b 和 detached 当前竞争者；固定 a 只对身份一致的音频、模板和候选列表复用。一批生成一份常量目标，各 micro 只读。不为 reference 另存基座或各步 LoRA；不使用 TEST/迁移结果设置权重、阈值和锚强度。

## 一次联合判定

锁定同一音频上的成员正负 Brier/NLL、真类与最强错类间隔和次序翻转、含 NONE 的最终准确率（命中误拒/缺席误接分报），以及 Noul p_i 与 Choice c r_i 的绝对差，按列表长度和命中状态分层。用源域 TRAIN 确定任务权重及容忍度，独立评测前冻结。业务要求以三个方面同时守住护栏来表达；一个加权总分不足以判定成功。将一次联合方案与封存基线配对评估，只能验证整体方案，不能从单次对照拆出各改动的独立因果贡献。
