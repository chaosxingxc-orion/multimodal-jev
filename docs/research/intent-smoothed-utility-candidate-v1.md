## 优化对象与Loss

对单个可靠Final标签，令p为正确候选概率，K为候选数：

```
tau = 1/K²
U(p) = log((p+tau)/(1+tau)) / log((1+tau)/tau)
c = stop_gradient(1 / ((p_old+tau)*log((1+tau)/tau)))
A(a) = c * (1[a=y] - p_old)
```

U在[-1,0]有界，单调增加。c在同策略点使正确性PPO的梯度匹配U的梯度；
离开旧策略后，冻结c及裁剪得到局部surrogate，不是全程精确优化U。
这是改变了跨来源优化偏好，不是原平均正确性目标的无偏修正，不应声称新
RL理论。接近无平滑极限时与缩放对数似然相关，但研究对照仍只比较RL方案。

tau=1/K²为本候选固定选择，未做阈值搜索；不是唯一或已验证最优设定。
它比先前1/K下限更低，能区分更多弱概率来源。p远小于tau时梯度仍趋近零，
不能宣称消除全部信用饥饿。U有界不代表动作奖励缩放c小：K=60最大c约440。

保留原分类均衡request_weight与有效请求全局分母。c乘在Span信用上，
不对batch的c重新归一化，否则会抵消预期的弱信用放大。只接受单Final、
原权重1的任务，未定义多Span过程奖励的缩放；缺标保持无信用。行为概率、
音频输入、候选支持及请求身份不变，监督仍在模型输入之外。

## 已执行验证

8项本地数学测试覆盖边界、有界性、有限差分、低概率极限和非法输入。
固定镜像无NPU容器中实际verl四Gloo/DDP rank，混合2/31/60类、不同请求
权重、一整rank缺标、microbatch1/2、连续2步，独立计算原始非线性U的
梯度并比较实际actor更新：最大梯度误差1.49e-8，参数2.98e-8，Adam一阶
矩1.86e-9、二阶矩2.73e-12。真实容器退出0。只证明合成FP32 CPU路径，
不证明真实语音/NPU/BF16训练、恢复或长期表现。
证据见`../engineering/span-smoothed-utility-dp4-cpu-v1-verified.json`。

## 进入训练前与收益判定

下一版需单独固定起点、Adam、学习率、来源日程、奖励和预算；先在真实
NPU完成一次更新、精确恢复及完整HF/vLLM验收。尤其记录未裁剪梯度范数、
裁剪比例、实际Adam位移及更新后KL，不能因c有界假设更新安全。应增加
统一标量缩放的正确性控制以区分相对信用重分配与单纯尺度效应，明确其
预算，不能把两者无区分地归因为算法收益。

主验收仍是固定独立评测的Final accuracy/macro-F1、类别覆盖和预定完整
曲线。U上升、NLL下降、有效来源增多都不能替代分类改善。当前独立开发
音频监督仍待准入，现有离线结果仅支持继续试验，不支持成功结论。
