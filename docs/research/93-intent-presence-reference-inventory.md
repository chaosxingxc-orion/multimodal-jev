# I_present 全量参考清单与覆盖缺口

本轮将联系人、交通、音频控制和事实信息四份既有参考包汇入同一份版本感知清单。
任务定义、原生标签、槽位工作包和训练实现未修改。该清单用于监督收口，不是训练发布。

入口：`configs/reviews/slurp-intent-presence-inventory-v1.json`；工具：
`tools/jev/consolidate_intent_presence_references.py`。数据位于
`/mnt/cephfs/xingchao/datasets/slurp-jev-benchmark/intent-presence-inventory-v1`，
已接入`semantic-supervision-plan-v1.json`的意图目录分支。

| 项目 | 数量 |
|---|---:|
| 全量学习录音 / 显式来源 | 40,513 / 9,192 |
| 当前语义意图卡 | 65 |
| 既有参考判决 / 来源×谓词坐标 | 1,058 / 1,058 |
| 有任意参考的来源 | 491 |
| 当前规则下正 / 负 / 未决建议 | 405 / 568 / 85 |

两个缺正例谓词为`audio_louder`和`audio_level_information`。参考队列是定向规则研究，
其正负比例不能拿来估计完整训练分布或设置分类权重。596,422表示当前全本体笛卡尔积
的未评估数量，不表示所有坐标都必须逐条人工填写；后续应按冻结的监督协议覆盖完整
任务与学习人口，保留真实缺标，并报告有效正负覆盖。

统一协议保留原始判决、原包位置、卡片及适用政策身份，不以新目录覆盖历史。
联系人/交通的请求政策来自原包直接pin；音频/事实信息的请求政策来自原包pin的
历史目录，边界政策另行核对。兼容性只比较相应卡与适用政策，未修改的卡不因无关
政策变化失效。缺少历史政策证据应拒绝合并，不能借当前政策补造来源。

重复建议保留且不投票；相同规则下相互矛盾的建议标conflict。过期建议保留历史，
不参与当前规则的判断。录音状态必须由其所有显式source_ids共同支持，不通过
source_group传播；部分来源缺失是partial_source_review，不是false。未评估坐标
以稀疏表示记录为unassessed，既不准入reward也不准入CE。

验证包括13项测试（8项新清单测试和5项旧映射测试），覆盖政策变更、无关政策不变性、
缺失历史依赖、重复冲突、多来源缺评及权限边界。另外独立脚本从原始metadata、targets
和四份原始参考包重建全部来源/录音绑定、判决多重集、65卡统计和全量录音状态，核验见
[检查记录](intent-presence-inventory-check-v1.json)。生成后增加了主输入必须显式pin的
断言；报告保留生成时实现身份及后续身份，当前实现重建得到相同的四个数据文件hash。
上述是程序与身份验证，未进行独立语义复核或音频复听。

下一步先集中完成集合、非请求、媒体的共同边界审核，再基于同一完整目录开展规模化
监督及独立分歧处理。旧I_fit、I_class成员标签和原生缺失标注均不能自动转成I_present。
统一清单解决了已有证据分散和版本兼容的问题，没有消除语义监督缺口。菜单、Stage1、
奖励、上下文、评测及FSC语义迁移仍须完成统一修订后才能进入工程验收与训练。
