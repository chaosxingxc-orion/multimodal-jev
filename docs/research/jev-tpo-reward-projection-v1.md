# 从直接 loss 转为冻结奖励的 TPO（v0.0.195）
0.6B、181、DP6、BF16、LoRA r64。初始化、训练人口、逐轮配对、两轮 34 步、学习率及优化器沿用 v0.0.194。对照使用已封存的 v0.0.194 TPO 端点。两版的差异包括动作空间、奖励和投影的归一化，效果只能归因于整套改法。

每个候选的动作是“是/否”。在冻结 Stage1 处，先离线计算两个动作的奖励差 A=R(是)−R(否)，再构造 logit(q)=logit(p1)+A/τ。这是最大化期望奖励减 τ×KL(策略||参考) 的独立 Bernoulli 解。actor 只最小化每个候选的 KL(Bern(q)||Bern(sigmoid(z)))，取候选均值，再按全局真实录音平均。其导数与 sigmoid(z)−q 成正比。一个类别 softmax 不能识别共同的 logit 平移，故这里直接投影到与 harness 相同的独立概率空间。绝对概率是否已校准仍要评测。

[奖励配置](../../configs/portable/operations/tpo-stage2-reward-projection-v1.json)和[奖励实现](../../src/multimodal_jev/context_tpo_rewards.py)定义七个信号：保留按类频率加权的正确项效用；加入正确项对最强错误项的有界排序修正；原存在性、正项与强负项、同音频间隔、跨录音区分和一致性这五项在冻结参考处取局部负导数 −∂cost/∂p，逐项截幅后加权进入 A。前两项也只在目标编译时使用。类别效用保持原定义，不截断；有界排序只修正尚不足的间隔。配对代价对两个成员均求导；每轮按其真实伙伴制表。它们是局部奖励代理，不等价于在每步对当前策略重新求导。目标编译阶段的自动微分仅作用于离线概率张量，不加载研究模型。训练时除了固定目标的 KL 没有其他反向项。七个信号不是七次 rollout，推理接口不变。

有限验收使用原有四个 parity pass 和两次更新，另检查唯一任务 loss 与投影 KL 数值相同。训练/退出/收集按共享控制器。评测仍以冻结的 Stage1 和 v0.0.194 为对照：三数据集完整 top-1 macro-F1 与准确率、候选 NLL/Brier；报告回退、修复和源域正负项 NLL，不依据测试或迁移标签重新定权。拟合 TRAIN 奖励目标不等于留出增益。
