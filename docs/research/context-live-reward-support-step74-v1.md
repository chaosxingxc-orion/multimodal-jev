原始记录，没有再次远程观察或模型推理。将128个request逐槽位对齐冻结epoch0/batch73，

对算法设计的具体启示：

1. 先保持GRPO/RLOO当前实验完整性。相同奖励下两种估计器优势均为0，切换估计器不能
   自行恢复探索。不能删除无信号组改变全量曝光，也不能据这个批次调阈值或选择checkpoint。
2. 后续需要区分奖励饱和来源。正确确定性无需强行增加随机性；错误确定性才是纠正信号的
   重点。训练标签可供离线诊断，不能成为部署时筛选候选或问句的oracle。
3. 若完整曲线复现相同现象，先固定harness决策效用、概率评分与探索约束，再独立比较
   探索变体或精确期望reward。精确期望避免有限采样漏掉稀有动作，但其logit梯度仍可能
   随饱和而很小，也不等于GRPO标准化裁剪目标，不能承诺自动修复错误确定性。
4. Step-wise过程reward不能凭空解决Final的错误饱和。前置节点的有效信号、真实监督和
   对Final的依赖需要单独设计；过程指标提高不作为Final收益替代。
