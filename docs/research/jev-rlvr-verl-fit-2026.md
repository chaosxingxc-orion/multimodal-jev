# 2026 年 RLVR 与 veRL 在简单 Jev 判决上的适配

本次核验覆盖 2026-11-20 至 21 日。Qwen3-ASR-0.6B 直接消费音频和候选定义，在 clean SLURP 单标签意图上输出排序与独立存在概率。FSC、MINDS 用于冻结后的迁移评测。目标、采样和阈值只使用源域训练数据。复杂决策、参数抽取与生成不在本报告范围。

**建议下一轮优先验证直接的排序和概率目标，并把 G16 双信用 GRPO 保留为已实现基线。** 当前动作空间足够小，每个候选对和每个存在位的两个动作都能由 clean TRAIN 标签直接判分。检验 RLVR 的新增价值时，先定义独立且可确定验证的最终判决效用，再计算其期望或反事实信用。

## 现有 GRPO 在学什么

每个 query 里，排序对和存在位分别采样 G16 个二值动作。每个动作判对得 1、判错得 0。两路各自按组做 `(reward - mean) / max(std, 0.25)`，然后各乘 `0.25`。联合候选集合奖励的权重为 `0`。现行实现调用 veRL `compute_policy_loss_vanilla`，其余分支、奖励和归一化由 Jev 定义。辅助监督包含最强负例排序、Bernoulli NLL 和概率间隔，另对冻结 Stage1 概率加 KL 约束。

每批轨迹只更新一次，训练与采样策略在更新前对齐。记 `r=exp(logπθ(a|x)-logπold(a|x))`，在 `r=1` 和 clipping 未生效的点，`mean(-r*A)` 等于零，但导数是 `mean(-A*∇logπθ(a|x))`。例如同一 Bernoulli 的两个采样动作 `a=(1,0)`，优势 `A=(+1,-1)`，当前 `p=0.5`：策略 loss 为 `0`，对 logit 的梯度为 `-0.5`。本次用 PyTorch 验证，叠加一个标量 `0.2`、梯度 `-0.1` 的辅助项，反向得到 `-0.6`。单步 optimizer 实际接收各分支对可训练参数的梯度之和，之后才执行裁剪、更新 AdamW 的矩估计。分支权重来自目标函数中配置的系数。[TRL 实现](https://github.com/huggingface/trl/blob/main/trl/trainer/grpo_trainer.py)及[文档](https://huggingface.co/docs/trl/main/en/grpo_trainer)也支持单次更新。

二值动作下能进一步看清信号。令 `s` 为判对概率，`z` 为越大越倾向判对的 logit，`f` 为实际采样正确率。忽略权重并在 `r=1` 时，组梯度对 `z` 为 `-f(1-f)/max(sqrt(f(1-f)), 0.25)`。因此，**组内有对有错时有梯度。16 抽全对或全错时，这个分量的梯度恰为零。** G16 混合组概率是 `1 - s^16 - (1-s)^16`。这是奖励没有区分出不同动作所致，和训练、推理数值近似相等是两个现象。把一组全错的奖励统一改成负数，中心化后仍全为零。

| 本地证据 | 纯策略 loss 的读数 | 能确定的梯度信息 |
|---|---:|---|
| 历史 v0.0.93 正式 634 步，两 rank、1,268 条记录 | `abs(jev/dual_rl)` 中位数 `1.44e-10`，P90 `3.51e-10`，最大 `5.82e-10` | 保存的 `actor/grad_norm` 只有总梯度，不能归因给 GRPO |
| 历史 `macro-efficiency-v1/micro8-attempt2` 100 步、12,800 次 TRAIN 曝光 | `abs(jev/dual_rl)` 中位数 `1.05e-10` | 按原始轨迹和当时的目标复算，输出 logits 的 GRPO/辅助梯度范数比中位数 `5.50`，P10–P90 `4.30–7.17` |
| 当前 `jev-r64-stratified-192-formal` 前 3 步 | `+5.70e-10`、`+7.75e-10`、`-1.32e-11` | 同口径复算 logits 梯度比 `0.383 / 0.407 / 0.468`，与辅助梯度余弦 `0.685 / 0.544 / 0.629` |

历史曲线与 capsule SHA256 相符。100 步重算逐文件匹配独立审核绑定的 transport SHA256。步级标量统一按每 rank 求和 microbatch 再跨 rank 平均。梯度为行为策略点的输出坐标诊断，纳入分支系数，不含 KL。两个实验的数据与辅助 loss 都不同，只能说明同数量级标量可对应截然不同的相对梯度，不能归因给单一权重变化。早期归档的 `actor/pg_loss` 是[混合目标](../engineering/archive/raw/context-rl-history/context-step256-native-metric-semantics-v1.md)，也不能当作纯 RL 值。

当前前三步，598 个严格排序错误中有 111 个（18.6%）的「正确项 vs. 最强负例」G16 全错，其正确动作概率中位数 `2.41%`。另有 97/1,152 个正确候选存在位 G16 全错，正确动作概率中位数 `2.26%`。在这个概率附近，16 抽全错的概率约七成。该结论只覆盖对应的判决分量。其他节点仍可向共享参数传递梯度。只看前三步，辅助项在输出层范数较大。LoRA/head 上的分项梯度、裁剪后步幅或评测收益仍未分离。

## veRL 支持与 Jev 适配

## 2026 年研究与当前优先级

- [Advantage Collapse / AVSPO](https://arxiv.org/abs/2605.21125)、[EBPO](https://arxiv.org/abs/2602.05165)：直接针对全错或恒奖励组。前者改归一化基线，后者用跨组统计做基线收缩，均可在已采样失败动作上给惩罚。对 Jev 来说，两个动作及其真值都已知，额外造基线之前先做完整动作对照。
- [TPO](https://arxiv.org/abs/2604.06159)、[LPO](https://arxiv.org/abs/2605.06139)：先构造奖励改善后的目标分布，再把策略拟合过去。TPO 验证包含 contextual bandit。与 Jev 的匹配点是可以在完整小动作集上构造目标，避免只在采到的失败动作上分配概率。有界奖励对近饱和分数的拉动仍要验证。两篇均没有提供 Jev 或 SLURP 效果证据。
- [GDPO](https://arxiv.org/abs/2601.05242) 解决多个可验证 reward 在同一个采样动作上被混合后失去分辨率的问题。只有将来确立同一最终判决上的多维效用，这种归一化才值得尝试。
- [VPR](https://arxiv.org/abs/2605.10325) 用可验证 oracle 给中间动作归因。[CBPO](https://arxiv.org/abs/2608.24300) 用同前缀分支比较后果。当前 Jev 的多个候选或 Span 是一次 forward 的并行输出，没有独立 rollout 转移。可借用其反事实思想，对同一音频只翻转一个判决位、重新计算最终效用，不必做文本生成或强行使用 GAE。
- [Le Critique](https://arxiv.org/abs/2608.16739)、[S3AC](https://arxiv.org/abs/2610.35518) 为长轨迹提供 token 级 value/advantage，并减少对多个 rollout 的依赖。它们将 critic 的准确度与额外成本作为研究问题。当前 G16 是在一次模型打分后做 CPU 二值采样，换成单个 rollout 不会省下 15 次音频模型前向。低优先级。
- [2026 年音频 mDPO](https://arxiv.org/abs/2610.04004) 给出了用完整音频与有扰动音频做偏好对照的音频 grounding 实例。它不证明 DPO 能校准候选概率，也不支持把改变标签语义的音频扰动视作等价样本。当前训练优先使用本就有真值的同音频候选对。

## 按判决分量决定何时使用 RL

对一个候选对或存在位，若组内奖励全相同，则每个优势 `A_i=(R_i-mean(R))/max(std(R), ε)` 都为零。裁剪策略项的每一项和导数都为零，与概率比无关。只跳过这些分量的策略项，并保留原始 query 分母、辅助项和参考约束，与现有 GRPO 更新等价。同一音频的其他判决分量照常独立计算。若改用有效组数量作分母，就改变了训练权重。给定同一输入，设 `M` 为采到混合组的事件，当前策略梯度估计 `g` 满足 `E[g|M]=E[g]/P(M)`。只收混合组并持续重采，尤其会改变混合组较少的样本的权重。

| 观测 | 策略项 | 直接监督 |
|---|---|---|
| G16 全对 | 跳过该组 GRPO | 检查冻结的概率间隔和阈值。两者满足时可作为少量回放，仍有欠校准时保留概率监督 |
| G16 全错，且 clean TRAIN 真值可用 | 跳过该组 GRPO | 用正确候选与最强负例做排序和间隔监督，用存在性 NLL 拉回过低的正确概率。保留在训练人口内 |
| 有对有错 | 可以产生 GRPO 信号 | 逐位正确性已能由真值直接评分。策略优化优先用于比较最终判决效用 |
| 证据不足或监督缺失 | 未能验证的奖励位用掩码屏蔽 | 屏蔽对应监督位，保留其他有证据的位 |

全对和全错描述这批采样。是否达到推理判决标准，由冻结的排名、概率间隔和阈值判断。如果 16 次都答错但策略仍有 `p>0` 的概率答对，完整动作空间上的期望奖励仍有梯度。若要提前省去采样，应通过冻结的 Stage1 训练域判决和配置决定哪些分量走直接监督。用当前采样结果事后截断则只适合跳过已知为零的 GRPO 计算。

只看一个已知真值的二值判决，令 `p=σ(z)` 为答对概率。最大化正确奖励的期望就是最大化 `p`，梯度是 `p(1-p)`。直接最小化正确动作的负对数概率，下降方向是 `1-p`。两者方向相同，前者是后者的 `p` 倍。以本轮排序全错组的概率中位数 `p=0.0241` 为例，期望奖励的梯度约为 `0.0235`，直接监督约为 `0.9759`。这是同一输出坐标、等权下的梯度，给出了全错且有可靠真值时由辅助项接手的数学理由。

Jev 专用优化先定义可验证的最终效用 `R(x,a)`。例如同一个 harness 选中真意图后，额外纳入一个错误候选会降低效用。若策略对并行判决位作独立 Bernoulli 采样，令 `a_j` 为其中一位，`p_j=σ(z_j)` 为其取 1 的概率。在给定音频条件下，固定其他位 `a_-j`，比较两次评分。由对 `a_j` 条件求和可得

```text
∂ E[R(x,a)] / ∂z_j
    = p_j(1-p_j) × E_a_-j[R(x,a_-j,1) - R(x,a_-j,0)]
```

这个式子把“改动哪一个判决会改变最终效用”写成可以检验的梯度。对完整小动作空间可精确求和。较大的空间可对其他位按同一行为策略采样，再枚举当前位。这个估计对应原始期望效用的一阶梯度，前提是行为和待求导策略在该点一致。若部署规则本身只优化逐位 0/1 正确性，这个目标仍只复用已有的标签信号。

## 下一轮决策与验收

1. **优先明确训练在优化什么。** 对同一音频选正确候选和最强混淆负例，保留显式概率间隔。存在性保留独立概率监督。若做 DPO，单标签候选的排序对可用 logit 差 `Δ=z_correct-z_confuser`，以 `softplus(-β*(Δ-Δ_stage1))` 作为二候选策略的参考相对目标。它无需等正确动作被抽到。当 `β=1`、参考差为零时，它就是现在的 pairwise logistic 项。若 Stage1 本来排错，参考相对改善后仍可排错，所以 DPO 不能单独承担绝对排序和概率校准。
2. **若要保留 RLVR 主张，先登记一个额外的可验证最终效用。** 例如真意图漏收、错误候选入选的非对称部署成本，或有独立证据支持时才使用的拒判收益。固定正确性与代价规则。在训练域内验证最强负例翻转、正确位翻转对效用的影响。二值正确奖励的期望就是正确动作概率 `p`，确切梯度大小是 `p(1-p)`，它仍在错误饱和区变弱。`-log p` 的梯度大小为 `1-p`，所以保留概率监督有明确作用。若新的效用仍只是逐候选 0/1 正确率，枚举更省采样误差，但没有提供额外信息。已有[单正例集合 F1 解析方向](../../tools/reports/exact_singleton_f1_gradient.py)和[条件信用离线验证](context-conditional-credit-objective-v1.md)可复用。
3. **先核验梯度是否真正改了策略和预算。** 固定相同 Stage1、LoRA、训练视图和种子。在独立候选的有限验收里，用同一批训练样本对排序、存在性、辅助、KL 分别测 head/LoRA 梯度范数与余弦，保留混合梯度裁剪前后的证据。必要时以同一 AdamW 状态做一次 CPU/有限 NPU 反事实更新。正式收益看 clean SLURP 的 Top-1 macro-F1、正确项与最强负例的概率间隔、NLL/Brier，再看冻结策略在 FSC/MINDS 的迁移。TRAIN 用于分层与阈值校准。无需用独立长时间 SFT 对照代替这项诊断。吞吐按完整 macro 计时，区分消除二值采样、消除模型前向和消除实时部署三部分，未实测前不声称省卡或提速。

本地运行归档包括 `context-stage2-minimal-result-v0.0.1/training-curve.json`、`macro-efficiency-v1/micro8-attempt2/{audit.json,transport.json,dual-signal-analysis-v1.json}`、`next-simple-r64-dp8-v1/full-train-stratified-v1/{first-losses-192-observer-v2/report.json,packages-192/formal/config.json}`。本次证据来自历史训练记录、源码核对和 CPU 复算。

## 推荐候选：基于 TPO 的有限动作投影，把语义一致性单独验证

**选择。** 建议以 2026 年 [Target Policy Optimization（TPO）](https://arxiv.org/html/2604.06159) 为唯一新算法母体，做一次有限动作、固定 Stage1 参考的改造。TPO 从已评分的采样输出构造目标分布，再拟合该分布；论文实验包括 contextual bandit。这里可以给一个音频下的全部单标签候选直接评分，省去策略动作的蒙特卡洛抽样。选择它的理由是可以审核“本次更新具体应该把概率质量移向谁”。[LPO](https://arxiv.org/abs/2605.06139) 同属目标投影思路；[AVSPO](https://arxiv.org/abs/2605.21125) 着重修复同奖励采样组；[DPO 的参考相对性分析](https://arxiv.org/abs/2605.20834) 则解释了为什么相对 Stage1 改善并不保证绝对排名正确。依据任务的完整动作信息，目前没有必要并行开发这三条分支。

**输入和输出。** 一个训练状态是“音频、任务规约、候选定义”。对同一个状态，冻结模型的同候选概率应在既定数值容差内可重复；生产 harness 用冻结的确定性规则消费分数。旧版 G16 是 CPU 从同一组分数抽 16 次二值动作，不是模型独立听 16 次。即使某个动作概率恒为 0.9，16 次全选它的概率也只有约 18.5%。训练抽样动作是否相同，不能衡量语义不变性。语义不变性需要另一份保留决定性证据、含义相同的输入；如果关键证据缺失，则允许置信度下降。

**改造一：先只把 RL 效用作用在 Top-1 排序分支。** 对当前单标签意图，令动作 `a` 为一个候选，沿用同一个判决头的 logits。训练时定义辅助排序分布 `πθ=softmax(zθ)`。冻结的 Stage1 排序分布 `π₀` 由同模板同候选的缓存 logits 构造；它与输出给 harness 的独立存在概率 `pθ,j=sigmoid(zθ,j)` 分开解释。枚举候选计算逐动作可验证效用 `U(x,a)`。先冻结真实消费策略和代价表（例如某些错选产生额外路由代价，前提是有独立依据）；若业务动作是返回一个集合，就不能声称单标签效用优化了整个集合。后者需单独定义集合评分并沿用前节反事实公式，避免枚举 2^K 个集合。不能使用 selection/test 统计反推代价。

对 `τ>0` 和具有完整支持的 `π₀`，在单纯形上最大化 `E_q[U] − τ KL(q||π₀)`。一阶条件给出唯一最优目标 `q*(a|x) ∝ π₀(a|x) exp(U(x,a)/τ)`。用 `KL(stopgrad(q*)||πθ)` 投影到模型，排序 logits 上的梯度为 `πθ−q*`。这是带固定参考的离线策略改善目标；参考始终取 Stage1，不以本轮实时 actor 刷新缓存。该证明只覆盖单输入的无约束目标分布，不保证共享 LoRA 可达到目标、开发/测试单调提升或概率已经校准。反例：若正确项概率原本为 0.02，而所有错项的效用相同且比正确项低 1，取 τ=1，目标正确概率也只有约 0.053。因此必须由直接监督处理确信但排错的样本，不能将正则化参考或一致性当成真值。

**改造二：可靠的绝对概率和语义一致性各有监督。** 直接判决分支保留正确项与最强负例的间隔及存在性 NLL。对等义录音的同一候选，按 ID 对齐，比较 Bernoulli 概率分布，可用平均 Jensen–Shannon 散度作一致性项。以原 query 或话语为单位归一化，同一话语中伙伴多不会因配对组合数而获得更多权重。不能仅按标签相同配对，也不使用无差别熵最小化。稳定地答错、所有候选同分，都能得到极低的一致性 loss，所以必须同时检查正确性与区分性。证据改变且 gold 意图不同的真实样本单独测试是否正确翻转；只改变执行参数但意图不变的样本仍属于意图等价。

**数据可行性。** 确定性核对 clean TRAIN 的 40,513 个录音，以文件名连接官方 `metadata/train.jsonl` 的 `slurp_id`，只统计标签一致且至少两份不同音频 SHA256 的官方话语组。共有 8,288 组、39,609 条录音。限制在本轮冻结 Stage2 视图 `packages-192/formal/view-data/batches.json` 非 padding 唯一 ID 中，有 1,428 组、4,346/6,248 条录音；其余样本仍承担直接监督。这是同一话语多录音的可配对人口，不证明任意同义改写、说话人独立性、每份录音的可懂度或模型已实现不变性。输入始终是音频。伙伴若是另一个实际音频，就要把额外音频前向计入预算。

**验证顺序与停止条件。** 在相同单模型、Stage1 起点、训练视图、真实音频前向预算下，先锁定直接排序/概率与等义对训练，再只开关效用投影，保留现有 GRPO 作历史对照。主指标仍为源任务及冻结 FSC/MINDS 的 Top-1 macro-F1，附 Top-1 准确率、NLL/Brier、错误且高置信比例。对等义对报告双方均正确率、翻转率和正确候选概率差的 P90；对改变意图的最小对报告双方均正确且翻转率。重复输入另做数值一致性验收。论文主张必须由增量验证支持：若只能定义“选中 gold 得 1”，那是同一标签的再利用；若独立业务效用不能改善，或用过度自信换来表面一致性，则保留直接目标即可。当前只形成研究候选，未接入冻结训练入口。
