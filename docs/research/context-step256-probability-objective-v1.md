## 当前损失并非没有纠错信号

按原零基update255计算alpha=0.1990705481。由存储概率反推有效logit、独立计算得到：

| 项 | 未加权平均值 | 按当前系数加权 |
| --- | ---: | ---: |
| pairwise ranking | 0.0719384 | 0.0143208 |
| binary NLL | 0.0535061 | 0.0106515 |
| reference KL，逐候选求和 | 0.8224067 | 0.0082241 |

这些是behavior概率空间重构值，ranking会受FP32 sigmoid反推与原BF16 logit差异影响。
它们不等于实际actor日志的逐项loss，也不能与DP microstep缩放后的context_loss直接相减。
KL非零，确认外层actor/kl_loss=0不能解释成自定义参考KL被关闭。

用重建G16、原GRPO公式与ratio=1计算局部loss梯度，再加辅助项和KL：
33条集合错误中32条有提高gold概率的方向；剩余1条gold概率已0.999374，属于多选错误。
33条错误的局部总下降方向均降低其NLL；其中30条采样GRPO梯度为零，纠错来自其他项。
但95条正确样本中92条局部方向会增加NLL：固定参考KL可把极端正确概率拉回较软的参考分布。
这不意味着KL有害，也不能由此决定关掉KL；要检查完整Final、校准、策略移动和稳定性。

输出空间局部梯度不包含共享参数Jacobian、Adam预条件、梯度裁剪、DP和实际步长。
所以“输出坐标存在纠错方向”与“模型经过一次训练就能纠错”是不同命题。
误差可能涉及共享表示/参数冲突或目标相对强度，目前不能凭该批单独归因。
