# 语音 Jev：简单判决、结构判决与配置迁移的 RL 协议

2026-11-12，按用户最新研究重点制定。本文是待验证的算法与实验协议，不是收益声明。现有时间规则小样本曾出现全 false 退化，不能据其宣称方法有效。主目标是 RL 自身的持续提升，不新增 SFT 效果对照。

## 共同契约与三个问题

输入为音频、候选定义、全部问题和可配置思考要求；一次调用交付全部 typed Span。结构任务为 `Q1,<SPAN1>,Q2,<SPAN2>,Final Q,<SPAN3>`，不增加文本理由生成、外部 ReAct 或转写后语言模型。当前模型按因果位置共享隐藏状态，各离散 Span 在给定输入后独立采样。Final 可以利用早期位置的隐藏表示，但没有消费其离散预测。

三条证据分开成立：

1. 简单判决：固定起点后，RL 提升固定开发集上的判决指标，并抑制退化。
2. 结构判决：相同最终任务上，前置问题和过程信用分配使最终判决比直接问题的 RL 更好，或用更少训练请求达到相同水平。
3. 配置迁移：SLURP 训练好的固定模型，在不使用 FSC 标签训练/选模板的条件下，通过预先冻结的 FSC 模板取得相对 RL 起点的提升。

这三条不是 RL/SFT 比较。FSC 零样本迁移和少样本适配须分别登记；只改变模板的收益也与权重训练收益分开。

## 简单判决：奖励和损失

对单个 enum/Boolean 判决，以正确性 `r(a,y)=1[a=y]` 为起点；可靠标签缺失时整个决策不贡献 reward/loss。已审核的有限等级可用预先定义的距离效用，但本轮不为 SLURP/FSC 凭空制造数值标签。有限 typed 候选没有 JSON 格式奖励，也不奖励解释长度。

一个确定真值的 K 分类决策，旧策略完整候选概率 `p0(a|x)` 已可获得。推荐先验证精确中心化信用：

```
b(x) = sum_a p0(a|x) r(a,y)
A(a) = r(a,y) - b(x)
rho(a) = p_theta(a|x) / p0(a|x)
L = - mean_x sum_a p0(a|x) min(rho(a) A(a), clip(rho(a),1-eps,1+eps) A(a))
```

旧概率、baseline 和 advantage 都停止梯度；从全候选概率构建期望，不依赖随机采样碰巧命中正确类别。该有限支持 PPO 候选可用于60类意图与2类判决。新增 `span_finite_credit.py` 已通过混合候选数学测试及真实 verl CPU loss/gradient 核验，既有 Boolean 条件信用代码保持不变；有限支持目标现已接入原生 actor 的 compute/update，并在四个真实 Gloo/DDP CPU rank 验证：混合60/2/5候选、缺标、不同请求权重、整卡有效权重为0、microbatch 1/2与连续两步。全局加权参考梯度最大误差1.49e-8，参数误差2.98e-8；错误的局部分母负对照梯度误差至少0.059。该结果仅是合成 FP32 CPU 证据，尚未验证此新目标的音频/NPU路径。真实 verl 的 dual clipping 等细节保持版本一致并单独记录。偏离旧策略时，此边缘裁剪目标不等价于对整个多 Span 联合动作裁剪。

仍保留采样 GRPO 作为 RL 算法控制：同一完整输入采样 G 份动作，在组内计算相对优势。60类较低正确率下，32次采样可能全错；若近似均匀，其概率约 `(59/60)^32=58.4%`，该组没有正确性梯度。须记录零方差组比例、非零梯度覆盖和按类正确概率。精确枚举消除的是采样漏中问题，不保证收敛；当正确类别概率极低时，期望奖励梯度依然弱。不能仅提高 G 或凭训练 reward 解决这个问题。

类别均衡作用于来源组采样和跨请求 loss 权重，只由学习集频率确定；不能把同一 query 的所有 reward 乘同一个类权重后期待标准化 GRPO 保留其效果，因为组内标准化基本会抵消该缩放。稀有类不以重复相同录音伪装更多独立证据，评测保持自然分布。

类型集合不能用55个判决的普通平均正确率主导，因为全 false 容易得高分。推荐先把可靠正、负类型作为均衡的原子判决目标；完整集合样本另加入有界集合质量目标并报告 micro/macro-F1、集合 exact、非空完整覆盖、空样本误报。部分标注集合不得计算“全空正确”或把未知类型罚为误报。集合目标的精确联合支持是指数规模，不能套用单 Span 全枚举而声称精确优化集合 F1。

同策略点的精确正确性策略梯度与 `p0(y)` 加权分类交叉熵梯度有关。因此这里的研究主张应来自实际持续提升、结构信用与迁移证据，不能把有限支持枚举本身宣称为新 RL 理论。

## 结构判决：Final 优先，过程奖励具有明确预算

前置问题必须有可核查语义且服务最终任务。SLURP 三个并列时间类型不是天然推理链，简单 AND/OR 只能提供工程诊断。原生意图可以研究“业务领域→动作语义→具体意图”的结构；领域/动作标签来自已审核 scenario/action，不能因分解容易就声称复杂推理已获益。类型识别中“有无实体证据→语义角色边界→具体类型”需要额外可靠标签，不能自动从缺标反推。

定义 Final 正确性 `rF`、有效前置判决的平均正确性 `rP` 和审核通过的关系违反比例 `v`：

```
R = rF + lambda * rP - mu * v
rP = sum_j m_j * correct_j / sum_j m_j    # 无有效前置标签时该项为0
0 <= lambda, mu; lambda + mu < 1
```

建议先预注册 `lambda=0.2, mu=0` 过程臂，Final-only 臂取两者为0；再在明确关系标签上独立验证小权重一致性惩罚，如 `mu=0.1`。这些是待测试起始配置，不是已验证最优参数。不奖励“所有答案内部一致”本身，因为一致地全错仍可能高分。只针对配置中可执行且审核可靠的关系计算违反，不借模型自己生成的解释裁决。

这个有界预算保证单个同任务轨迹上 Final 正确优于 Final 错误的最坏辅助项差异；它不保证跨样本优化绝不牺牲某些 Final，也不保证分开标准化后的 loss 仍保持该顺序。若需要严格 Final 主导，不对每个 reward 分量分别单位方差标准化；保留原尺度并监测各分量梯度范数。问题增多时 rP 仍为均值，避免“多加问题多得奖励”。

当前因子化动作策略的推荐信用分配：

- Final 正确性只进入 Final 的边缘策略项。它仍通过共享 backbone 更新能影响 Final 的中间隐藏表示。
- 每个有审核标签的前置 Span 获得自身正确性信用，权重合计为 lambda。
- 关系项若耦合多个动作，使用条件反事实信用 `A_j(a_j)=E[R|a_j,x]-E[R|x]`。小型相关因子可精确枚举，大型因子采用固定预算采样估计，明确区分精确与估计；不枚举55个 Boolean 的全部组合。
- 缺失前置标签不补假奖励。可靠 Final 和独立可验证关系可仍提供信用，但关系不把未知语义标签自动变成已知。

若奖励只有 Final 正确性，独立采样的前置动作的精确条件信用为0；给所有 Span 分配同一个采样组 advantage 会给这些动作引入有限样本噪声。显式前置决策是否帮助 Final 要通过隐藏表示路径的对照证明，而不是奖励名字证明。未来若引入内部循环/条件动作策略，必须重新定义概率分解与训推 gate，不能沿用独立乘积公式。

## 结构方案相对简单方案如何判断提升

固定同一音频、最终问题、最终标签、来源划分、候选知识与 RL 起点，运行以下 RL 对照：

| 臂 | 输入 | 奖励/信用 | 回答的问题 |
|---|---|---|---|
| D | 仅 Final | Final 正确性 | 直接判决 RL 能否持续改善 |
| Q | 前置问题及 Final | 仅 Final | 问题分解本身是否帮助 |
| P | 同 Q | Final + 审核过程项，边缘信用 | 过程监督是否改善 Final |
| C | 同 Q | 同 P + 审核关系项 | 一致性约束有无额外收益 |

依次推进 D/Q/P，C 在有合适关系数据后加入。不是要求同时开四个大训练。所有臂报告各自 step0 到固定检查点的曲线，再报告同预算下结构臂相对 D 的 Final 差异。主预算是相同独立来源与 RL 更新/请求数，同时披露音频秒数、输入 token 和 NPU 时间；多问题模板计算更多，不能声称等计算成本。另报告单位计算的收益。过程标签是额外监督预算，应明确计数，不把额外标签全部归因为推理结构。

提升要求 Final 主指标或样本效率改善，而不是仅前置准确率或综合 reward 提高。加无关前置问题、隐藏路径屏蔽和保持语义的顺序变换可检查结构利用；改变因果位置后输入并不严格等价，应按实际干预解释。若只有多任务辅助训练收益，就如实报告，不宣称离散推理链的因果作用。

## FSC：配置迁移的具体落点

FSC 是有限 action/object/location 命令，31个原生联合意图；不是开放槽位值生成任务。用本地官方本体生成两个固定配置，均直接消费音频：

```
direct:
  Final Q = 在全部合法命令定义中选择一个联合命令
structured:
  Q1 = 动作是什么                         <action enum>
  Q2 = 控制对象是什么                     <object enum>
  Q3 = 位置是什么                         <location enum>
  Final Q = 在全部合法命令定义中选择一个联合命令
```

候选定义明确解释 FSC 本体语义，不能只用 SLURP 分类 ID 硬映射。FSC 原生字符串 `none` 是合法任务取值，不等于监督缺失，也不自动等于拒绝选项。完整候选在推理前给定，禁止按 gold 筛选候选或前置问题。Final 由模型读出，同时另计算 action/object/location 的确定性组合以诊断结构错误，不能替换模型输出后再计作模型 Final 成绩。

第一阶段不在 FSC 上更新权重：冻结 SLURP RL 起点和至少两个预定后续检查点，用相同 FSC direct/structured 模板测试。模板依官方任务定义设计，正式测试前冻结；不依据 FSC 测试错误修词。FSC TRAIN/开发标签若用于模板搜索或模型选择，则必须改称目标域适配，另列预算，不能继续称严格零样本迁移。已有 FSC 历史实验不用于选这次新模板；披露预训练数据未知，不宣称模型从未见过 FSC。

最小分析矩阵为“起点/后续 RL 检查点 × direct/structured”，其中：

- 同模板跨检查点差异衡量源任务 RL 带来的迁移。
- 同检查点跨模板差异衡量目标任务结构配置作用。
- `(后期 structured - 起点 structured) - (后期 direct - 起点 direct)` 衡量两者交互，但不是因果机制的充分证明。

FSC 主报31联合意图 exact、三个组件 accuracy、最终判决与组件兼容率；补报候选重排/ID重绑定前后两边同时正确率，验证定义消费而非固定 ID 记忆。缺候选拒绝及 Boolean 成对查询属于单独的派生任务，不能与原生31类分数混成一个 accuracy。自然 TEST 以官方说话人划分，按说话人和命令/重复语句依赖披露不确定性，避免把同一句衍生视图当独立样本。

FSC 容易且已有强基线接近天花板，因此成功结果也不能替代 SLURP 难任务提升；若原生准确率饱和，可观察合法的重绑定、复合配置和 OOD 模板遵循，明确其派生性质。若无收益或负迁移照实报告，不根据测试结果反复挑模板。SLURP 训练若只有时间判决，不能合理预期直接迁移到设备命令；需先提供跨业务的候选语义、动作/对象和配置遵循训练覆盖。

## 当前落地边界

下一步先完成真实四卡原生 actor/恢复与全候选验收，同时推进意图/类型监督。算法先扩展简单任务有限支持信用与零方差监测，再接 D/Q/P 的相同最终任务比较，最后冻结 FSC 配置执行跨检查点迁移。不得把现有小样本时间规则结果替代这三条正式证据。


## 固定首轮执行与收益归因

首轮先使用可审核的意图分类和意图分解；槽位类型的可靠正负监督单独准入，不等待全55类型补齐，也不以填假负例加快训练。SLURP `scenario/action` 是原生意图的语义分解，能承载过程监督，但它本身不证明多跳推理复杂度。只有最终判决确实需要组合多个证据、且每个前置判决有独立核查依据的派生任务，才进入复杂组合推理声明。来源组、说话人与模板/组合的隔离按实际任务分别登记。

简单与结构任务使用同一 PPO surrogate 算子；差异是 Span 的优势来自何种奖励，而不是为结构任务随意换一种 loss：

```
简单：A_F(a) = 1[a=yF] - p0_F(yF)
过程：A_j(a) = lambda * m_j / sum(m) * (1[a=yj] - p0_j(yj))
最终：A_F(a) = 1[a=yF] - p0_F(yF)
总体：L = sum_j L_PPO(A_j) + L_PPO(A_F)  # 外层用全局有效请求权重平均
```

上式适用于可加正确性目标、因子化策略；关系奖励另以条件期望推导优势，不能直接附加一个同名标量便声称实现关系信用。缺失过程标签时只计算可靠 Final；缺失全部监督且无可验证关系时排除该请求的有效分母。Final标签缺失的辅助请求不计入Final训练样本数，单列其监督预算。

当前工程探针每次使用新行为策略、仅一个 optimizer minibatch，更新前 actor 与行为概率一致。因此裁剪在本次梯度计算时通常不激活；不能仅因为调用 PPO loss 就声称验证了多轮旧数据复用的稳定性。偏移策略下的裁剪已有独立 CPU loss 测试，真正增加 PPO epoch/复用行为数据时，须重新设计更新前一致性与更新后偏离监控，不能让旧策略一致性检查拒绝所有合法更新，也不能取消其来源认证。

训练监测拆开记录：Final期望奖励、过程期望奖励、关系违反率、greedy开发集指标、各类正确概率、优势/梯度范数、更新后KL及裁剪比例。原尺度中心化优势的loss在同策略点可接近0而梯度非0，故不以loss数值下降或总体reward上涨作为唯一验收。分类均衡仅调整学习采样/外层权重，避免重复进行采样平衡和逆频率加权；开发/测试保持发布分布，同时报告macro指标。

D/Q/P先运行相同来源与固定起点的短程验证，再开展至少3个预先固定种子的正式曲线。预先锁定总更新数U及0、U/4、U/2、3U/4、U检查点；开发集用于协议内选点，测试集在选择锁定后统一评估并完整报告预定点，不依据测试曲线继续调参。报告末点相对step0、曲线面积及退化；不要求每个相邻点单调。对同一评测样本做配对差异，并按来源组/说话人依赖计算区间，跨种子变异另报。模板增益、过程额外标签收益和RL权重更新收益必须分别呈现。

FSC配置至少包含 `input_modality`、`thinking_requirements`、每个问题的语义、Span类型、带解释的候选、合法联合命令、确定性评分与版本哈希。输出类别必须通过本次配置绑定，不能默认SLURP训练输出ID等于FSC输出ID。候选表示及未见配置的可消费性是迁移实验前提；重排/重绑定检查失败时，先修复模板消费能力，不将其归因于跨域声学差异。

FSC的最低可观测证据为固定模板下后续RL检查点相对起点的31命令准确率变化，并与direct/structured交叉矩阵一起报告。若只在structured模板上观察到提升，需检查起点差异与交互；若仅组件提升而Final不变，只能报告组件迁移。严格目标域零样本协议禁止用FSC标签选检查点、选模板；任何历史目标域反馈对本次方案的影响都需披露。最终还应在SLURP内部未见场景/任务配置上验证迁移，避免用较容易的FSC独自承担泛化结论。
