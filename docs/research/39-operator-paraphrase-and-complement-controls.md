# 算子改写与正反命题对照

2026-11-12。任务设计产物，不修改既有predicate编译器或训练入口。
[definition-interventions-candidate-v1.json](../../configs/tasks/definition-interventions-candidate-v1.json)
固定I_class/I_present/S_present/B_bound四种算子的原命题、等义问法及整句命题否定。
全部Q在输入前给定，同一音频在三个独立单次前向请求下评测，不把前次输出作为后次
输入，不生成思维链。完整定义、存在政策和共同规则保持原文；尚未渲染到模型输入。

## 真值变换与作用域

| 已有独立监督状态 | 原问 | 算子等义改写 | 原命题是否为假 |
|---|---|---|---|
| positive | true | true | false |
| negative | false | false | true |
| unavailable | mask | mask | mask |
| conflict | mask | mask | mask |

这是真值逻辑变换，不是新标签认证。reference-only审核即使给出拟议布尔值，也不能
因此成为准入的音频标签。冲突记录即使有proposed_value仍保留mask。unknown/听不清
不是自动增加的输出类别。模型评分需要独立准入后的真值，当前只构造参考对照fixture。

尤其B_bound的否定是“不存在任何符合定义且具有该绑定的意图实例”，不是“存在一个
未绑定的实例”。一个绑定实例与一个未绑定实例共存时，两种表述真值不同，因此用
“以下完整命题是否为假”明确取整句否定，不能简单在局部关系上加not。
S_present否定仍按同一whole-utterance/presence policy；不改变为“最终意图不需要此槽位”。
I_class否定只否定该任务的类别成员关系，不推断所有其他现实意图缺席。

## 退化控制与可证伪指标

合成的均衡true/false两例中：

| 控制 | 回答互补率 | 两问都对率 |
|---|---:|---:|
| 全答false | 0% | 0% |
| 不听音频，正模板答true、反模板答false | 100% | 50% |
| 两次始终互补但均与真值相反 | 100% | 0% |
| 真值oracle | 100% | 100% |

这些是可枚举的控制结果，非模型成绩。互补一致性可以靠问题词面取巧；必须同时报告
原问正确率、反问正确率、两问都对、互补但都错、非法输出率，并按基础正/负真值分别
统计。非法输出不当false使用，不能被计成正确互补。算子等义改写也需同时看两次都对
与一致率，不能只看一致性。

该对照只能验证问题极性响应与算子表述鲁棒性，不能单独证明音频理解、新概念理解或
Final因果使用过程结果。符号重排/重绑定、算子改写、定义卡语义改变是不同干预。
当前尚未完成定义卡等义改写审核及定义语义改变后的独立真值，不将本轮算子测试
冒充这两个缺口已解决。音频静音/错配控制需冻结波形身份与预期解释，另行准入。
