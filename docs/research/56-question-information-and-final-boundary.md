# Q提供的信息与Final的任务边界

2026-11-12。对40,513条learning录音、9,181来源组开展原生标注结构分析，回答
“只知道这些Q的正确答案，能否决定意图”。这不是模型推理、RL实验或新语义标签。
工具为`audit_slurp_question_information.py`；共享结果为
`slurp-jev-benchmark/question-information-v1`。源人口、原生类型发布、固定15面板均验hash。

## 方法及结果

每条录音构造原生意图成员/槽位标注存在的布尔向量，以向量为key统计意图分布。
第一列为在同一人口上给每个key指定最多数意图能达到的准确率：它只约束仅消费该
向量的确定性映射，绝不是音频模型能力上界。第二列按source_group固定hash五折，
使用其他四折计数预测当前折；同来源录音不跨折。未知key退回其他折全局多数类，
并列按类名排序。全部来自learning，无选择集/测试集，没有神经模型训练。

| 可使用的原生真值向量 | 同人口多数映射 | 来源五折查表 |
|---|---:|---:|
| 不提供Q，仅全局多数类 | 6.31% | 6.31% |
| 完整55槽位类型存在 | 40.77% | 37.64% |
| 固定面板I，15面板均值 | 12.88% | 12.87% |
| 固定面板S，15面板均值 | 8.68% | 8.60% |
| 固定面板I+S，15面板均值 | 15.02% | 14.92% |
| 完整60个I_class成员位 | 100% | 100% |

面板最多4I/4S，最后两个S面板分别3题、0题；均值包括全部15面板，不能把它们拼合
为一次调用。查表只用于显示关联跨来源组能否保持，不是可部署语音基线。
完整I_class的100%是标签可逆编码的结果，不是泛化能力证据。

完整槽位向量有345个观测取值，14800录音为空且覆盖60个意图。35296录音位于
含多个意图的取值中，只有5217落入当前人口纯意图取值；纯取值也不能外推必然蕴含。
原生意图熵5.468 bits，给定完整槽位向量后的经验条件熵仍2.972 bits。
五折完整槽位查表正确15250条，682条所属向量在其他四折未出现；宏召回29.47%。

例如仅date的2289条覆盖27意图；仅time的961条覆盖23意图；date+event_name的
800条仍覆盖13意图，包含日程查询/新增/删除。地点或设备类型不能替代请求操作。
这些统计基于原生标注，缺标可能影响分布，不能直接外推到新S_present语义层。

## 对Q/奖励设计的具体约束

1. **S作为辅助证据，不作硬候选过滤。** 不用类型共现表自动生成意图—槽位一致性
   reward，不因S为空否定某意图。若要引入硬逻辑蕴含，须有任务语义与可靠关系监督。
2. **I_class明确披露标签冗余。** 它可训练定义消费、二分类及共享表示，但不能作为
   独立多步推理真值。有限菜单全false表示类别在菜单外，不是用户没有意图。
3. **继续保留音频到Final的完整决策。** 模型必须能使用操作及上下文等其他语义；
   不将少量Q输出视为最终答案的充分统计量，不强制通过外部规则合成Final。
4. **保留相同输入的过程奖励对照。** I+S比I的查表均值高约2.14个百分点，说明
   原生槽位具有附加关联，却不证明过程RL带来2.14个百分点收益。真实收益仍由
   Q-input/Q-credit在相同CE、起点和预算下的Final曲线检验。
5. 这些结果不用于按样本挑“最有用问题”，现有标签无关15面板不变。完整类型分析
   不代表55类型已获一次前向上下文准入，也不将annotation omission变为语义false。

上述约束已写入task v2及任务设计稿，仍为设计状态。没有新增算法实现或训练派发。
[独立复算](question-information-check-v1.json)从原始native targets重新构造完整类型向量，
核验16516条经验正确数与15250条五折正确数；4项测试涵盖冗余标签、无信息特征、
同来源多录音泄漏防护和重复输入拒绝。未将程序复算称作独立语义认证。
