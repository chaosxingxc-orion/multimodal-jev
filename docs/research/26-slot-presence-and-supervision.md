# SLURP槽位存在政策与监督覆盖

2026-11-12。完成当前40,513条learning录音的原生槽位覆盖统计，为55类型分别绑定
候选存在政策及证据种类。目标是让S判决和Final含义明确，而不是提前把尚未审核的
槽位数据交给训练。配置见[逐类型政策](../../configs/tasks/slurp/slot-presence-policy-candidate-v1.json)，
计数见[统计摘要](slot-support-summary-v1.json)。原数据、旧卡片和训练入口未修改。

## 1. 类型表达不等于具体参数值

本版S的候选主政策为`explicit_filler`：音频中存在一个符合类型定义及语义角色的表达。
这里filler指支持该类型的表达，不要求可执行或标准化的参数值。

阅读本轮固定hash抽取的161条learning参考例后，可明确区分：

| 类型与实际learning来源 | 原生标注的表达 | 政策含义 |
|---|---|---|
| personal_info / 16876 | work number | 字段名本身符合“个人信息属性”类型，无需真的给出电话号码 |
| personal_info / 15772 | number | 用户询问的信息属性，不能因此泛化为所有未赋值角色都存在 |
| change_amount / 981 | to max | 相对/极值表达足够，不要求数字 |
| event_name / 8081 | meeting | 原生类型允许活动类别表达，不只接受专有名称 |
| radio_name / 9387 | rock station | 可由描述性引用支持，不必是电台专名 |
| player_setting / 2162 | repeat | 动作/控制模式也可以是被标类型，不应全写成实体名称 |
| time / 5432 | two hours | 时长表达不是钟表时间，数值归一化属于另一个任务 |

上表是原生标注事实和定义讨论，不是新的逐例语义准入。对“会议几点开始”而言，
询问时间角色并不自动满足当前time卡中的时刻/时长表达规则；若要把这种询问也判true，
须另立`activated_role_allowing_unspecified_value`任务并准备独立标注。不能看到意图
通常需要时间参数，就把S(time)判true。

每类政策配置明确证据种类（身份引用、类别描述、数量时间、字段/查询对象），同时保留
旧卡的具体边界争议。先采用一套可说明的存在语义，不针对当前样本在两种政策间切换。

## 2. 提及范围、共存与绑定

S判断整条音频中是否表达该类型，包括背景、转述或否定语境中的角色表达。类型被提及
不等于该值被接受，也不等于它属于最终请求的操作。I_present对于被拒绝的行动可以是
false，而相关类型S仍可能为true；B关系、状态和意图要分别判断。

类型可共存，不能全局要求互斥。相同文字到底按person、artist_name还是news_topic
输出，需明确数据集约定；语义上像人物，不足以证明所有本体都应标person。当前不提供
gold意图来筛选槽位候选，也不借intent标签生成槽位存在性。

## 4. 原生标注投影和新Jev语义真值分别管理

原生任务复现时，`set(entity.type)`是原生标注投影，未列出某类型可作为该原生评分
目标的0，须披露这是标注复现口径及其质量局限。类型集合F1仍不等于原生槽值/SLU-F1。

新Jev任务宣称“音频是否出现定义中的类型”时，原生标注缺席不足以证明语义不存在。
14,800条空集合不能直接变成55类可靠负例；已有类型正例也要匹配定义与提及范围。
这并非要求声称所有原数据均无效，而是不给更强的新语义命题虚造真值证据。

最终监督表需按`source_group × definition_version × presence_policy`记录positive、
negative、unavailable或conflict及依据；同一句的不同政策不能共享未经核验的标签。
语义负例必须有逐例审核或该类型完整标注的验证依据。少量抽查不构成完备性认证。
当前统计不执行新的mask、不删除源记录、不放行槽位优化。

## 5. 对奖励与评测的具体约束

固定Q菜单在读入样本前产生；类别均衡在学习日程/外层权重定义，不能先找正类再挑Q。
训练必须报告每类型positive/negative/missing数量和有效覆盖，不能只统计原生类型频率。
未知监督被mask，不作为unknown输出或false参与CE和reward。

对完整集合EM奖励，面板内每个类型都需要有效真值。存在缺标的面板不得用“已知子集
全对”冒称完整集合EM；可另报带覆盖分母的原子指标，或在预先登记的完整面板上评分。
过程奖励按可靠Q的固定总预算分配，另报有效Q数量与构成；覆盖差异本身可能改变训练
分布，需要在对照臂保持一致。类型正例极稀疏时，全部答false的原子准确率高不代表
有用，必须同报macro-F1、正例召回及误报率。

下一步是完成高风险相邻类型的共同边界及监督裁决，再固定菜单和定义消费评测。
这批产物完成了全人口计数和逐类型政策登记，尚未完成任务冻结或工程release验收。
