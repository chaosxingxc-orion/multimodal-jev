独立Bernoulli动作下，G个完整动作全部相同的概率精确为
`product_j(p_j**G + (1-p_j)**G)`。该事件必然使确定性奖励相同，但不同动作也可能同奖励，
所以这是组内奖励零方差概率的下界，不是全部无信号组比例。

辅助ranking/NLL与reference KL仍可能产生梯度，不能把无组内优势称作整个更新没有学习。
没有gold，不能区分确定且正确与确定但错误，也不能由单批推断随训练持续塌缩或校准恶化。

这为后续算法选择增加实测依据：RLOO也无法从完全同奖励组取得优势，换优势估计器本身
不解决动作探索不足。增加G只有在尚有足够概率质量的替代动作上才有效；不能默认G翻倍
就按比例增加有效信号。若完整评测表明确有错误确定性，再预先冻结探索/熵约束或
精确期望奖励候选，与现有基线独立比较。不得在当前曲线中途改变采样温度、剔除无信号组、
改reward或辅助损失系数。现有标准算法和完整人口保持。
