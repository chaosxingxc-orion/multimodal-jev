## Stage 1：音频指令适配

从本地Qwen3-ASR-0.6B和新LoRA初始化开始，明确区别于旧temporal SFT adapter。
直接输入音频、完整问题、候选语义、符号绑定、思考配置，一次输出typed Span。
SFT指Span上的监督交叉熵，不要求生成转写、JSON或文本CoT。

使用完整learning人口，每轮可复现地覆盖所有录音。训练视图覆盖：单问intent、
scenario/action单问、多问及Final；候选排列与输出符号独立变化，监督随语义映射。
同一录音在不同问题下要求不同答案，降低只记音频→固定ID而忽视指令的风险。
配置由预先登记的模板族生成，不读取该条gold决定问题/候选；不声称这是通用聊天指令训练。
这些任务与Stage 2共享语义，阶段差异是训练目标和配置多样性，不宣称任务知识完全隔离。

监督目标为按有效来源归一化的masked CE。多Span过程总权重固定，不能因增加问题
无意扩大监督预算。每epoch每录音一个登记视图，按类交错/分桶并完整覆盖；不再同时
叠加逆频率loss和重采样。大类的覆盖段保留，不能声称每个batch严格均衡。

验收：独立selection上的意图accuracy/macro-F1，scenario/action，候选重排和
符号重绑定的语义正确率，留出模板族，以及每类召回/预测类别覆盖。训练CE仅解释优化。
阶段预算运行前冻结；若未取得可信的指令消费能力，记录未达标，不自动转入RL。

## Stage 2：任务RL与衰减监督

从Stage 1固定检查点开始；新的RL step0必须重新评测。保留同一音频与Span接口。

```
L_total(t) = L_RL(t) + lambda_sft(t) * L_CE(t)
L_CE = CE_Final + beta(t) * mean_masked(CE_process)
R = correct_Final + 0.1*correct_scenario + 0.1*correct_action
```

直接任务没有过程项。结构任务的两个过程CE初始各0.1，Final为1；与RL分别计权，
不重复乘权。RL沿用已验证有限候选边缘PPO，未知监督mask，同一有效来源分母。
CE直接优化正确候选logprob，不受RL正确概率过低造成的额外p(gold)梯度缩小。
不把辅助CE编码成伪reward或按旧正确概率缩放；它是独立的监督梯度。

初始候选日程：lambda_sft从1.0平滑衰减到0.1，在Stage 2前80%更新完成衰减，
之后保持0.1。这是待真实梯度尺度验收的默认值，不是已证实最优值；正式运行前固定。
恢复必须携带全局更新数、日程版本、Adam/master和来源游标，不能重启后重置衰减。
报告RL/CE/总loss、各项reward、KL、梯度范数及实际有效系数；不以总loss或总reward
代替Final表现。新曲线明确标为“RL+衰减监督”，不能宣称观测增益单独来自RL。

先保证规模化直接任务能学，再在相同Stage 1起点及数据预算上比较结构问题/过程信用。
不恢复旧小样本D/Q/P队列，也不增加纯SFT对照。复杂任务机制仍需未见组合证据；
scenario/action由intent投影不能单独证明多跳推理。

FP32 master/Adam及loss归一化。第一版保持已验证LoRA r4/alpha8、语言q/v，不同时改容量。

每次发布给vLLM的策略保留固定canary候选概率检查，阶段边界/预定检查点进行完整
后端验收及selection评估。检查频率改变单独登记，不能沿用旧“每步全量验收”的声明。
监督阶段无需每步vLLM rollout；阶段终点须通过同adapter导出/重载/跨后端验收。
特征缓存按波形及预处理版本寻址，增强后不得误用raw缓存；首先raw模式建立可靠吞吐。
