# 单正例集合F1的精确期望梯度候选

当前动作是60个独立Bernoulli，完整真值只有一个目标事件g。此特殊结构允许直接
计算期望集合F1及其梯度，无需枚举2^60动作，也无需额外音频前向。
这属于对已知奖励求精确期望的基础方法，不作为新算法发明或已实现训练效果宣传。

## 目标和计算

令K为非gold候选入选数，P(K=k)可通过Poisson-binomial递推取得：

`J(p) = E[F1] = p_g * sum_k 2/(k+2) * P(K=k)`。

对递推表反向传播即可获得每个概率导数，再乘`p_j*(1-p_j)`得到独立logit导数。
`tools/reports/exact_singleton_f1_gradient.py`实现CPU诊断版本，时间与保存递推表的空间
均为O(C²)。它没有接入torch autograd、verl actor、vLLM或NPU训练。

完整单正例及独立动作假设不可省略：缺失标签不能补false，多正例、绑定、外部环境奖励
不能直接套此实现。概率0/1的logit梯度采用sigmoid极限为0；实际饱和和浮点舍入仍是问题。

## 证据

11项测试通过/0.26秒：小维全动作穷举的期望reward和score梯度、60候选全部坐标的
current-logit有限差分、边界值及非法输入。又在已验收两步工程前缀的256个真实概率向量上，
以独立32节点多项式积分逐一复算15,360个logit导数，最大绝对差2.78e-16。
原概率/标签来源由既有审核报告及文件hash绑定；没有模型前向或参数更新。
见[实际概率核验](context-exact-f1-gradient-real-prefix-v1.json)。

两批的正例梯度均非负、负例梯度均非正。在独立logit坐标上，提高负例概率不会提高
此期望F1。因此上一节观察到首次混合更新后多选增加，不能解释为该奖励直接偏好增加
每个负例的概率。共享参数耦合、有限采样/组标准化、其他loss及更新步幅均可能影响结果，
目前未分离这些原因。两批query不同，不将其梯度均值差异称为策略改善。

## 与冻结算法的关系

该候选优化原始J(p)，不等于当前GRPO的组标准化、联合ratio裁剪目标。它也是利用
已知标签的决策效用优化，不是文本生成或开放环境RL的通用替代品。
即使对动作完全积分，也不能消除训练样本、数据批次、模型训练随机性造成的不确定性，
不能保证更好的泛化或harness效用。

一个后续可登记的对照是`exact_expected_singleton_f1`：在同Stage1起点、数据、辅助项、
KL及训练预算下，使用`-J(p)`替代采样surrogate，单独报告真实NPU成本和梯度尺度。
不默认沿用GRPO学习率就公平，因为组标准化改变梯度尺度；尺度规则必须先设计并冻结。
它不使用旧行为ratio，是否仍需要行为/reference前向及其训推一致性检查，应在新版本
工程设计中明确，不能借此删除当前运行的检查或直接声称吞吐提升。

当前GRPO/RLOO仍完整执行，候选dispatch=false。只有基线曲线取得后，结合实际学习
信号与业务效用确定后续实验优先级。复杂Q依然需要可靠过程真值；精确奖励计算不能
填补语义标注缺口，也不能证明单次并行读出形成了因果多步推理。
