## 任务输入和输出

输入完整保留公开函数定义及参数schema、环境信息、按时间顺序的用户音频和官方
提供的assistant历史。当前轮答案不进入输入；上轮官方history属于本基准输入
条件，应披露为supplied-history，不能称模型自主闭环。候选来自输入定义，不能
从gold函数筛选。各函数输出独立prob，不强制互斥或归一化。

问句的语义是“按照公开函数定义、环境和当前会话要求，此函数是否属于本轮应输出
的调用函数集合”。评分真值只投影官方调用列表的函数名集合；某函数不在列表中
仅表示它不是该官方调用集合成员，不等价于广义上永远不适用。缺参数NAN不取消
函数成员资格，函数选择也不等价于参数齐备、可执行或执行成功。

主报函数集合exact match和query宏set-F1，补充active micro precision/recall/F1、
候选binary NLL/Brier、误接收/误拒绝和完整覆盖率。按官方level、stage、ID/OOD分列，
多轮按会话both-correct，配对不确定性按会话分组。候选数变化下先按query汇总，
另报按所有候选汇总的权重口径。top1不能充当多函数主指标；本任务不输出参数，
不复用strict full-call EM或绑定参数F1冒称完成官方生成任务。

## 工程与研究边界

当前`ContextDecisionRequest.audio`为单字符串、history为文本字符串序列，且编码
入口只有一段audio；尚不能消费SFC的两段有序音频。不得删除上轮音频、用转写替代
或只筛单轮后声称完成全量SFC。需独立的有序多音频输入契约、参数schema/环境
渲染、1–6动态候选位置和真实HF/vLLM一致性验证，保持端到端音频与同一概率head。

SFC旧Omni/TFRL有TRAIN提示研究和历史评测暴露。本轮审计也使用了TRAIN标签做
任务结构定义，因此只能声称SLURP-only权重训练及目标无权重适配，不能声称整个
研究过程未接触SFC；不得继承旧教师提示再冒称零目标提示适配。

待准入项：原生集合投影/scorer、完整多音频输入编译、真实输入成本与后端parity、
历史暴露登记、冻结源选模型后的TEST评分。当前只完成结构及TRAIN标签绑定核对，
不派发SFC训练或评测。39项结构审计、原生无损转换和历史Jev转换回归通过0.73秒，
新增测试明确禁止打开TEST targets；并覆盖hash、人口、重复、历史前缀、标签绑定
及标签函数越界。旧SFC-Jev发布保持不变，旧present/absent不能直接重标为新head
上的广义函数适用性真值。
