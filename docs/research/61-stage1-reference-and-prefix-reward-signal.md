# Stage1参考策略与首次RL更新后的集合奖励信号

本分析使用已独立验收的真实NPU两步工程前缀，读取归档的两个128条TRAIN批次。
它不是正在运行的正式634步实验，也不是选择集或TEST成绩。未追加模型前向，
没有修改当前算法、配置或队列。

工具：`tools/reports/analyze_context_prefix_reward_signal.py`。
[逐query报告](context-prefix-exact-reward-signal-v1.json)绑定原独立验收文件hash，
检查学习标签、完整60候选、监督mask、实际FP32概率tensor hash、策略身份及行为/reference
输入和位置一致性。初始批次的行为概率与Stage1 reference逐项相同。

## 计算口径

在完整单正例exclusive_event真值下，gold入选概率为p_g，其他候选入选数K服从
Poisson-binomial分布。gold未入选时集合F1为0，否则为2/(K+2)。
由归档概率递推精确积分奖励分布，G16整组奖励相同概率是各奖励概率质量的16次方之和。
这些是对采样分布的期望，不是阈值0.5的确定性决策指标，也不是重放实际采样动作。

复用既有9项独立小维穷举测试，全部通过/0.14秒。另对全部512个分布使用
32节点Gauss-Legendre积分与直接概率乘积独立复算期望F1、完整正确、空集和多选概率；
被积多项式次数60，规则精确到63次，实测最大差8.61e-16。
见[独立复核](context-prefix-exact-reward-signal-v1-independent.json)。
独立积分不复核整组奖励相同概率；该项的算法依据为已有穷举测试。

## 初始批次的信号

第一批128条、128个来源组，策略等于Stage1终点。期望集合F1为0.694878，
G16整组奖励相同概率的均值14.6701%，即128组中期望约18.78组没有奖励差异。
因此该批不能描述为整体缺乏RL信号；也不能由“有奖励差异”推出梯度有效或模型会改善。
相同奖励组不产生组内优势，当前冻结配置继续保留其曝光分母，辅助监督仍然起作用。

## 同输入的行为/reference比较

第二批128条、127个来源组；行为策略已进行一次工程更新，reference仍为固定Stage1终点。
下表只在第二批相同输入内配对，不跨两批比较。

| 精确采样分布指标 | 固定Stage1 reference | 一次更新后的行为策略 |
| --- | ---: | ---: |
| 期望集合F1 | 0.697312 | 0.707247 |
| 完整正确集合概率 | 62.9901% | 40.1211% |
| 空集概率 | 16.1545% | 0.8359% |
| 多选概率 | 12.2760% | 57.2008% |
| 期望入选候选数 | 0.97184 | 1.87955 |
| gold候选入选概率 | 73.3198% | 92.0560% |
| G16整组奖励相同概率 | 16.6068% | 6.3017% |

这一批中，期望F1增加0.009936，同时完整正确概率下降。更多gold被选中，但更多其他
候选也被选中。集合F1允许这种折中，不能仅凭reward上升声称harness决策更稳定。
这里没有计算NLL/Brier变化，不据此声称校准退化。也没有隔离RL、ranking及binary NLL
各自的因果贡献；这次更新使用的是固定混合目标。

## 对后续算法工作的影响

保持当前正式GRPO/RLOO和预定评测不变。原协议已有exact set、选中数量、precision/recall、
NLL/Brier及全曲线，足以检查上述现象是否在完整选择集出现或持续，无需新增发布门槛。
正式长程结论不能由工程前缀替代，不能根据此小批次中途改reward、阈值或选择规则。

若正式曲线也出现F1改善而完整决策质量持续下降，应先讨论harness效用与reward的对齐，
再另立效用约束或奖励变体。节点信用降低估计噪声不能自动解决奖励偏好与业务效用不同。
若主要问题是奖励同值组增多，则先区分确定且正确、确定但错误、gold概率过低等原因，
不能统一剔除无优势组或只挑困难样本改变训练人口。

节点条件信用仍是独立研究候选，不加入当前训练。其旧策略局部梯度等价性、共享网络
方差限制和更新后不等价性已在[绑定信用分析](59-binding-reward-and-node-credit.md)说明。
复杂Q的过程监督仍需真实数据支持，当前完整集合奖励诊断不为其补造标签。
