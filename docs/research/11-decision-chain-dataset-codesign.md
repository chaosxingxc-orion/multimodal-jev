# 决策链、数据监督与收益实验协同设计

2026-11-11。响应用户要求：先证明数据能承载拟研究的决策依赖，再建设复杂策略。本文收紧候选链准入，不改变直接音频 actor、可配置非文本思考、清理后 SLURP 优先和质量隔离要求。

**当前结论：SLURP 适合先研究语义角色的联合判决与选择性复核；SFC 适合研究函数绑定的参数状态和补充信息后的状态保持。两者都没有天然证明最优决策过程的监督，也尚无本项目的思考收益证据。** 数据能定义和检验收益，不能保证一定获得收益。

## 1. 本次从本地学习数据核实了什么

可重跑工具：[audit_decision_chain_support.py](../../tools/jev/audit_decision_chain_support.py)；含输入及代码 SHA256 的[聚合凭证](../engineering/decision-chain-learning-support-v1.json)。本次未做推理、训练或下载，未打开 TEST。SLURP 仅使用 learning 文件；SFC 验证完整 TRAIN 文件哈希并按既有 learning 会话过滤，不统计或选取 selection 标签。以下均是标注结构审计，不代表完成音频语义审查。

### SLURP：有组合空间，缺少过程真值

- 9,223 个学习来源句子，60 个 scenario/action 组合、55 种槽位类型；多录音不增加独立语义样本量。
- 1,963 个来源标注了至少两种槽位类型，302 个来源出现同类型多个实体。
- 60 个意图中，59 个对应不止一种槽位类型集合；55 种类型中，39 种跨意图出现。因此不能把意图当成硬性槽位白名单。
- 即便给定 gold 意图，用该意图在学习集最常见的槽位集合回填，也仅命中 3,994/9,223（43.3%）。这是同集统计捷径诊断，不是模型测试成绩，更不说明复核一定有收益。
- `music_album`、`game_type` 各只有 1 个学习来源；已有证据卡还暴露个别语义边界疑点。不能将全部 55 个草案直接批准成过程监督。
- 未标注类型不能未经审核直接解释为语义不存在；零槽位的 2,977 条也不自动构成所有类型的可靠负例。

### SFC：有参数补充，存在轮次捷径

- 3,600 个学习会话、4,428 个请求、6,085 次 gold 调用；1,590 个请求含多个调用，639 次调用含数组参数。
- 所有 gold 调用对应的输入 schema 都显式提供 `required`，11,877 个必填参数位置中有 884 个包含 `NAN`，不存在必填键未写入 gold 的情况。
- 828 个两轮会话第一轮全部含 `NAN`，第二轮全部不含 `NAN`；函数集合始终不变。
- 按唯一函数名对齐两轮：916 个含 `NAN` 的参数被补齐；1,961 个此前已知的参数全部保持。916 包含全部参数，不等于 884 个必填参数位置。
- 当前学习集中没有同一请求重复调用同名函数的样本。不能仅凭转换器支持重复调用就宣称数据支持训练此能力。

这意味着，“第二轮参数更完整”容易被轮次、输入长度或固定历史模板预测。SFC 现有数据不能作为用户改口、更换工具、取消行动或自主决定澄清时机的充分证据。原始助手历史是给定输入，也不是本模型自主生成的交互轨迹。

## 2. 候选链与数据必须一一对应

| 候选链 | 可用监督与最终结果 | 必须补的证据 | 拟检验收益及边界 |
| --- | --- | --- | --- |
| SLURP：意图/角色初判 → 定义相关的歧义复核 → 最终联合判决 | 原生意图、实体类型；审核后的意图与类型集合 gold | 类型边界、可靠负例、同意图不同角色组合、相同类型跨意图的对照 | 意图准确率、类型 macro/micro F1、类型集合 EM、意图+类型联合 EM；不冒称完整 SLU-F1 |
| SLURP：若干语义事实 → 可配置规则 → 有限判决 | 审核事实 + 显式规则可计算最终标签 | 分支覆盖、语义等价规则归族、来源与规则族双重隔离 | 未见规则族上的判决准确率；单独标为派生任务，确定性规则执行器必须作对照 |
| SFC：函数适用性 → 函数绑定的参数状态 → 缺失项集合 | 原始调用、输入 schema、`NAN` 标记 | 标记与音频的一致性；区分缺失、可推导及默认值语义 | 活跃函数 F1、绑定的缺失参数集合 EM；不直接叫“安全执行准备度” |
| SFC：上一轮状态 → 补充音频 → 更新/保持 | 两轮同函数参数对齐 | 去轮次/历史模板捷径；新增跨条件覆盖或经审核补录 | 参数状态更新准确率、保持率、整轮状态 EM；开放值完全一致另表，不把类型任务称作完整函数调用 |
| MAC-SLU：多个意图 → 各自绑定的角色集合 | 原生多意图/槽位标注，须进一步审核转换 | 本地学习子集支持量、跨意图绑定对照、汉语声学影响 | 绑定集合 EM；原生 Overall 仅在完整原生输出时报告 |
| SpokenWOZ：历史状态 → 当前证据 → 状态转移 | 逐轮状态，具体可推导范围待审计 | 保持/替换/删除的真实覆盖、完整会话隔离、历史状态输入协议 | 有限转移任务单列；完整 JGA 需要真实槽位值，不能靠类型读出替代 |

中间节点有三种来源，必须明确标记：原生监督、经审核的确定性派生监督、策略内部未监督状态。不能把自己设计的节点序列当作“正确思考顺序”；没有过程真值时，只能由最终任务质量与成本检验策略，不能编造过程奖励。

## 3. 其他数据集承担什么证据

| 数据 | 在当前研究中的角色 |
| --- | --- |
| FSC、MINDS-14、SLUE 情感/DAC | 简单决策和跨域控制；直接判断足够的任务上，策略应学会停止，不强求复核带来正增益 |
| SLUE NER/NEL/QA | 依据具体标注研究角色或证据定位；没有跨度/时间监督的分支不能自行生成过程 gold |
| Audio2Tool | 冻结协议后的复杂工具外部测试；测试内容不用于设计规则、选择链或形成训练样本 |
| MMAR、MMSU、MMAU | 有限候选任务和声学边界的外部检验；只有最终答案时不能声称中间链正确 |
| VoiceBench | 按子任务适用性补充评估；生成任务不能强行折成有限决策以报告原生成指标 |
| FDB、τ² voice、EVA | 后续检验真实工具反馈、行动和任务成功；须接入环境与相应反馈，静态 SLU 无法代替 |

完整来源和指标见[16 项数据指南](08-dataset-metrics-working-guide.md)。本次没有重新在线核验文献，也未将上述待审计资源描述为训练就绪。

## 4. 先做最小可证伪实验

第一条主假设：**同一音频策略在同一语义任务下，能利用可配置要求将有限复核计算用于易混淆的角色判决，提高完整任务正确率或降低达到同等质量的计算成本。** “所有模型有配置入口”是接口契约；“所有任务都因更多思考而提高”不是合理实验承诺。

首个试验保持 Qwen3-ASR 0.6B、同一初始 checkpoint、同一审核后 SLURP 学习数据和直接音频输入。先完成任务 SFT，再逐步比较：

1. 无思考要求的单次直接读出：研究消融。
2. 同模型有配置、单次读出：隔离条件化指令的影响。
3. 有配置、固定复核：衡量额外计算本身的收益。
4. 有配置、规则触发复核：可复现的策略基线。
5. 有配置、学习触发与停止：检验 RL 的增量价值。

步骤 3–5 共用同一可用节点、原始音频和操作空间。部署时只能依据输入、模型实际预测和允许反馈触发，绝不能看 gold。复核是有限结构状态/数值决策，不输出自由文本思维链。

训练策略比较另加等预算继续 SFT、仅最终奖励 RL；若研究过程奖励，只用验收的节点标签。统一来源暴露、训练样本、监督信息、可用预算；分别报告训练计算和实际推理计算。共享单次预测用于复核消融，另以各自完整运行确认最终结论。与固定复核比较质量—成本曲线和匹配平均成本点，同时报告 p95 延迟，避免只用相同最大轮数宣称预算公平。

必须包括三类捷径控制：

- 只用任务 schema/数据先验，不用音频；语义不同的音频互换对照须经审核且按来源隔离。空音频是输入扰动诊断，不能单独证明模型依赖音频。
- SFC 只用轮次/提供的文本历史预测缺失状态；若已很强，改测具体参数绑定，并核实该细粒度任务是否仍有历史泄漏，不能只换指标名称。
- 派生规则任务使用“预测原子事实 + 确定性执行器”；gold 节点执行器仅诊断错误来源，不计可部署成绩。

主指标建议为 SLURP 意图+类型联合 EM，辅助报告各组成指标、全体样本及预先定义的困难切片。复核报告纠错率、改错率及净变化：纠错数减改错数。按来源连接组做配对区间估计，多录音不能当独立样本；训练重复的 seed 波动单独报告。

未知规则族、未知定义措辞与未知数据集分别建表；同一模板改写不是规则泛化，SFC TRAIN 适配之后不再叫 SLURP-only 零样本迁移。

## 5. 准入与停止条件

在正式试验前为每条链发布一张证据卡：语义任务、输入证据、节点出处、最终 gold、分支/类别覆盖、来源组、已知捷径、主指标、比较臂、可接受成本与失败后调整。数据不足的分支标 unknown 或排除出过程奖励，不能自动补负例。

先用 learning pilot 估计基线难度、配对纠错/改错量和方差，依据科研上有意义的最小改善量确定样本量、计算预算和成功门槛，再冻结 selection/最终测试协议；当前不凭空指定提升百分点。若样本量不足，结论为证据不足，不等于“没有效果”。困难切片须由学习数据定义，最终报告整体结果，禁止事后只保留有收益的测试题。

- **标签不能可靠审定**：缩小节点范围或补充独立审查，不进入 RL。
- **只有标签先验/轮次就能完成**：任务降为控制，或制作有合法对照的新数据；不作为思考能力核心证据。
- **单次模型已足够好、没有可测余量**：保留为停止/成本控制，不人为增加无依据的链条。
- **固定复核有效、学习策略不占优**：保留“额外推理计算有效”的结论，不声称 RL 策略改进。
- **一致性提高而原生语义质量无改善**：只能证明结构一致，不能宣称决策能力提升。
- **有质量提升但成本不满足预注册要求**：报告权衡，不用加权总分掩盖。

## 6. 下一阶段顺序

1. 55 类草案保留为候选。按学习集支持量、边界可审查性和预注册对照覆盖，选择首条 SLURP 角色复核链，形成可训练的小规模质量验收 release；不先扩展更多规则。
2. 补齐该 release 的训练适配，完成直接音频 SFT 基线；真实模型错误分布决定复核试验是否有可测余量。当前接口测试成功不等于该基线已完成。
3. 先比较单次判决与固定/规则复核；只有证据支持再加入学习触发和 RL。成功与失败结果都保留。
4. SFC 先形成函数绑定参数状态的独立监督审核和捷径分析；保持其迁移评估与监督适配两条轨道独立。MAC-SLU/SpokenWOZ 先核实覆盖，再决定是否补充复杂链证据。

这使“先用好清理后的 SLURP”和“需要更复杂数据验证复杂决策”兼容：前者验证语义基础和最小复核机制，后者按实际监督覆盖逐步扩展学术主张。
