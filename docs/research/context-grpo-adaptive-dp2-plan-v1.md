## 每轮诊断、每步新轨迹

“轮”在第一版定义为一次 TRAIN 难度刷新周期。固定当前策略，扫描全部 40513 条
TRAIN，记录 greedy 判决、正例与最难负例 margin、接受/拒绝错误、NLL/Brier，
以及 G16 组 reward 方差、非零优势比例。当前模型输出为候选概率与集合动作；这里的
轨迹不是文本 CoT，也不是自回归生成 token。固定一次音频前向可以在 CPU 采样多组
Bernoulli 动作，不应为 16 组动作重复做 16 次相同音频前向。

分层初值（实验假设，不是已有最优比例）：

| 层 | 定义 | 初始训练配额 |
|---|---|---|
| 已掌握 | greedy 集合正确且 margin/概率稳定 | 25% |
| 有学习信号 | 其余样本中 G16 reward 方差非零 | 50% |
| 持续失败/低信号 | 其余错误或不稳定且 G16 reward 方差为零 | 25% |

明确：greedy 正确不等于概率已校准；组内全错/全对都可能零优势。
全错层保留辅助监督与排序信号，不能期望仅增加零优势 RL 样本就改善。
不能将模型困难直接判为坏标签；重复失败只触发独立数据审计，不自动改标或删除。
稳定 margin 阈值必须从 TRAIN 诊断预先确定并封存，当前未填写最优数值。

每层内保持类别覆盖、限制单样本重复次数；空层配额回退到全 TRAIN 均匀采样，
不复制伪样本。记录每条抽样概率、曝光次数、类别/长度分布和冻结的轮次索引。
每轮扫描覆盖全量，不等于该轮训练全量覆盖；训练遗漏率必须单独报告。
保留固定训练机会预算的均匀采样对照，不能将额外曝光的收益归因于采样策略本身。

诊断只决定 query 选择，选中后的 G16 训练动作必须由当前 behavior policy 新生成。
不能按“这组 reward 有差异”挑选同一组动作再当无偏 on-policy 数据。
记录 policy_id、候选/输入身份、old logprob；两实例同策略，更新前 parity，更新后共同
确认新 LoRA/head 才接受下一批。跨轮旧轨迹不直接回灌普通 GRPO。

优先采样改变了 query 分布，GRPO 的 action ratio 不会自动纠正这一变化。
RL 可明确优化 curriculum 分布，但应如此命名；若概率辅助项目标仍是原始 TRAIN
分布，则使用独立均匀辅助流，或记录精确抽样概率并进行相应重要性加权，报告权重方差。
不得把偏采样 loss 直接称为全量自然分布校准损失。所有 selection/TEST 固定、不重采样。

## 两卡训练、双单卡推理

候选拓扑：175 4–5 为 DP2 actor，6、7 各一个 vLLM TP1 behavior 副本。
两推理副本按文本 token/音频帧预算分配 query，合批后恢复 request 顺序；均可打分
所有候选，不是分别固定处理容易/困难样本。固定 reference 在独立冷建阶段计算后缓存，
不永久占掉一个 behavior 实例；与历史缓存跨 runtime 复用仍需实际等价验证。

global128 保持；首次 DP2 micro8/accum8 建立数值基线，随后在同一发布候选内测
micro16/accum4，容量允许再测 micro32/accum2。不能沿用 DP4 的梯度缩放/四分片恢复
契约；从固定 Stage1 adapter/head 起点建新优化器，验证 DP2 的全局归一化和新进程恢复。
不把旧四卡 Adam 分片直接当两卡状态加载。

第一版保持同步：收齐当前 batch 的双实例 rollout→actor 更新→两副本同步发布→下一批。
不为利用空闲卡自动引入过期策略的异步流水线。阶段间有空闲是此一致性方案的已知代价。
当前代码有单 socket、四卡契约及共享设备假设，需要改准入、服务池、分发、同步和恢复；
仅改 physical_devices 不是完整实现。

现有原训练源码 session.prepare 在 actor.update_policy 之前，不能从共卡推断两个计算
始终同时竞争。共卡还会占用显存、限制批量，但目前没有隔离拓扑的因果性能测量。
旧 GRPO 冷轮约101s/step（rollout66、actor24），热轮约68s（rollout33、actor24）。
假设推理减半、DP2 actor 翻倍且其他不变：冷轮约92s，热轮约75s。
这是简单成本模型，不是预测实测；它说明两推理实例不能保证端到端两倍提速。
真实合批和 actor microbatch 才可能进一步改变收支。

对比必须包含冷/热 reference、代表性长短音频、模型同步、检查点与恢复，并单列全量
诊断成本；报告有效 query/s、音频秒/s、非零优势 query/s、每设备小时指标增益。
端到端收益满足已定目标后冻结配置，不持续扫描小改动。

## 下一实验顺序

1. 已完成：停止 RLOO，保护 partial 证据，释放 175 4–7。
2. DP2+双 TP1 数值/完整更新/恢复与吞吐验证；这一步先保持旧 GRPO 目标和固定样本，
   避免将算法/采样变化误计为工程收益。
3. 同一起点同预算比较固定采样与轮次刷新采样，目标仍固定；把诊断扫描成本计入。
4. 在选定采样方案上加入组件级排序/存在性 GRPO，明确方差下限等算法改造。
5. 固定 selection 选模后进行 clean TEST、FSC、MINDS；不继续等待 RLOO 比较链。

“极限”以固定资源预算下的质量—成本边界衡量，同时约束 Top1、NLL/Brier 和误接受。
没有找到数学最优或无限调参的承诺；旧混合 GRPO 的集合指标收益仍保留其原解释边界。
