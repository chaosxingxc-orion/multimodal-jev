# 教师全菜单预算、格式与共享规则对照

本轮固定同一接机参考，新增15个未测共享面板及1个字面S_present-05对照请求，
复用doc98的共享S_present-05。并发2、每请求输出4096、thinking enabled、180秒
总截止，关闭自动重试。所有新进程均已终态，不留待执行队列。输入仍无原生类别或
历史建议；全部数据来自learning，未用于选择/测试反馈优化。

16个共享面板均HTTP成功；其中15个有完整判决，合计112/120项，剩余8项缺失。
S_present-00返回finish_reason=length，4096 completion tokens全为reasoning，
最终content为空。另一S_present-06用4055输出token才完成，说明4096不是稳定的
全局输出预算。不能把HTTP成功或executor exit0记作完整标注，更不能把8项缺失补负。

意图面板输入3053–4104 token，槽位面板12830–24593 token。单来源跨16面板合计
172800输入token；乘9192得到1,588,377,600，仅为同一参考的规模投影，不是全量
token化、保证上界或实际费用。没有供应商费率、缓存折扣或完整输出统计，暂不报金额。

字面S_present-05输入74470 token，共享版24593；同源8项判决8/8一致。仅支持这
一个面板/来源的观察一致，不能宣称共享表示对全部语义、正例、歧义或长输出等价。
这一轮同源主要检验上下文与接口，不能当作全类别正负校准或随机质量样本。

实际返回出现Markdown JSON围栏。新增独立离线解析工具
`tools/jev/parse_semantic_annotation_response.py`，只接受裸JSON或一个完整围栏，
拒绝说明文字、截断、多对象、重复键及非有限常量；再调用既有完整ID/status/rationale
验证器。原始响应保留，裸JSON和围栏格式分列记录，空输出仍失败。不修改原生模型
benchmark解析器、不抽取猜测性的子串。18项相关测试通过。原工作包builder源码恢复
并核验与既有pin完全一致，解析器另文件保存，避免为格式兼容改变旧输入身份。

阅读全部可用理由：意图只支持taxi_ride_arrange，不把航班/地点/时间参数变成查询；
槽位支持明确日期、事件、人物、地点、时间及交通角色。设备谓词理由中的“车辆不是
物理硬件”表述过宽，应按设备/交通的任务边界解释，而不是当作现实世界事实。此处
只是作者对输出的质检，未新增独立语义准入，也未将该样本自动加入监督清单。
