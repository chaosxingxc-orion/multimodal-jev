# 本地宏与日常入口 v1

共享配置引用`${NAME}`，每台部署机器只维护自己的`.local/config/macros.json`。
可指定`--local`切换绑定文件；团队起点为[宏示例](../../local-macros.example.json)，
入口与调用方式见[配置说明](../../README.md)。解析后的配置及本地绑定不入库。

本版本登记宏解析器、配置生成器、日常工具入口、11份执行模板、相关测试和使用说明。
从仓库根目录执行：

```bash
sha256sum -c configs/releases/local-operations-v1/SHA256SUMS
```

清单只使用仓库相对路径；不绑定个人目录、服务器或本地宏值。
后续修改登记文件时发布新版本，保留旧清单及对应源码快照用于复现。
清单核验不能替代依赖安装、模型/数据身份检查或训练发布审核。

本次联合测试96项通过，11份模板均用团队示例成功解析；测试命令和范围记在
[validation.json](validation.json)。团队示例含待填写的资产身份，解析成功不代表可以训练。
本次仅对本地工程验收，没有启动远程任务，也没有改变现有训练/推理配置。

这不是全仓库或镜像的完整锁文件：只验证SHA256SUMS中显式列出的文件，不保证所有
传递依赖、跨机器执行及历史产物可移植。历史冻结配置继续作为证据保留，不做原位替换。
