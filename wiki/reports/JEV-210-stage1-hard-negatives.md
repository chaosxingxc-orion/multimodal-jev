# JEV-210 Stage1：语音对齐错例与强负例分数

**当前错因判断。** 根据团队对当前错例的文本语义核查，给定对应文字时，业务类别已经可判。研究重点转为两个可分别检验的问题：等义语音是否保留相同的意图、近义但改变决策的语音是否可分；在完整指令和单卡上下文中，这份语音证据能否改变正确的卡片分数。这里的文字是离线分组与核查依据，在线模型仍直接听录音。下文的概率与梯度统计描述输出和训练信号，不能从中定位究竟哪一层丢了证据。

**配对证据。** 在 Stage2 构造前的 68,303 条 TRAIN 候选里，Stage1 有 5,674 条严格错排。其中 2,422 条有同一文本标注、同一 gold、不同音频哈希且被严格判对的另一条录音；3,100 条有复录但无一严格判对，122 条无复录，30 条来源组混标单列。前一组证明输入换成另一录音就可能改变判决；后一组不能直接归因于文本歧义、特定噪声或模型容量。此处不是下文全 TRAIN 的分母。历史研究提交 `0514a91` 的 `wiki/reports/JEV-210-B-full-error-census.json` 记录该次分型；本次全 TRAIN 用下文独立脚本复算。

**对 Stage1 设计的影响。** 用源 TRAIN 的已有标注显式区分同句复录、异句同意图，以及只改变关键业务含义的异类对照。前两种检查不变性，第三种防止靠忽略“调高/调低”这样的差异过关。分别记录无卡语音检索是否选对，以及同一对录音换到完整卡面上时正确卡和易混淆卡的排序是否随含义改变。已完成的 210 按同标签抽正例，不保证选中复录；语音对语音项只更新共享读出，冻结塔的时间均值如果丢失关键信息，读出无法恢复它。应先用成对证据区分表示损失与读出错误，再决定是否改变可训练层；不把调温或提高 margin 作为错因已解决的证据。

使用正式 step 1362 已审核的全 TRAIN 原始 sigmoid 分数；复核 roster 和各分块 SHA、录音 ID 唯一覆盖，不重跑模型。每条录音比较 1 张真卡和 67 张错卡。这里的“错”指官方单标签业务定义，不推断整句语义互斥。[机器结果](JEV-210-stage1-hard-negatives.json) · [复算脚本](../../tools/reports/stage1_wrong_card_audit.py)。

| 指标 | 全 TRAIN |
|---|---:|
| 真卡严格第一 / 与最高错卡并列 / 被错卡超过 | 102,147 / 272 / 7,191 |
| 真卡原始概率中位数 | 0.9736 |
| 每条录音最高错卡原始概率中位数 | 0.9149 |
| 逐录音真卡减最高错卡的概率差中位数 | 0.0571 |
| 概率差至少 0.30 | 0 / 109,610 |

前两项概率的中位数不能相减代替差的中位数。统计量用于分析训练机制，不是泛化成绩，也不适用于重新校准后的读数。

**概率目标的局限。** 每一次成员打分都读完整的任务指令、单张卡及真实录音。历史 InfoNCE 只约束组内分数差；对所有 logits 加同一个常数，两个方向的 loss 都不变，而独立 sigmoid 分数可以整体接近 1。以一真一负、原始概率 0.97 和 0.91 为例，温度 0.1 时对比交叉熵约 0.000009，而概率差只有 0.06。完整输入和低排序损失都不保证可靠的逐卡概率。这解释了为何允许分数挤在高端，不证明统一偏移造成了每条错排；常数偏移本身无法交换名次。

**可能放大的机制。** 负例 logit 梯度为其温度 softmax 份额除以温度。固定同一批末点分数，只在每条录音的 67 张错卡内归一化，最强错卡占负例总份额的中位数：温度 0.1 为 81.54%，0.2 为 44.54%。这是全候选反事实，不是历史三个采样负例的参数梯度；份额集中也不等于总梯度大。训练用类别 EMA 混淆度、有放回抽三个错卡和三个异类语音；高混淆类可能重复得到权重，也可能遗漏该录音实际的最强错卡。严谨归因需按当步候选、当步分数、出现次数核对。每条录音在自己的卡上为正；把它放到别张互斥卡下才是成员负例。歧义、规约重叠、不可听辨都可能产生假负例，单看高分无法区分。

**候选修订。** 保留独立完整上下文，在两个成员方向比较原始 sigmoid 的真项与最强采样错项，施加 0.30 的概率间隔；两个成员 softmax 的温度可独立设置。第三项从前两项已经计算的每条唯一录音的冻结声学输出取均值，通过成员读出也使用的可训练 FFN 和归一化层，比较一条锚点语音和同类/异类录音的余弦相似度；不再跑声学塔和语言模型。该项更新共享读出参数，不单独更新冻结声学塔或语言层 LoRA。温度作用在各自 softmax 上，不作用在部署 sigmoid 上。间隔只约束本次抽到的对照，不保证全候选都达标、也不保证绝对概率已经校准。

后续修订已登记为 [JEV-211 Stage1 协议](../../experiments/stage1-speech-alignment-211.md)；[配对基线](JEV-211.md)复用上述原始分数，211 使用独立输出和有限收据。CPU 合约检查与历史全 TRAIN 分析不等于 NPU 性能、收敛或迁移收益。
