# Stage2 错例复盘：下一轮优先验证哪种训练信号

2026-11-21。建议保留 Stage1，以 JEV-194 固定参考 TPO 为意图排序基线；开放 Choice 单独验证覆盖判断，GRPO 保留为匹配预算的对照。这里比较的是已审核端点，属于研究建议，未新增队列、未恢复 JEV-204。

## 变长 Choice：正确意图已经排第一，仍被 NONE 拦下

从 [201 变长评分收据](JEV-201.md)按未舍入的分子、分母还原下表。198 和 201 对同一录音使用完全相同的候选与顺序。前三个错因互斥，之和等于错误总数；最后一行是误拒的子集。

| 录音数（198 → 201） | SLURP TEST（12,991） | MINDS（8,168） |
| --- | ---: | ---: |
| 真类在场，选择 NONE | 827 → 4,621 | 1,901 → 4,229 |
| 真类缺席，却接受某个候选 | 768 → 68 | 409 → 73 |
| 真类在场，接受了错误候选 | 1,692 → 302 | 658 → 67 |
| 错误总数 | 3,287 → 4,991 | 2,968 → 4,369 |
| 其中：真类排候选第一，最终选 NONE | 649 → 3,683 | 1,320 → 3,195 |

最后一行的复算：真类在候选内排第一的条数，减去最终正确接受真类的条数；后者等于整体正确数减去正确拒绝数。只看一个候选且它恰好是真类时，已经没有可排错的其他意图，201 仍分别误拒 **650/1,081、591/853**（198 为 270、305 条）。这把一部分失败直接定位到了覆盖判断。多候选时，现行[读出](../../src/multimodal_jev/context_choice.py)比较的是“覆盖概率 × 最大条件候选概率”与“不覆盖概率”，故其他误拒也可能与候选概率分散有关。覆盖概率本身的 Brier 在两集分别从 0.1011 升至 0.2129、0.2010 升至 0.2901（越低越好）。误拒并非单纯由列表变长或 harness 固定阈值引起；还不能从留出预测判定长期锚、联合损失或覆盖训练人口哪一项造成了偏移。

这个结论取决于任务和候选契约。[201 完整候选面板](JEV-201.md)上，相对 198，SLURP Choice macro-F1 反而提高 7.91 点，MINDS 下降 27.40 点。SIB-FLEURS 上 201 的候选内准确率为 75%，同时 302/320 条被拒；MMSU 候选内答对 50/98，同时误拒 48/98。封闭题看候选内排名，开放题同时计入正确拒绝、误拒与误接，不能混用两种成绩，也不能靠一律接受来解决。

## 意图 Top-1：负例得分上升和确实排错，不能靠调拒答阈值修复

**R64 GRPO。** 将[同轮 Stage1 step 160 与 Stage2 step 68](JEV-R64-S2.md)的完整原始预测按录音 ID 和封存标签配对，复核预测、标签哈希及两端正确数。SLURP 修正 483 条、退化 398 条；MINDS 修正 251 条、退化 703 条。各自错例中的平均 Top-1 原始概率在 SLURP 从 45.80% 升至 66.28%，在 MINDS 从 11.21% 升至 23.51%（两端错例集合不同）。MINDS 新错中，88 条从正确的 `pay_bill` 变为 `direct_debit`；末点全部错误中有 350 条 `freeze → card_issues`。这说明部分具体意图边界在后训练中丢失；没有音频反事实或独立标注复核，无法进一步认定噪声、口音或标注错误。

GRPO 有可验证的信号缺口：在**另一组历史 102 步**的[已审训练轨迹](../../experiments/0p6b-contrast-groups-and-capacity.md)中，48,522 个已错序比较有 12,059 个采样 16 次全部为错。该对的组内排序优势为零，其他损失仍可有梯度。不能将 24.85% 移用为 r64 的实测比例，也不能据此解释其每一条新错。

**固定参考 TPO。** [194](JEV-194.md) 比同起点、同视图、同 34 步且仅关闭投影的 direct，在 SLURP/MINDS 的 Top-1 macro-F1 分别高 2.51/3.68 点。相比 Stage1 本身仅高 0.69/0.17 点（原始值之差），单种子。MINDS 相比 Stage1 修复 229 条、退化 210 条，净收益很小；仍有 344 条 `freeze → card_issues`。其 [TRAIN 目标审核](../../docs/research/jev-tpo-error-analysis-194.md)定位到一个可直接修改的原因：3,903 条原本严格错排的录音里，2,740 条的固定投影目标本身仍未把真类排到第一。即使完美拟合这项目标，也不足以纠正它们；同一训练中的其他损失仍可能纠正。按真类落后最强错类的幅度做有界修正，离线可把目标翻正数从 1,163 提到 2,945。这是目标的变化，没有对应的单因素训练收益。195 同时改变动作空间、奖励和归一化，无法回答这个问题。

**动态参考 TPO。** [197 → 198](JEV-198.md)只改逐步刷新先验，保留原先冻结的奖励位移。SLURP 最强错类概率中位数从 0.135 升至 0.990，真类相对最强错类的概率间隔中位数从 0.680 降至 0.004；MINDS 的间隔也缩小。这个单种子配对说明，在这套目标下，每步改用最新 actor 会损伤排序。201 将动态竞争者、长期锚和双接口联合训练一起引入，恢复了部分排序，但 Noul 在 MINDS 相对主对照 197 仍有 486 条新错、仅修复 284 条；不能把差异单独归因给某一项。196 的五项开放面板也曾靠拒答得到等于真类缺席率的正确率，故正确拒绝必须与真类在场时的修复/退化一起读。

## 技术取舍与可证伪的下一步

1. **主线：固定参考 TPO，先单独修排序目标。** 同一 0.6B Stage1 step 160、194 的 6,248 条 TRAIN、配对、34 步、曝光、其他 loss 和读出；A 复用身份匹配的 194，B 只改有界排序修正。先验证目标不会破坏已满足间隔的样本，再看实际训练修复/退化、有无把最强错误候选一并抬高。主报源域 Top-1 macro-F1、准确率和平均最高原始概率；分列正负 NLL。预登记预算与容忍度，用源域 selection 选定策略；短对照见收益再换种子复核。
2. **Choice：先用源 TRAIN 判断错误出在目标、模型还是最终动作。** 固定 201 权重、音频、列表及顺序，用直接音频评分分出真类在场/缺席；按候选数和召回方式报告覆盖标签、冻结锚、投影目标、实际覆盖概率、候选第一名和最终动作。在 K=1 时先看覆盖是否偏低；在 K>1 时另算概率分散引入的误拒。若源 TRAIN 已复现覆盖低估且投影目标也低估，单独消融覆盖锚；若概率可用而接受代价不匹配，才比较固定模型下的覆盖决策策略。Harness 仅用源 TRAIN 校准并冻结，两臂同报误拒和误接。源 TRAIN 无对应现象则保留域外归因未定。冻结策略再评现有 SLURP、MINDS、SIB-FLEURS 与 MMSU；SIB 的提升区间跨零，MMSU 仅 98 题，不能以此证明普遍迁移优势。
3. **GRPO 保留为可翻转决策的对照。** 简单单标签任务有可信 gold，候选可枚举；优先使用无需采样到正确动作就能提供排序方向的投影。194 的 direct 并非 GRPO，R64 GRPO 的 68 步与 194 的 34 步也不是等条件对照。要决定算法本身的胜负，须固定 Stage1、视图/列表、真实曝光、更新数、共同奖励和辅助项，只比较投影与组内采样更新，并单列固定参考、在线采样、训练及评测卡时。如果匹配对照中 GRPO 可重复地减少原本正确样本的退化、守住跨域和开放面板且成本合算，再转主线。204 只有 4/212 步，不能作为路线证据。
